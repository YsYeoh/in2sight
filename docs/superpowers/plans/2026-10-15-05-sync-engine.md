# Plan 5: Sync Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pull Instagram insights for every active account on a 30-minute tick (Stories every tick, post metrics hourly/daily, account day snapshots with a 90-day first-connect backfill, audience daily, token refresh) into Supabase, with per-account failure isolation, and show "last synced" plus a "Sync now" action on the Accounts page.

**Architecture:** One scheduler-agnostic route, `GET|POST /api/cron/tick`, authenticated with `Authorization: Bearer <CRON_SECRET>`, answers `202` at once and runs `runTick()` inside Next's `after()`. `runTick` loads per-account `sync_state`, asks the pure `dueJobs()` (`lib/sync/schedule.ts`) what is due, takes a per-account lease (one conditional `UPDATE`), runs the jobs (`lib/sync/run-account.ts`) against a thin fetch client (`lib/instagram/data.ts`) within a 45 s budget, and writes snapshots through the admin Supabase client (`lib/sync/store.ts`). cron-job.org calls the route every 30 minutes (Supabase `pg_cron` + `pg_net` is the documented fallback).

**Tech Stack:** Next.js 16.4 route handlers + `after()`, TypeScript strict, `@supabase/supabase-js` (admin client), Vitest 5. **No new dependencies.**

**Spec:** `docs/SPEC.md` (§2, §3, §4, §5, §6, §7b; updated in the same commit as this plan for the scheduler decision). Project rules: `CLAUDE.md`.

## Decisions taken in this plan

- **202 + `after()`, not synchronous.** cron-job.org's free tier gives up after ~30 s. Next 16 docs (`node_modules/next/dist/docs/01-app/03-api-reference/04-functions/after.md`): `after` runs after the response for "the platform's default or configured max duration of your route"; on Vercel it is backed by `waitUntil`. So the route exports `maxDuration = 60`, validates auth and env synchronously (401/503 are visible to the scheduler), returns `202 {"accepted":true}`, and the tick runs in `after()` with `TICK_BUDGET_MS = 45_000` (45 s work + one 10 s request timeout + state write < 60 s). Results go to `public.sync_runs` (one row per tick) instead of the HTTP response. Testable: tests mock `after` and run the captured callback.
- **No per-job routes** (YAGNI): one tick decides everything. **"Sync now"** is included (one server action reusing `runTick` with `accountId` + `trigger: 'manual'`; ~20 lines).
- **Per-day account insight calls.** `metric_type=total_value` with `since/until` returns ONE total for the range, so each insight day is its own call (`since` = owner-timezone midnight, `until` = next midnight). This also sidesteps the undocumented maximum range.
- **Re-fetch the last 3 days daily** (`SETTLE_DAYS`): Meta says data can lag up to 48 h; upserts make re-fetching idempotent.
- **Token refresh** is a tick job (due within 14 days of expiry, retried at most daily) instead of a weekly cron. Same outcome as SPEC §3, faster recovery.
- **Error policy inside an account:** auth error → `needs_reconnect` (via the existing `markNeedsReconnect`), stop; rate limit → stop the account and back off 30/60/120/240 min; app-wide throttle (code 4) → stop the whole tick; any other error → record the key and continue with the next job (a broken metric must not starve Stories capture).

## Global Constraints

- Ponytail: smallest thing that works; no SDKs where `fetch` suffices; no new dependency (this plan adds none).
- TypeScript strict. Meta metric names live in ONE constants file (`lib/instagram/metrics.ts`); re-verify against Meta docs when touching them.
- All DB changes are SQL files in `supabase/migrations/`. RLS on every table; policies `to authenticated` using `public.is_owner()`; data tables are owner read-only, all writes via the admin client. `account_tokens` stays service-role only.
- Sync/API code gets mocked-fetch tests; logic is pure where possible (`lib/sync/schedule.ts`, `lib/sync/time.ts`, `lib/instagram/parse.ts`).
- Sync must isolate failures per account; never let one bad token stop the rest. `archived` accounts are skipped by every job.
- Never log, print or return access tokens or secrets. Errors carry fixed messages and codes only. `NEXT_PUBLIC_` only for Supabase URL / publishable key.
- Cron endpoints require `CRON_SECRET`; constant-time compare; fail closed when unset. Service-role key server-only (`import 'server-only'`).
- i18n: every UI string via next-intl, new keys in both `messages/en.json` and `messages/zh-CN.json`; backend returns error keys, not prose.
- Theming: semantic tokens only (`text-destructive`, `text-muted-foreground`). Responsive: works at 360 / 768 / 1280 px (table on md+, cards on phones).
- Dates/numbers in UI only via `lib/format.ts`; day boundaries computed with `Intl` in the owner's timezone (`profiles.timezone`), never manual offsets.
- Don't touch any Supabase project, Vercel project or Meta app from a task; the owner applies the migration and sets up cron-job.org (runbook).
- `npm run check` (lint + typecheck + tests + build) must pass before the plan is called done. Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Overlapping ticks** (cron-job.org retry or double fire; manual "Sync now" during a cron tick): an account must run at most once at a time → lease via one conditional `UPDATE`; pinned by Task 7 "overlapping ticks … cannot double-run an account" and "a lease left by a crashed tick blocks until it expires", Task 5 `claimLease` filter test.
2. **Token expired mid-run** (code 190 on any call): that account flips to `needs_reconnect`, its remaining jobs stop, every other account still syncs → Task 6 "token expired mid-run", Task 7 "one expired token never stops the other accounts".
3. **Owner timezone, day boundary and DST**: daily job due once per owner-local day after 06:00, day windows from `Intl` → Task 4 `dayStart` spring-forward/fall-back tests and "day boundaries follow the owner timezone, not UTC"; Task 6 "passes owner-timezone day boundaries as unix seconds".
4. **Rate-limit exhaustion** (80002/17/429, or app-wide 4): stop the account, back off, don't burn the rest of the budget → Task 4 back-off test, Task 6 rate-limit tests (captured media still marked), Task 7 "an app-wide rate limit (code 4) stops the tick".
5. **New / small accounts** (no history, under 100 followers, no stories, no media): first tick backfills; empty data becomes null/no rows, never zeros or errors → Task 4 "a brand-new active account is due…", Task 3 "accountDay returns nulls", Task 6 "an account under 100 followers…", "no live stories is fine".

Also pinned: pagination incl. host guard (Task 3), deleted media (Task 6), idempotent upserts and duplicate snapshots (Tasks 1, 5), archived/needs_reconnect skipped (Tasks 4, 7), partial work resumes next tick (Tasks 6, 7), tokens never in results/logs (Tasks 3, 6, 7, 8).

- [ ] **Step 3: Write the migration** — `supabase/migrations/20261015000001_sync.sql`:

```sql
-- Plan 5: synced Instagram data + sync bookkeeping. Owner session: read-only (select policies gated on is_owner()).
-- Every write goes through the server-side admin (secret-key) client, which bypasses RLS.

-- One row per account per Instagram insight day (owner timezone). followers is the count observed during that day.
-- profile_views stays null: the account-level metric was removed from the API (v21+); kept for the SPEC §5 shape.
create table public.account_daily (
  account_id         uuid not null references public.accounts (id) on delete cascade,
  day                date not null,
  followers          integer,
  reach              integer,
  views              integer,
  profile_views      integer,
  accounts_engaged   integer,
  total_interactions integer,
  follows            integer,
  unfollows          integer,
  link_taps          integer,
  updated_at         timestamptz not null default now(),
  primary key (account_id, day)
);
alter table public.account_daily enable row level security;
create policy account_daily_owner_select on public.account_daily
  for select to authenticated
  using (public.is_owner());

-- Feed posts, Reels and Stories. id is the Instagram media id.
create table public.media (
  id              text primary key,
  account_id      uuid not null references public.accounts (id) on delete cascade,
  media_type      text not null check (media_type in ('IMAGE', 'CAROUSEL_ALBUM', 'REELS', 'STORY')),
  permalink       text,
  caption         text,
  posted_at       timestamptz not null,
  expires_at      timestamptz,                -- stories only: posted_at + 24h
  last_metrics_at timestamptz,                -- when the last media_metrics snapshot was taken (drives re-capture)
  gone_at         timestamptz,                -- Instagram says the media no longer exists; stop fetching, keep history
  created_at      timestamptz not null default now()
);
create index media_account_posted_idx on public.media (account_id, posted_at desc);
alter table public.media enable row level security;
create policy media_owner_select on public.media
  for select to authenticated
  using (public.is_owner());

-- Point-in-time metric snapshots (growth curves). Story-only columns stay null for feed/reels.
create table public.media_metrics (
  media_id           text not null references public.media (id) on delete cascade,
  captured_at        timestamptz not null,
  reach              integer,
  views              integer,
  likes              integer,
  comments           integer,
  shares             integer,
  saves              integer,
  total_interactions integer,
  replies            integer,
  taps_forward       integer,
  taps_back          integer,
  exits              integer,
  primary key (media_id, captured_at)
);
alter table public.media_metrics enable row level security;
create policy media_metrics_owner_select on public.media_metrics
  for select to authenticated
  using (public.is_owner());

create table public.audience_snapshots (
  account_id uuid not null references public.accounts (id) on delete cascade,
  day        date not null,
  kind       text not null check (kind in ('age_gender', 'country', 'city')),
  data       jsonb not null,
  primary key (account_id, day, kind)
);
alter table public.audience_snapshots enable row level security;
create policy audience_snapshots_owner_select on public.audience_snapshots
  for select to authenticated
  using (public.is_owner());

create table public.online_followers (
  account_id uuid not null references public.accounts (id) on delete cascade,
  day        date not null,
  hourly     jsonb not null,                  -- 24 numbers, index = hour as Instagram reports it
  primary key (account_id, day)
);
alter table public.online_followers enable row level security;
create policy online_followers_owner_select on public.online_followers
  for select to authenticated
  using (public.is_owner());

-- Per-account scheduler state. The lease (lease_id + lease_until) stops overlapping ticks from double-running.
create table public.sync_state (
  account_id           uuid primary key references public.accounts (id) on delete cascade,
  lease_id             uuid,
  lease_until          timestamptz,
  last_attempt_at      timestamptz,
  last_success_at      timestamptz,
  consecutive_failures integer not null default 0 check (consecutive_failures >= 0),
  last_error_key       text,
  daily_done_through   date,                  -- last insight day fully written to account_daily
  last_run             jsonb not null default '{}'::jsonb   -- { "<job>": "<ISO time of last success>" }
);
alter table public.sync_state enable row level security;
create policy sync_state_owner_select on public.sync_state
  for select to authenticated
  using (public.is_owner());

-- One row per tick (cron or manual): a small JSON summary with counts and error keys, never tokens.
create table public.sync_runs (
  id          bigint generated always as identity primary key,
  started_at  timestamptz not null,
  finished_at timestamptz not null,
  trigger     text not null check (trigger in ('cron', 'manual')),
  summary     jsonb not null
);
alter table public.sync_runs enable row level security;
create policy sync_runs_owner_select on public.sync_runs
  for select to authenticated
  using (public.is_owner());
```

- [ ] **Step 5: Write the parsers** — `lib/instagram/parse.ts`:

```ts
// Pure parsers for Instagram API responses. Unknown or missing values become null / are skipped, never 0:
// Meta returns an empty data set (not 0) when a metric is unavailable.

type Obj = Record<string, unknown>;
const isObj = (v: unknown): v is Obj => typeof v === 'object' && v !== null && !Array.isArray(v);
const num = (v: unknown): number | null => (typeof v === 'number' && Number.isFinite(v) ? v : null);
const str = (v: unknown): string | null => (typeof v === 'string' && v !== '' ? v : null);
const entries = (body: unknown): Obj[] => (isObj(body) && Array.isArray(body.data) ? body.data.filter(isObj) : []);

/** Insight entry value: total_value.value (account insights) or values[0].value (media insights). */
function entryValue(e: Obj): number | null {
  const tv = isObj(e.total_value) ? num(e.total_value.value) : null;
  if (tv !== null) return tv;
  const first = Array.isArray(e.values) && isObj(e.values[0]) ? e.values[0] : null;
  return first ? num(first.value) : null;
}

/** { metricName: value } for every entry that has a numeric value. */
export function parseTotals(body: unknown): Record<string, number> {
  const out: Record<string, number> = {};
  for (const e of entries(body)) {
    const name = str(e.name);
    const v = entryValue(e);
    if (name && v !== null) out[name] = v;
  }
  return out;
}

/** First breakdown of `metric` as { "dim1|dim2": value }, e.g. { "25-34|F": 330 }. Empty object if absent. */
export function parseBreakdown(body: unknown, metric: string): Record<string, number> {
  const e = entries(body).find((x) => x.name === metric);
  const tv = e && isObj(e.total_value) ? e.total_value : null;
  const first = tv && Array.isArray(tv.breakdowns) && isObj(tv.breakdowns[0]) ? tv.breakdowns[0] : null;
  const results = first && Array.isArray(first.results) ? first.results.filter(isObj) : [];
  const out: Record<string, number> = {};
  for (const r of results) {
    const v = num(r.value);
    if (!Array.isArray(r.dimension_values) || v === null) continue;
    out[r.dimension_values.map(String).join('|')] = v;
  }
  return out;
}

export type MediaKind = 'IMAGE' | 'CAROUSEL_ALBUM' | 'REELS' | 'STORY';
export interface IgMediaItem {
  id: string;
  kind: MediaKind;
  caption: string | null;
  permalink: string | null;
  postedAt: string; // ISO UTC
}

/** Every feed video is a Reel since 2022, so VIDEO maps to REELS when media_product_type is unavailable. */
function kindOf(m: Obj, story: boolean): MediaKind | null {
  if (story || m.media_product_type === 'STORY') return 'STORY';
  if (m.media_product_type === 'REELS' || m.media_type === 'VIDEO') return 'REELS';
  if (m.media_type === 'IMAGE' || m.media_type === 'CAROUSEL_ALBUM') return m.media_type;
  return null;
}

/** Instagram timestamps look like 2026-10-13T10:00:00+0000. Returns ISO UTC or null. */
export function toIso(v: unknown): string | null {
  const s = str(v);
  if (!s) return null;
  const t = Date.parse(s.replace(/([+-]\d{2})(\d{2})$/, '$1:$2'));
  return Number.isNaN(t) ? null : new Date(t).toISOString();
}

/** A page of /me/media or /me/stories. Items with an unknown type or no timestamp are skipped. */
export function parseMediaPage(body: unknown, story: boolean): { items: IgMediaItem[]; next: string | null } {
  const items: IgMediaItem[] = [];
  for (const m of entries(body)) {
    const id = typeof m.id === 'number' ? String(m.id) : str(m.id);
    const kind = kindOf(m, story);
    const postedAt = toIso(m.timestamp);
    if (!id || !kind || !postedAt) continue;
    items.push({ id, kind, caption: str(m.caption), permalink: str(m.permalink), postedAt });
  }
  const paging = isObj(body) && isObj(body.paging) ? body.paging : null;
  return { items, next: paging ? str(paging.next) : null };
}

/**
 * The insight day an online_followers value belongs to. end_time marks the END of the day it covers (midnight in
 * Instagram's day, e.g. 07:00Z = Pacific midnight); stepping back 12h lands safely inside that day.
 */
export function insightDay(endTime: string): string | null {
  const iso = toIso(endTime);
  return iso ? new Date(Date.parse(iso) - 12 * 3_600_000).toISOString().slice(0, 10) : null;
}

/** online_followers values -> [{ day, hourly[24] }]. Empty values (accounts under 100 followers) are skipped. */
export function parseOnlineFollowers(body: unknown): { day: string; hourly: number[] }[] {
  const e = entries(body).find((x) => x.name === 'online_followers');
  const values = e && Array.isArray(e.values) ? e.values.filter(isObj) : [];
  const out: { day: string; hourly: number[] }[] = [];
  for (const v of values) {
    const day = typeof v.end_time === 'string' ? insightDay(v.end_time) : null;
    if (!day || !isObj(v.value) || Object.keys(v.value).length === 0) continue;
    const byHour = v.value;
    out.push({ day, hourly: Array.from({ length: 24 }, (_, h) => num(byHour[String(h)]) ?? 0) });
  }
  return out;
}
```

```ts
// Instagram data reads for the sync (graph.instagram.com, Instagram Login tokens). Thin fetch wrapper, no SDK.
// Errors are InstagramApiError('data' | 'network'): fixed messages, never a URL, body or token.
import * as M from '@/lib/instagram/metrics';
import { call, InstagramApiError, refreshLongLived } from '@/lib/instagram/oauth';
import { parseBreakdown, parseMediaPage, parseOnlineFollowers, parseTotals, type IgMediaItem } from '@/lib/instagram/parse';

const HOST = 'https://graph.instagram.com';
/** Per request. Keeps one hung call from eating the tick's time budget. */
export const IG_TIMEOUT_MS = 10_000;

export interface AccountDayValues {
  reach: number | null;
  views: number | null;
  accountsEngaged: number | null;
  totalInteractions: number | null;
  linkTaps: number | null;
  follows: number | null;
  unfollows: number | null;
}

export interface MediaMetricValues {
  reach: number | null;
  views: number | null;
  likes: number | null;
  comments: number | null;
  shares: number | null;
  saves: number | null;
  totalInteractions: number | null;
  replies: number | null;
  tapsForward: number | null;
  tapsBack: number | null;
  exits: number | null;
}

const NO_METRICS: MediaMetricValues = { reach: null, views: null, likes: null, comments: null, shares: null, saves: null, totalInteractions: null, replies: null, tapsForward: null, tapsBack: null, exits: null };

export type IgErrorClass = 'auth' | 'app_rate_limit' | 'rate_limit' | 'no_data' | 'gone' | 'transient' | 'other';

/** What a failed call means for the sync. Callers decide what to do with no_data / gone (only media insights skip). */
export function classifyIgError(e: unknown): IgErrorClass {
  if (!(e instanceof InstagramApiError)) return 'other';
  if (e.kind === 'network') return 'transient';
  const c = e.code;
  if (c !== undefined && ((M.IG_ERROR.auth as readonly number[]).includes(c) || (c >= 200 && c <= 299))) return 'auth';
  if (c !== undefined && (M.IG_ERROR.appRateLimit as readonly number[]).includes(c)) return 'app_rate_limit';
  if ((c !== undefined && (M.IG_ERROR.rateLimit as readonly number[]).includes(c)) || e.status === 429) return 'rate_limit';
  if (c === M.IG_ERROR.notEnoughViewers) return 'no_data';
  if (c === M.IG_ERROR.invalidParam && e.subcode === M.IG_ERROR.objectMissingSubcode) return 'gone';
  if ((c !== undefined && (M.IG_ERROR.transient as readonly number[]).includes(c)) || (e.status ?? 0) >= 500) return 'transient';
  if (e.status === 401) return 'auth';
  return 'other';
}

const num = (v: unknown): number | null => (typeof v === 'number' && Number.isFinite(v) ? v : null);

export function igData(apiVersion: string, fetchFn: typeof fetch = fetch) {
  const getUrl = (url: string) => call('data', fetchFn, url, { signal: AbortSignal.timeout(IG_TIMEOUT_MS) });
  const get = (path: string, params: Record<string, string | number>, token: string) => {
    const u = new URL(`${HOST}/${apiVersion}/${path}`);
    for (const [k, v] of Object.entries(params)) u.searchParams.set(k, String(v));
    u.searchParams.set('access_token', token);
    return getUrl(u.toString());
  };

  /** Follows paging.next until maxItems, the last page, or (if given) a page reaching media older than stopBefore. */
  async function listPaged(path: string, token: string, story: boolean, maxItems: number, stopBefore?: string): Promise<IgMediaItem[]> {
    const out: IgMediaItem[] = [];
    let body = await get(path, { fields: M.MEDIA_FIELDS, limit: M.MEDIA_PAGE_SIZE }, token);
    for (;;) {
      const page = parseMediaPage(body, story);
      for (const item of page.items) {
        if (out.length >= maxItems) return out;
        out.push(item);
      }
      const reachedOld = stopBefore !== undefined && page.items.some((i) => i.postedAt < stopBefore);
      // the next URL carries the token: only ever follow it to Instagram's own host
      if (!page.next || reachedOld || out.length >= maxItems || !page.next.startsWith(`${HOST}/`)) return out;
      body = await getUrl(page.next);
    }
  }

  return {
    async profile(token: string): Promise<{ followersCount: number | null }> {
      const b = await get('me', { fields: M.PROFILE_FIELDS }, token);
      return { followersCount: num(b.followers_count) };
    },

    /** One insight day: since/until are unix seconds of that day's start and the next day's start. */
    async accountDay(token: string, since: number, until: number): Promise<AccountDayValues> {
      const base = { metric_type: 'total_value', period: 'day', since, until };
      const t = parseTotals(await get('me/insights', { ...base, metric: M.ACCOUNT_DAY_METRICS.join(',') }, token));
      const f = parseBreakdown(await get('me/insights', { ...base, metric: M.FOLLOWS_METRIC, breakdown: M.FOLLOWS_BREAKDOWN }, token), M.FOLLOWS_METRIC);
      return {
        reach: t.reach ?? null,
        views: t.views ?? null,
        accountsEngaged: t.accounts_engaged ?? null,
        totalInteractions: t.total_interactions ?? null,
        linkTaps: t.profile_links_taps ?? null,
        follows: f[M.FOLLOW_TYPE.follows] ?? null,
        unfollows: f[M.FOLLOW_TYPE.unfollows] ?? null,
      };
    },

    listMedia: (token: string, maxItems: number, stopBefore?: string) => listPaged('me/media', token, false, maxItems, stopBefore),
    listStories: (token: string) => listPaged('me/stories', token, true, 100),

    async feedInsights(token: string, mediaId: string): Promise<MediaMetricValues> {
      const t = parseTotals(await get(`${mediaId}/insights`, { metric: M.FEED_METRICS.join(',') }, token));
      return { ...NO_METRICS, reach: t.reach ?? null, views: t.views ?? null, likes: t.likes ?? null, comments: t.comments ?? null, shares: t.shares ?? null, saves: t.saved ?? null, totalInteractions: t.total_interactions ?? null };
    },

    async storyInsights(token: string, mediaId: string): Promise<MediaMetricValues> {
      const t = parseTotals(await get(`${mediaId}/insights`, { metric: M.STORY_METRICS.join(',') }, token));
      const nav = parseBreakdown(await get(`${mediaId}/insights`, { metric: M.STORY_NAVIGATION_METRIC, breakdown: M.STORY_NAVIGATION_BREAKDOWN }, token), M.STORY_NAVIGATION_METRIC);
      const navUpper = Object.fromEntries(Object.entries(nav).map(([k, v]) => [k.toUpperCase(), v]));
      return {
        ...NO_METRICS,
        reach: t.reach ?? null,
        views: t.views ?? null,
        replies: t.replies ?? null,
        shares: t.shares ?? null,
        totalInteractions: t.total_interactions ?? null,
        tapsForward: navUpper.TAP_FORWARD ?? null,
        tapsBack: navUpper.TAP_BACK ?? null,
        exits: navUpper.TAP_EXIT ?? null,
      };
    },

    async audience(token: string, kind: M.AudienceKind): Promise<Record<string, number>> {
      const params = { metric: M.DEMOGRAPHICS_METRIC, period: 'lifetime', metric_type: 'total_value', timeframe: M.DEMOGRAPHICS_TIMEFRAME, breakdown: M.DEMOGRAPHIC_BREAKDOWNS[kind] };
      return parseBreakdown(await get('me/insights', params, token), M.DEMOGRAPHICS_METRIC);
    },

    async onlineFollowers(token: string, since: number, until: number) {
      return parseOnlineFollowers(await get('me/insights', { metric: M.ONLINE_FOLLOWERS_METRIC, period: 'lifetime', since, until }, token));
    },

    refresh: (token: string) => refreshLongLived(token, fetchFn),
  };
}
```

```ts
// Owner-timezone day arithmetic. Offsets come from Intl for the instant in question (DST-safe), never hard-coded.
// A "day" is a 'YYYY-MM-DD' string in the owner's timezone.

const DAY_MS = 86_400_000;
const pad = (n: number) => String(n).padStart(2, '0');

function parts(at: Date, tz: string) {
  const f = new Intl.DateTimeFormat('en-US', { timeZone: tz, hourCycle: 'h23', year: 'numeric', month: '2-digit', day: '2-digit', hour: '2-digit', minute: '2-digit', second: '2-digit' });
  const p = Object.fromEntries(f.formatToParts(at).map((x) => [x.type, x.value]));
  return { y: Number(p.year), m: Number(p.month), d: Number(p.day), h: Number(p.hour), min: Number(p.minute), s: Number(p.second) };
}

export function localDay(at: Date, tz: string): string {
  const p = parts(at, tz);
  return `${p.y}-${pad(p.m)}-${pad(p.d)}`;
}

export function localHour(at: Date, tz: string): number {
  return parts(at, tz).h;
}

/** Calendar arithmetic on a day string (timezone-free). */
export function addDays(day: string, n: number): string {
  return new Date(Date.parse(`${day}T00:00:00Z`) + n * DAY_MS).toISOString().slice(0, 10);
}

/** tz offset (ms, local minus UTC) at an instant. */
function offsetMs(at: number, tz: string): number {
  const p = parts(new Date(at), tz);
  return Date.UTC(p.y, p.m - 1, p.d, p.h, p.min, p.s) - Math.floor(at / 1000) * 1000;
}

/** The instant the day starts in tz. Two passes so a DST change between UTC midnight and local midnight is handled. */
export function dayStart(day: string, tz: string): Date {
  const utcMidnight = Date.parse(`${day}T00:00:00Z`);
  let t = utcMidnight - offsetMs(utcMidnight, tz);
  t = utcMidnight - offsetMs(t, tz);
  return new Date(t);
}

/** [since, until) of a day as unix seconds, the form Instagram's insights API takes. */
export function dayRangeSec(day: string, tz: string): { since: number; until: number } {
  return { since: dayStart(day, tz).getTime() / 1000, until: dayStart(addDays(day, 1), tz).getTime() / 1000 };
}
```

```ts
// Pure scheduling decisions: which jobs are due for an account on this tick, and which media need a new snapshot.
// The tick runs every 30 minutes from any HTTP scheduler (docs/RUNBOOK_SYNC.md); intervals here are independent of it.
import type { AccountStatus } from '@/lib/accounts/types';
import { addDays, localDay, localHour } from '@/lib/sync/time';

export const STORIES_EVERY_MIN = 30; // every tick: a story lives 24h, a missed window is lost data
export const MEDIA_LIST_EVERY_MIN = 60;
export const SLACK_MIN = 5; // a scheduler firing a few minutes early (or a slow previous tick) still counts as on time
export const DAILY_HOUR = 6; // owner-local hour after which the daily account + audience jobs run
export const BACKFILL_DAYS = 90; // first connect: account insights this far back (Meta keeps ~90 days)
export const SETTLE_DAYS = 3; // Instagram data can lag up to 48h: re-fetch the last 3 days every day
export const TOKEN_REFRESH_WITHIN_DAYS = 14;
export const TOKEN_RETRY_HOURS = 24;
export const MEDIA_HOURLY_UNDER_HOURS = 48;
export const MEDIA_DAILY_UNDER_DAYS = 30;
export const MEDIA_BACKFILL_MAX = 500;
export const MEDIA_RECENT_MAX = 100;
const BACKOFF_BASE_MIN = 30;
const BACKOFF_MAX_MIN = 240;

const MIN = 60_000;
const HOUR = 60 * MIN;

/** Run order inside one account: time-critical first, token refresh last (the current token stays valid). */
export const JOBS = ['stories', 'daily', 'mediaList', 'mediaMetrics', 'audience', 'tokenRefresh'] as const;
export type JobKind = (typeof JOBS)[number];

export interface SyncState {
  accountId: string;
  leaseUntil: string | null;
  lastAttemptAt: string | null;
  lastSuccessAt: string | null;
  consecutiveFailures: number;
  lastErrorKey: string | null;
  dailyDoneThrough: string | null;
  lastRun: Partial<Record<JobKind, string>>; // ISO time of each job's last success
}

export const emptyState = (accountId: string): SyncState => ({
  accountId,
  leaseUntil: null,
  lastAttemptAt: null,
  lastSuccessAt: null,
  consecutiveFailures: 0,
  lastErrorKey: null,
  dailyDoneThrough: null,
  lastRun: {},
});

/** Rate-limit back-off: 30, 60, 120, 240, 240… minutes after the last attempt. */
export function backoffMs(failures: number): number {
  return failures <= 0 ? 0 : Math.min(BACKOFF_BASE_MIN * 2 ** (failures - 1), BACKOFF_MAX_MIN) * MIN;
}

export interface ScheduleInput {
  status: AccountStatus;
  tokenExpiresAt: string | null;
  state: SyncState;
}

export function dueJobs({ status, tokenExpiresAt, state: s }: ScheduleInput, now: Date, tz: string, opts: { manual?: boolean } = {}): JobKind[] {
  if (status !== 'active') return []; // archived and needs_reconnect accounts are never synced
  const t = now.getTime();
  if (s.leaseUntil && Date.parse(s.leaseUntil) > t) return []; // another tick holds this account
  const ago = (iso: string | null | undefined) => (iso ? t - Date.parse(iso) : Infinity);
  const atLeast = (iso: string | null | undefined, ms: number) => ago(iso) >= ms - SLACK_MIN * MIN;
  if (!opts.manual && s.lastErrorKey === 'rate_limited' && !atLeast(s.lastAttemptAt, backoffMs(s.consecutiveFailures))) return [];

  const today = localDay(now, tz);
  const afterDailyHour = localHour(now, tz) >= DAILY_HOUR;
  const ranToday = (iso: string | undefined) => !!iso && localDay(new Date(iso), tz) === today;
  const due = new Set<JobKind>();

  if (opts.manual || atLeast(s.lastRun.stories, STORIES_EVERY_MIN * MIN)) due.add('stories');
  // behind = never ran (first-connect backfill) or a day was missed: catch up now, whatever the hour
  const behind = !s.dailyDoneThrough || s.dailyDoneThrough < addDays(today, -2);
  if (behind || (afterDailyHour && !ranToday(s.lastRun.daily))) due.add('daily');
  if (opts.manual || atLeast(s.lastRun.mediaList, MEDIA_LIST_EVERY_MIN * MIN)) due.add('mediaList');
  due.add('mediaMetrics'); // cheap when nothing is due: pickDueMedia decides per post
  if (!s.lastRun.audience || (afterDailyHour && !ranToday(s.lastRun.audience))) due.add('audience');
  const expires = tokenExpiresAt ? Date.parse(tokenExpiresAt) : NaN;
  if (!Number.isNaN(expires) && expires - t <= TOKEN_REFRESH_WITHIN_DAYS * 24 * HOUR && atLeast(s.lastRun.tokenRefresh, TOKEN_RETRY_HOURS * HOUR)) due.add('tokenRefresh');

  return JOBS.filter((j) => due.has(j));
}

/** Round-robin: accounts that waited longest go first (never-attempted first of all). */
export function byOldestAttempt(a: SyncState, b: SyncState): number {
  if (a.lastAttemptAt === b.lastAttemptAt) return 0;
  if (a.lastAttemptAt === null) return -1;
  if (b.lastAttemptAt === null) return 1;
  return a.lastAttemptAt < b.lastAttemptAt ? -1 : 1;
}

export interface MediaRef {
  id: string;
  postedAt: string;
  lastMetricsAt: string | null;
}

/** Feed/Reels media needing a snapshot now, newest first: never captured (backfill), hourly under 48h, daily under 30d. */
export function pickDueMedia(refs: MediaRef[], now: Date): string[] {
  const t = now.getTime();
  const slack = SLACK_MIN * MIN;
  return refs
    .filter((r) => {
      if (!r.lastMetricsAt) return true;
      const age = t - Date.parse(r.postedAt);
      const since = t - Date.parse(r.lastMetricsAt);
      if (age < MEDIA_HOURLY_UNDER_HOURS * HOUR) return since >= HOUR - slack;
      if (age < MEDIA_DAILY_UNDER_DAYS * 24 * HOUR) return since >= 24 * HOUR - slack;
      return false;
    })
    .sort((a, b) => (a.postedAt < b.postedAt ? 1 : a.postedAt > b.postedAt ? -1 : 0))
    .map((r) => r.id);
}
```

```ts
type Call = { table: string; op: string; args: unknown[]; filters: [string, ...unknown[]][] };

/** Records every query-builder call; each awaited query resolves to the next queued result (default: ok, no data). */
function recorder(results: { data?: unknown; error?: unknown }[] = []) {
  const calls: Call[] = [];
  const db = {
    from(table: string) {
      const call: Call = { table, op: '', args: [], filters: [] };
      calls.push(call);
      const next = () => Promise.resolve(results.shift() ?? { data: null, error: null });
```

```ts
// Sync persistence. supabaseSyncStore takes the ADMIN client (writes bypass RLS); listSyncStatus takes the owner session.
// Errors never include Supabase's message (it can echo values).
import type { SupabaseClient } from '@supabase/supabase-js';
import type { AccountDayValues, MediaMetricValues } from '@/lib/instagram/data';
import type { AudienceKind } from '@/lib/instagram/metrics';
import type { IgMediaItem } from '@/lib/instagram/parse';
import { DEFAULT_PREFS, isValidTimeZone } from '@/lib/prefs';
import { emptyState, type JobKind, type MediaRef, type SyncState } from '@/lib/sync/schedule';

export interface StatePatch {
  lastAttemptAt: string;
  lastSuccessAt?: string;
  consecutiveFailures: number;
  lastErrorKey: string | null;
  dailyDoneThrough: string | null;
  lastRun: Partial<Record<JobKind, string>>;
}

export interface SyncRun {
  startedAt: string;
  finishedAt: string;
  trigger: 'cron' | 'manual';
  summary: unknown;
}

export interface SyncStore {
  ownerTimezone(): Promise<string>;
  loadStates(accountIds: string[]): Promise<Map<string, SyncState>>;
  /** Atomic: true only if no live lease exists. One UPDATE … WHERE lease free, so two ticks cannot both win. */
  claimLease(accountId: string, leaseId: string, untilIso: string, nowIso: string): Promise<boolean>;
  /** Writes the state and releases the lease, only if this tick still holds it. */
  saveState(accountId: string, leaseId: string, patch: StatePatch): Promise<void>;
  getToken(accountId: string): Promise<string | null>;
  upsertDaily(accountId: string, day: string, v: AccountDayValues): Promise<void>;
  upsertFollowers(accountId: string, day: string, followers: number): Promise<void>;
  upsertMedia(accountId: string, items: IgMediaItem[]): Promise<void>;
  mediaForMetrics(accountId: string, sinceIso: string): Promise<MediaRef[]>;
  insertMetrics(mediaId: string, capturedAt: string, v: MediaMetricValues): Promise<void>;
  markCaptured(mediaIds: string[], atIso: string): Promise<void>;
  markGone(mediaId: string, atIso: string): Promise<void>;
  upsertAudience(accountId: string, day: string, kind: AudienceKind, data: Record<string, number>): Promise<void>;
  upsertOnlineFollowers(accountId: string, day: string, hourly: number[]): Promise<void>;
  recordRun(run: SyncRun): Promise<void>;
}

type Row = Record<string, unknown>;

function fail(op: string): never {
  throw new Error(`sync store: ${op} failed`);
}

export function rowToState(r: Row): SyncState {
  return {
    accountId: r.account_id as string,
    leaseUntil: (r.lease_until as string | null) ?? null,
    lastAttemptAt: (r.last_attempt_at as string | null) ?? null,
    lastSuccessAt: (r.last_success_at as string | null) ?? null,
    consecutiveFailures: typeof r.consecutive_failures === 'number' ? r.consecutive_failures : 0,
    lastErrorKey: (r.last_error_key as string | null) ?? null,
    dailyDoneThrough: (r.daily_done_through as string | null) ?? null,
    lastRun: typeof r.last_run === 'object' && r.last_run !== null ? (r.last_run as SyncState['lastRun']) : {},
  };
}

const ITEM_TO_ROW = (accountId: string) => (i: IgMediaItem) => ({
  id: i.id,
  account_id: accountId,
  media_type: i.kind,
  permalink: i.permalink,
  caption: i.caption,
  posted_at: i.postedAt,
  expires_at: i.kind === 'STORY' ? new Date(Date.parse(i.postedAt) + 86_400_000).toISOString() : null,
});

export function supabaseSyncStore(db: SupabaseClient): SyncStore {
  const check = (op: string) => ({ error }: { error: unknown }) => {
    if (error) fail(op);
  };
  return {
    async ownerTimezone() {
      const owner = await db.from('owners').select('user_id').limit(1).maybeSingle();
      if (owner.error) fail('ownerTimezone');
      if (!owner.data) return DEFAULT_PREFS.timezone;
      const p = await db.from('profiles').select('timezone').eq('user_id', (owner.data as Row).user_id).maybeSingle();
      if (p.error) fail('ownerTimezone');
      const tz = (p.data as Row | null)?.timezone;
      return isValidTimeZone(tz) ? tz : DEFAULT_PREFS.timezone;
    },
    async loadStates(ids) {
      const out = new Map(ids.map((id) => [id, emptyState(id)]));
      if (ids.length === 0) return out;
      const { data, error } = await db.from('sync_state').select('*').in('account_id', ids);
      if (error) fail('loadStates');
      for (const r of (data ?? []) as Row[]) out.set(r.account_id as string, rowToState(r));
      return out;
    },
    async claimLease(accountId, leaseId, untilIso, nowIso) {
      check('claimLease')(await db.from('sync_state').upsert({ account_id: accountId }, { onConflict: 'account_id', ignoreDuplicates: true }));
      const { data, error } = await db
        .from('sync_state')
        .update({ lease_id: leaseId, lease_until: untilIso })
        .eq('account_id', accountId)
        .or(`lease_until.is.null,lease_until.lt.${nowIso}`)
        .select('account_id');
      if (error) fail('claimLease');
      return ((data ?? []) as Row[]).length === 1;
    },
    async saveState(accountId, leaseId, p) {
      const row: Row = {
        lease_id: null,
        lease_until: null,
        last_attempt_at: p.lastAttemptAt,
        consecutive_failures: p.consecutiveFailures,
        last_error_key: p.lastErrorKey,
        daily_done_through: p.dailyDoneThrough,
        last_run: p.lastRun,
      };
      if (p.lastSuccessAt) row.last_success_at = p.lastSuccessAt;
      check('saveState')(await db.from('sync_state').update(row).eq('account_id', accountId).eq('lease_id', leaseId));
    },
    async getToken(accountId) {
      const { data, error } = await db.from('account_tokens').select('access_token').eq('account_id', accountId).maybeSingle();
      if (error) fail('getToken');
      const t = (data as Row | null)?.access_token;
      return typeof t === 'string' && t !== '' ? t : null;
    },
    async upsertDaily(accountId, day, v) {
      const row = {
        account_id: accountId,
        day,
        reach: v.reach,
        views: v.views,
        accounts_engaged: v.accountsEngaged,
        total_interactions: v.totalInteractions,
        follows: v.follows,
        unfollows: v.unfollows,
        link_taps: v.linkTaps,
        updated_at: new Date().toISOString(),
      };
      check('upsertDaily')(await db.from('account_daily').upsert(row, { onConflict: 'account_id,day' }));
    },
    async upsertFollowers(accountId, day, followers) {
      // separate upsert: only the followers column is written, metrics from other runs are left alone
      check('upsertFollowers')(await db.from('account_daily').upsert({ account_id: accountId, day, followers }, { onConflict: 'account_id,day' }));
    },
    async upsertMedia(accountId, items) {
      if (items.length === 0) return;
      // last_metrics_at / gone_at are not in the payload, so re-listing never resets them
      check('upsertMedia')(await db.from('media').upsert(items.map(ITEM_TO_ROW(accountId)), { onConflict: 'id' }));
    },
    async mediaForMetrics(accountId, sinceIso) {
      const { data, error } = await db
        .from('media')
        .select('id,posted_at,last_metrics_at')
        .eq('account_id', accountId)
        .neq('media_type', 'STORY')
        .is('gone_at', null)
        .or(`posted_at.gte.${sinceIso},last_metrics_at.is.null`);
      if (error) fail('mediaForMetrics');
      return ((data ?? []) as Row[]).map((r) => ({ id: r.id as string, postedAt: r.posted_at as string, lastMetricsAt: (r.last_metrics_at as string | null) ?? null }));
    },
    async insertMetrics(mediaId, capturedAt, v) {
      const row = {
        media_id: mediaId,
        captured_at: capturedAt,
        reach: v.reach,
        views: v.views,
        likes: v.likes,
        comments: v.comments,
        shares: v.shares,
        saves: v.saves,
        total_interactions: v.totalInteractions,
        replies: v.replies,
        taps_forward: v.tapsForward,
        taps_back: v.tapsBack,
        exits: v.exits,
      };
      check('insertMetrics')(await db.from('media_metrics').upsert(row, { onConflict: 'media_id,captured_at', ignoreDuplicates: true }));
    },
    async markCaptured(mediaIds, atIso) {
      if (mediaIds.length === 0) return;
      check('markCaptured')(await db.from('media').update({ last_metrics_at: atIso }).in('id', mediaIds));
    },
    async markGone(mediaId, atIso) {
      check('markGone')(await db.from('media').update({ gone_at: atIso }).eq('id', mediaId));
    },
    async upsertAudience(accountId, day, kind, data) {
      check('upsertAudience')(await db.from('audience_snapshots').upsert({ account_id: accountId, day, kind, data }, { onConflict: 'account_id,day,kind' }));
    },
    async upsertOnlineFollowers(accountId, day, hourly) {
      check('upsertOnlineFollowers')(await db.from('online_followers').upsert({ account_id: accountId, day, hourly }, { onConflict: 'account_id,day' }));
    },
    async recordRun(run) {
      check('recordRun')(await db.from('sync_runs').insert({ started_at: run.startedAt, finished_at: run.finishedAt, trigger: run.trigger, summary: run.summary }));
    },
  };
}
```

```ts
export function memoryStore(init: MemoryInit = {}) {
  const states = new Map((init.states ?? []).map((s) => [s.accountId, { ...s, leaseId: null as string | null }]));
  const media = new Map((init.media ?? []).map((m) => [m.id, { ...m, kind: 'IMAGE', gone: false }]));

  const followers: { accountId: string; day: string; followers: number }[] = [];

  const audience: { accountId: string; kind: string }[] = [];
```

```ts
// Runs the due jobs for ONE account. Never throws: every failure becomes an outcome + error key, so the tick can move
// on to the next account. Tokens are only passed to the Instagram client, never logged or returned.
import { markNeedsReconnect } from '@/lib/accounts/service';
import type { AccountsStore, StoredAccount } from '@/lib/accounts/types';
import { classifyIgError, type IgData } from '@/lib/instagram/data';
import { InstagramApiError } from '@/lib/instagram/oauth';
import { DEMOGRAPHIC_BREAKDOWNS, type AudienceKind } from '@/lib/instagram/metrics';
import { BACKFILL_DAYS, MEDIA_BACKFILL_MAX, MEDIA_DAILY_UNDER_DAYS, MEDIA_RECENT_MAX, SETTLE_DAYS, pickDueMedia, type JobKind, type SyncState } from '@/lib/sync/schedule';
import type { StatePatch, SyncStore } from '@/lib/sync/store';
import { addDays, dayRangeSec, localDay } from '@/lib/sync/time';

export type SyncErrorKey = 'token_invalid' | 'rate_limited' | 'instagram_unavailable' | 'instagram_error' | 'unexpected';
export type AccountOutcome = 'ok' | 'partial' | 'failed' | 'needs_reconnect';

export interface AccountResult {
  accountId: string;
  outcome: AccountOutcome;
  jobs: JobKind[]; // jobs that completed
  errorKey?: SyncErrorKey;
  appRateLimited?: boolean; // app-wide throttle (code 4): the tick stops starting new accounts
}

export interface RunContext {
  ig: IgData;
  store: SyncStore;
  accounts: AccountsStore;
  account: StoredAccount;
  token: string;
  state: SyncState;
  tz: string;
  now: Date;
  /** ms epoch; jobs stop between API calls once clock() passes it and report "not done" */
  deadline: number;
  clock: () => number;
}

/** Progress that must survive a job failing half-way (e.g. 40 backfill days written, then a 5xx). */
interface Progress {
  dailyDoneThrough: string | null;
}

/** done=false: stopped for the time budget; the job stays due and continues next tick. */
type Job = (c: RunContext, p: Progress) => Promise<{ done: boolean }>;
const DAY_MS = 86_400_000;
const outOfTime = (c: RunContext) => c.clock() >= c.deadline;

/** Account insights day by day: first-connect backfill, missed days, and a re-fetch of the last SETTLE_DAYS (data lags up to 48h). */
const daily: Job = async (c, p) => {
  const today = localDay(c.now, c.tz);
  const yesterday = addDays(today, -1);
  const done = p.dailyDoneThrough;
  const settleFrom = addDays(yesterday, -(SETTLE_DAYS - 1));
  let day = done ? (addDays(done, 1) < settleFrom ? addDays(done, 1) : settleFrom) : addDays(today, -BACKFILL_DAYS);
  const oldest = addDays(today, -30);
  for (; day <= yesterday; day = addDays(day, 1)) {
    if (outOfTime(c)) return { done: false };
    const { since, until } = dayRangeSec(day, c.tz);
    try {
      await c.store.upsertDaily(c.account.id, day, await c.ig.accountDay(c.token, since, until));
    } catch (e) {
      // ponytail: Meta does not document how far back each metric goes; an "other" error on a day older than 30 days is
      // treated as "no data that far back" and skipped so the backfill cannot wedge. Tighten once the runbook confirms.
      if (!(classifyIgError(e) === 'other' && day < oldest)) throw e;
    }
    if (!p.dailyDoneThrough || day > p.dailyDoneThrough) p.dailyDoneThrough = day;
  }
  const { followersCount } = await c.ig.profile(c.token);
  if (followersCount !== null) await c.store.upsertFollowers(c.account.id, today, followersCount);
  return { done: true };
};

/** Live stories: upsert, then one metrics snapshot each. Under 5 viewers Instagram refuses (no_data): skip that story. */
const stories: Job = async (c) => {
  const items = await c.ig.listStories(c.token);
  await c.store.upsertMedia(c.account.id, items);
  const at = c.now.toISOString();
  const captured: string[] = [];
  try {
    for (const s of items) {
      if (outOfTime(c)) return { done: false };
      try {
        await c.store.insertMetrics(s.id, at, await c.ig.storyInsights(c.token, s.id));
        captured.push(s.id);
      } catch (e) {
        const k = classifyIgError(e);
        if (k === 'gone') await c.store.markGone(s.id, at);
        else if (k !== 'no_data') throw e;
      }
    }
  } finally {
    await c.store.markCaptured(captured, at);
  }
  return { done: true };
};

/** Feed + Reels list. First run: up to MEDIA_BACKFILL_MAX posts; afterwards: until posts older than 30 days. */
const mediaList: Job = async (c) => {
  const first = !c.state.lastRun.mediaList;
  const since = new Date(c.now.getTime() - MEDIA_DAILY_UNDER_DAYS * DAY_MS).toISOString();
  const items = first ? await c.ig.listMedia(c.token, MEDIA_BACKFILL_MAX) : await c.ig.listMedia(c.token, MEDIA_RECENT_MAX, since);
  await c.store.upsertMedia(c.account.id, items);
  return { done: true };
};

/** Snapshots for media that are due (pickDueMedia). Deleted media are marked gone; unfinished work stays due. */
const mediaMetrics: Job = async (c) => {
  const since = new Date(c.now.getTime() - MEDIA_DAILY_UNDER_DAYS * DAY_MS).toISOString();
  const due = pickDueMedia(await c.store.mediaForMetrics(c.account.id, since), c.now);
  const at = c.now.toISOString();
  const captured: string[] = [];
  try {
    for (const id of due) {
      if (outOfTime(c)) return { done: false };
      try {
        await c.store.insertMetrics(id, at, await c.ig.feedInsights(c.token, id));
        captured.push(id);
      } catch (e) {
        const k = classifyIgError(e);
        if (k === 'gone') await c.store.markGone(id, at);
        else if (k === 'no_data') captured.push(id); // nothing to record now; try again at the next interval
        else throw e;
      }
    }
  } finally {
    await c.store.markCaptured(captured, at);
  }
  return { done: true };
};

/** Demographics + online followers. Under 100 followers Instagram returns empty data: nothing is written, not an error. */
const audience: Job = async (c) => {
  const today = localDay(c.now, c.tz);
  for (const kind of Object.keys(DEMOGRAPHIC_BREAKDOWNS) as AudienceKind[]) {
    if (outOfTime(c)) return { done: false };
    const data = await c.ig.audience(c.token, kind);
    if (Object.keys(data).length > 0) await c.store.upsertAudience(c.account.id, today, kind, data);
  }
  const { since } = dayRangeSec(addDays(today, -1), c.tz);
  const { since: until } = dayRangeSec(today, c.tz);
  for (const d of await c.ig.onlineFollowers(c.token, since, until)) await c.store.upsertOnlineFollowers(c.account.id, d.day, d.hourly);
  return { done: true };
};

/** Long-lived token refresh (another 60 days). An auth error here flips the account to needs_reconnect like any other. */
const tokenRefresh: Job = async (c) => {
  const t = await c.ig.refresh(c.token);
  await c.accounts.saveToken(c.account.id, t);
  await c.accounts.update(c.account.id, { tokenExpiresAt: t.expiresAt });
  return { done: true };
};

export const JOB_RUNNERS: Record<JobKind, Job> = { stories, daily, mediaList, mediaMetrics, audience, tokenRefresh };

function errorKeyFor(kind: ReturnType<typeof classifyIgError>, e: unknown): SyncErrorKey {
  if (kind === 'rate_limit' || kind === 'app_rate_limit') return 'rate_limited';
  if (kind === 'transient') return 'instagram_unavailable';
  return e instanceof InstagramApiError ? 'instagram_error' : 'unexpected';
}

/**
 * Runs `jobs` in order. auth -> needs_reconnect, stop. rate limit -> stop (back-off). Any other error -> record it and
 * continue with the next job (one broken metric must not starve Stories capture). Returns the result and the state
 * patch to persist.
 */
export async function runAccount(c: RunContext, jobs: JobKind[]): Promise<{ result: AccountResult; patch: StatePatch }> {
  const nowIso = c.now.toISOString();
  const lastRun = { ...c.state.lastRun };
  const progress: Progress = { dailyDoneThrough: c.state.dailyDoneThrough };
  const completed: JobKind[] = [];
  let partial = false;
  let errorKey: SyncErrorKey | undefined;
  let outcome: AccountOutcome = 'ok';
  let appRateLimited = false;

  for (const job of jobs) {
    if (outOfTime(c)) {
      partial = true;
      break;
    }
    try {
      const r = await JOB_RUNNERS[job](c, progress);
      if (!r.done) {
        partial = true;
        break;
      }
      lastRun[job] = nowIso;
      completed.push(job);
    } catch (e) {
      const kind = classifyIgError(e);
      if (kind === 'auth') {
        errorKey = 'token_invalid';
        outcome = 'needs_reconnect';
        await markNeedsReconnect(c.accounts, c.account.igUserId, 'token_invalid').catch(() => {});
        break;
      }
      errorKey = errorKeyFor(kind, e);
      outcome = 'failed';
      if (kind === 'rate_limit' || kind === 'app_rate_limit') {
        appRateLimited = kind === 'app_rate_limit';
        break;
      }
    }
  }
  if (outcome === 'ok' && partial) outcome = 'partial';

  const ok = outcome === 'ok' || outcome === 'partial';
  const patch: StatePatch = {
    lastAttemptAt: nowIso,
    ...(ok ? { lastSuccessAt: nowIso } : {}),
    consecutiveFailures: ok ? 0 : c.state.consecutiveFailures + 1,
    lastErrorKey: ok ? null : (errorKey ?? 'unexpected'),
    dailyDoneThrough: progress.dailyDoneThrough,
    lastRun,
  };
  return { result: { accountId: c.account.id, outcome, jobs: completed, ...(errorKey ? { errorKey } : {}), ...(appRateLimited ? { appRateLimited } : {}) }, patch };
}
```

```ts
// One scheduler tick: pick due work per account (round-robin, oldest attempt first), lease each account, run it within
// the time budget, persist state, record a summary. One account failing (bad token, DB hiccup) never stops the others.
import type { AccountsStore } from '@/lib/accounts/types';
import type { IgData } from '@/lib/instagram/data';
import { runAccount, type AccountOutcome, type SyncErrorKey } from '@/lib/sync/run-account';
import { byOldestAttempt, dueJobs, type JobKind } from '@/lib/sync/schedule';
import type { SyncStore } from '@/lib/sync/store';

/** Route maxDuration is 60s; work stops at 45s so a 10s Instagram timeout plus the state write still fit. */
export const TICK_BUDGET_MS = 45_000;
/** Don't start an account with less than this left: a half-started account only wastes calls. */
export const MIN_ACCOUNT_MS = 5_000;
/** Longer than any invocation can live, so a crashed tick's lease expires well before the next tick. */
export const LEASE_MS = 120_000;

export interface TickDeps {
  store: SyncStore;
  accounts: AccountsStore;
  ig: IgData;
  clock?: () => number;
  newId?: () => string;
}

export interface TickAccount {
  accountId: string;
  outcome: AccountOutcome | 'locked' | 'idle';
  jobs: JobKind[];
  errorKey?: SyncErrorKey;
}

export interface TickSummary {
  trigger: 'cron' | 'manual';
  startedAt: string;
  durationMs: number;
  stoppedEarly: boolean; // time budget or app-wide rate limit left due work for the next tick
  accounts: TickAccount[];
}

export async function runTick(deps: TickDeps, opts: { trigger: 'cron' | 'manual'; budgetMs?: number; accountId?: string }): Promise<TickSummary> {
  const clock = deps.clock ?? Date.now;
  const newId = deps.newId ?? (() => crypto.randomUUID());
  const start = clock();
  const deadline = start + (opts.budgetMs ?? TICK_BUDGET_MS);
  const startedAt = new Date(start).toISOString();
  const manual = opts.trigger === 'manual';
  const out: TickAccount[] = [];
  let stoppedEarly = false;

  const tz = await deps.store.ownerTimezone();
  const active = (await deps.accounts.list()).filter((a) => a.status === 'active' && (!opts.accountId || a.id === opts.accountId));
  const states = await deps.store.loadStates(active.map((a) => a.id));
  const ordered = [...active].sort((a, b) => byOldestAttempt(states.get(a.id)!, states.get(b.id)!));

  for (const account of ordered) {
    if (deadline - clock() < MIN_ACCOUNT_MS) {
      stoppedEarly = true;
      break;
    }
    const now = new Date(clock());
    const state = states.get(account.id)!;
    const jobs = dueJobs({ status: account.status, tokenExpiresAt: account.tokenExpiresAt, state }, now, tz, { manual });
    if (jobs.length === 0) {
      out.push({ accountId: account.id, outcome: state.leaseUntil && Date.parse(state.leaseUntil) > now.getTime() ? 'locked' : 'idle', jobs: [] });
      continue;
    }
    const leaseId = newId();
    try {
      if (!(await deps.store.claimLease(account.id, leaseId, new Date(now.getTime() + LEASE_MS).toISOString(), now.toISOString()))) {
        out.push({ accountId: account.id, outcome: 'locked', jobs: [] });
        continue;
      }
      const token = await deps.store.getToken(account.id);
      if (!token) {
        // connected without a stored token: nothing can be fetched until the owner reconnects
        await deps.accounts.update(account.id, { status: 'needs_reconnect', lastError: 'token_missing' });
        await deps.store.saveState(account.id, leaseId, { lastAttemptAt: now.toISOString(), consecutiveFailures: state.consecutiveFailures + 1, lastErrorKey: 'token_invalid', dailyDoneThrough: state.dailyDoneThrough, lastRun: state.lastRun });
        out.push({ accountId: account.id, outcome: 'needs_reconnect', jobs: [], errorKey: 'token_invalid' });
        continue;
      }
      const { result, patch } = await runAccount({ ig: deps.ig, store: deps.store, accounts: deps.accounts, account, token, state, tz, now, deadline, clock }, jobs);
      await deps.store.saveState(account.id, leaseId, patch);
      out.push({ accountId: account.id, outcome: result.outcome, jobs: result.jobs, ...(result.errorKey ? { errorKey: result.errorKey } : {}) });
      if (result.outcome === 'partial') stoppedEarly = true;
      if (result.appRateLimited) {
        stoppedEarly = true;
        break; // app-wide throttle: every further call would fail too
      }
    } catch {
      // store failure outside runAccount (lease, token read, state write). The lease expires by itself (LEASE_MS).
      out.push({ accountId: account.id, outcome: 'failed', jobs: [], errorKey: 'unexpected' });
    }
  }

  const summary: TickSummary = { trigger: opts.trigger, startedAt, durationMs: clock() - start, stoppedEarly, accounts: out };
  await deps.store.recordRun({ startedAt, finishedAt: new Date(clock()).toISOString(), trigger: opts.trigger, summary }).catch(() => {});
  return summary;
}
```

```ts
import { createHash, timingSafeEqual } from 'node:crypto';

const digest = (s: string) => createHash('sha256').update(s).digest();

/**
 * `Authorization: Bearer <CRON_SECRET>`, compared in constant time (hashing first makes the lengths equal, so neither
 * content nor length leaks through timing). An empty secret never authorizes anything.
 */
export function isCronAuthorized(header: string | null, secret: string): boolean {
  if (!secret || !header?.startsWith('Bearer ')) return false;
  return timingSafeEqual(digest(header.slice('Bearer '.length)), digest(secret));
}
```

```ts
import { EnvError, getServerEnv } from '@/lib/env';
import { isCronAuthorized } from '@/lib/sync/cron-auth';
import { createSyncDeps } from '@/lib/sync/deps';
import { runTick, TICK_BUDGET_MS } from '@/lib/sync/tick';

// Called every 30 minutes by an external scheduler (cron-job.org; pg_cron/pg_net as fallback), never by a browser.
// Answers 202 at once (cron-job.org gives up after ~30s) and does the work in after(), which Vercel keeps alive via
// waitUntil for up to maxDuration. Results land in public.sync_runs, not in the response.
export const maxDuration = 60;

async function handle(request: NextRequest) {
  let deps: ReturnType<typeof createSyncDeps>;
  try {
    const { cronSecret } = getServerEnv();
    // fail closed: no secret configured -> 503 above; wrong or missing header -> 401
    if (!isCronAuthorized(request.headers.get('authorization'), cronSecret)) return NextResponse.json({ error: 'unauthorized' }, { status: 401 });
    deps = createSyncDeps();
  } catch (e) {
    if (e instanceof EnvError) return NextResponse.json({ error: 'not_configured' }, { status: 503 });
    throw e;
  }
  after(async () => {
    try {
      await runTick(deps, { trigger: 'cron', budgetMs: TICK_BUDGET_MS });
    } catch {
      console.error('sync tick failed'); // fixed text: never log error objects (they could carry request details)
    }
  });
  return NextResponse.json({ accepted: true }, { status: 202, headers: { 'cache-control': 'no-store' } });
}

export { handle as GET, handle as POST };
```

```ts
// Runs the same per-account runner as the cron tick, now, for one account. Forces Stories + media list; daily and
// audience still follow their once-a-day rule. Bounded by the page's maxDuration (accounts/page.tsx).
export async function syncNowAction(id: string): Promise<Result> {
  await requireOwner();
  if (typeof id !== 'string' || !UUID.test(id)) return { ok: false, error: 'not_found' };
  try {
    const summary = await runTick(createSyncDeps(), { trigger: 'manual', budgetMs: TICK_BUDGET_MS, accountId: id });
    revalidatePath('/accounts');
    const r = summary.accounts[0];
    if (!r) return { ok: false, error: 'not_active' };
    if (r.outcome === 'locked') return { ok: false, error: 'busy' };
    if (r.outcome === 'failed' || r.outcome === 'needs_reconnect') return { ok: false, error: r.errorKey ?? 'unexpected' };
    return { ok: true };
  } catch {
    return { ok: false, error: 'unexpected' };
  }
}
```
