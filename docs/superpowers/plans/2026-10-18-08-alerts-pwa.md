# Plan 8: Alerts, Web Push & PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After every sync tick, evaluate the five alert rules per account, store each alert once (in-app notification centre with bell + unread badge) and push the new ones to the owner's subscribed devices; make the app an installable PWA with a small hand-written service worker that caches only static assets and an offline page.

**Architecture:** One migration adds `notifications` (owner may read and mark read; inserts only by the admin client) and `push_subscriptions` (owner session subscribes/unsubscribes; the sender reads via the admin client). Rules are pure functions in `lib/alerts/rules.ts` (inputs are plain data + an injected `now`, reusing `lib/analysis/flags.ts`). `runAlerts()` in `lib/alerts/run.ts` is called at the end of `runTick()`: per account in isolation it gathers inputs through an admin `AlertStore`, inserts with `ON CONFLICT (dedupe_key) DO NOTHING RETURNING`, and pushes only the rows that were really inserted, localised server-side in the owner's profile language with the same next-intl catalogs the UI uses. `lib/push/send.ts` wraps `web-push` behind a fake-able transport and prunes 404/410 subscriptions. UI: a bell popover in `AppShell`, a Notifications tab in Settings (explicit "Enable notifications" button, per-type push toggles, thresholds). PWA: `app/manifest.ts`, generated PNG icons, `public/sw.js`, a production-only registration component, an install prompt and a public `/offline` page.

**Tech Stack:** Next.js 16.4 App Router, TypeScript strict, `@supabase/supabase-js` (admin client in the tick, owner session elsewhere), next-intl 4 (`createTranslator` server-side), Radix Popover/Switch/Tabs from `components/ui/`, Vitest 5 + Testing Library + jsdom, Node `vm` for the service-worker test. **New dependencies:** `web-push@3.6.7` (runtime; pre-approved in SPEC §2: VAPID signing + RFC 8291 payload encryption is ~300 lines of crypto we must not hand-roll) and `@types/web-push@3.6.4` (dev, types only: `web-push` ships no TypeScript types; zero runtime bytes).

**Spec:** `docs/SPEC.md` §5 (`notifications`, `push_subscriptions`, `profiles.alert_settings`), §6 ("After the daily and Stories jobs finish, the alert rules (§7c) are evaluated and push notifications sent"), §7 ("Post taking off"), §7c (alert rules, defaults, dedupe, explicit permission, iOS), §8b.3 (i18n), §8b.5 (responsive), §8b.6 (PWA, no authenticated data in the SW cache), §9 (security). Project rules: `CLAUDE.md` (binding). Visual reference: `docs/mockups/app-prototype.html` (header bell).

## Decisions taken in this plan (owner: please confirm the ones marked ⚠)

- ⚠ **Column name `payload`, not `params`.** SPEC §5 names the column `payload jsonb`; it holds ONLY i18n parameters (`{ username, days, pct, ratio, postId }`), never prose. Text is produced at render time from `notifications.kinds.<kind>.title|body`.
- ⚠ **Adjustable in Settings:** per-type push on/off (defaults: all on except "taking off", SPEC §7c), reach-drop threshold (default 20 %, 5–90), taking-off ratio (default 2×, 1.5–10), sync-failing streak (default 2, 1–10). The token-expiry stages (7 d and 2 d) and the 7-day reach-drop cool-down stay constants (`lib/alerts/rules.ts`): nobody tunes them, a constant is one line to change. Stored in the existing `profiles.alert_settings jsonb` (no new column), always read through `parseAlertSettings()` (whitelisted keys, clamped numbers, defaults for anything missing or junk).
- **Dedupe keys (never repeat, cool-downs hold, double-fired ticks are harmless):**
  - `token_expiring:<account>:<expiry date>:<7|2>` — one alert per stage per token; a successful refresh moves the expiry, so a later problem alerts again.
  - `needs_reconnect:<account>:<last success ISO | never>` and `sync_failing:<account>:<last success ISO | never>` — one alert per failure streak (the streak is identified by the last success before it; the next success starts a new identity).
  - `reach_drop:<account>:<window end day>` plus a cool-down read: no new reach-drop alert while one for that account is younger than 7 days.
  - `taking_off:<media id>` — once per post, ever.
  The insert is `upsert(..., { onConflict: 'dedupe_key', ignoreDuplicates: true }).select(...)`, i.e. `INSERT … ON CONFLICT DO NOTHING RETURNING`: only rows really inserted come back, so two overlapping ticks can never push the same alert twice.
- **Rules run for every non-archived account after the account jobs**, from a fresh accounts list and a fresh `sync_state` read (an account flipped to `needs_reconnect` during this tick must alert now). A rule or a query failing for one account is caught and counted; it never fails the tick, other accounts, or the run summary. Alerts get their own small time budget after the sync budget (`ALERT_BUDGET_MS = 10_000`; route `maxDuration` is 60 s, sync stops at 35 s).
- **Push text is localised on the server** in the owner's `profiles.language` with the same `messages/*.json` the UI uses (`createTranslator` from next-intl) — the service worker only displays `{ title, body, url, tag }`. Payload is minimal: no tokens, no ids except the account id inside a same-origin path. Usernames are clipped to 40 characters in push text; the UI truncates with CSS.
- **Push failures are isolated per subscription**; 404/410 from the push service deletes that subscription (admin client); everything else is counted and retried at the next alert. Run summary gets counts only (`alerts: { created, pushed, failed }`) — never endpoints, keys or error objects.
- **No push without VAPID env:** when `NEXT_PUBLIC_VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` are missing, alerts are still created in-app and the Settings card says push is not configured.
- **Subscriptions are stored by the owner session** under an owner-only `for all` RLS policy (subscribe = upsert on `endpoint`, unsubscribe = delete by endpoint). Validation at the boundary: `https:` endpoint ≤ 1024 chars, `p256dh` base64url 80–100 chars, `auth` base64url 16–32 chars, user agent clipped to 512.
- **Notification reads** (bell list = newest 20 + unread count) happen in the `(app)` layout with the owner session. Layouts do not re-render on client navigation, so the badge refreshes on full loads and after every mark-read action (`revalidatePath('/', 'layout')`). ponytail: no polling/realtime; add Supabase Realtime if the owner wants a live badge.
- ⚠ **No "send test notification" button** (it was optional): the runbook triggers a real alert by lowering the taking-off ratio and pressing "Sync now". Add the button when asked.
- **Service worker:** cache name `in2sight-static-v1`; precaches `/offline`, the manifest and the icons; caches on use ONLY same-origin GETs under `/_next/static/`, `/icons/` and `/favicon.ico`; navigations are network-only with `/offline` as the fallback; everything else (pages, RSC, `/api/*`, Supabase) is never touched. `skipWaiting` + `clients.claim` are safe because the cache only holds immutable, content-hashed assets. Registered in production builds only.
- **theme-color follows the theme:** the root layout exports `generateViewport()` with the background colour of the user's theme + mode (`lib/pwa.ts`, a map pinned to `styles/tokens.css` by a test), and `applyPrefsToDocument` updates the meta tag on switch. Media-query variants cannot express our cookie-chosen mode, so one dynamic value replaces them. The manifest (fetched without cookies) uses Ink light.
- **Icons** are generated by `scripts/make-icons.mjs` (Node `zlib` only: a ~60-line PNG writer drawing the brand mark with 4× supersampling) and committed. `sharp` is only present as Next's optional dependency for some platforms, so it is not relied on.
- **Proxy / route policy:** `proxy.ts`'s matcher already excludes `sw.js`, `manifest.webmanifest`, `/offline` and every `.png/.svg/.ico`, so they are reachable without a session; Task 13 adds tests pinning the new paths (`/icons/*.png`, `/apple-touch-icon.png`) instead of changing code.

## Review Focus

1. **Double-fired tick** (scheduler retry, manual "Sync now" during a cron tick): both evaluate the same alerts at the same time → stored once, pushed once → Task 7 "two overlapping runs push each alert once".
2. **Expired subscription** (phone reset, browser data cleared): the push service answers 410 (or 404) → that subscription is deleted, the other devices still get the push, the tick continues → Task 5 "410 and 404 prune that subscription only" and Task 7 "a push failure never fails the run".
3. **Account with no data yet** (just connected, under 100 followers, backfill running): reach is null, not 0 → no reach-drop alert, no NaN in text → Task 3 "no data: no reach-drop alert (null is not 0)".
4. **Push switched off for a type** (default for "taking off"): the in-app notification is still created, nothing is pushed → Task 7 "push off for a type: stored, not pushed".
5. **Service worker and private data:** `/api/*`, `/overview`, RSC requests (`?_rsc=`), cross-origin Supabase calls must never be cached or answered from cache → Task 12 "never caches /api, pages, RSC or cross-origin responses".

Also covered in the owning tasks: permission denied / unsupported browser / iOS not installed (Task 11), 40+ character usernames in push and in the popover (Tasks 4 and 9), junk `alert_settings` JSON (Task 2), hostile subscription bodies (Task 10), push url pointing off-site (Task 12).

- [ ] **Step 3: Write the migration** — `supabase/migrations/20261018000001_alerts.sql`:

```sql
-- Plan 8: alerts (in-app notification centre) and Web Push subscriptions.

-- One row per alert. Written ONLY by the server-side admin client in the sync tick (insert ... on conflict
-- (dedupe_key) do nothing), so an alert never repeats. payload holds i18n parameters only (no prose, no tokens).
create table public.notifications (
  id         bigint generated always as identity primary key,
  account_id uuid references public.accounts (id) on delete cascade,
  kind       text not null check (kind in ('token_expiring', 'needs_reconnect', 'sync_failing', 'reach_drop', 'taking_off')),
  severity   text not null check (severity in ('info', 'warning', 'critical')),
  payload    jsonb not null default '{}'::jsonb,
  dedupe_key text not null unique check (char_length(dedupe_key) <= 200),
  created_at timestamptz not null default now(),
  read_at    timestamptz
);
create index notifications_created_idx on public.notifications (created_at desc);
create index notifications_unread_idx on public.notifications (created_at desc) where read_at is null;
alter table public.notifications enable row level security;
create policy notifications_owner_select on public.notifications
  for select to authenticated
  using (public.is_owner());
-- mark read: the owner session may update rows, and the column grant below limits that to read_at
create policy notifications_owner_update on public.notifications
  for update to authenticated
  using (public.is_owner())
  with check (public.is_owner());
revoke insert, update, delete on public.notifications from anon, authenticated;
grant update (read_at) on public.notifications to authenticated;

-- One row per subscribed browser/device. The owner session subscribes (upsert on endpoint) and unsubscribes
-- (delete by endpoint); the push sender reads them with the admin client and prunes 404/410 endpoints.
create table public.push_subscriptions (
  id         bigint generated always as identity primary key,
  endpoint   text not null unique check (endpoint like 'https://%' and char_length(endpoint) <= 1024),
  keys       jsonb not null,
  user_agent text check (char_length(user_agent) <= 512),
  created_at timestamptz not null default now()
);
alter table public.push_subscriptions enable row level security;
create policy push_subscriptions_owner_all on public.push_subscriptions
  for all to authenticated
  using (public.is_owner())
  with check (public.is_owner());
revoke all on public.push_subscriptions from anon;
```

Why the column grant: RLS decides WHICH rows the owner may update; the grant decides WHICH columns. With `update (read_at)` only, a bug or a hand-made PostgREST call from the owner's browser can mark a notification read but cannot rewrite its kind, payload or dedupe key.

```ts
// Alert settings live in profiles.alert_settings (jsonb). Anything read from there goes through parseAlertSettings:
// unknown keys are dropped, numbers are clamped, junk falls back to the SPEC §7c defaults. Never throws.

export const ALERT_KINDS = ['token_expiring', 'needs_reconnect', 'sync_failing', 'reach_drop', 'taking_off'] as const;
export type AlertKind = (typeof ALERT_KINDS)[number];

export interface AlertSettings {
  push: Record<AlertKind, boolean>;
  reachDropPct: number; // alert when 7-day reach falls by at least this many percent vs the previous 7 days
  takingOffRatio: number; // alert when a post reaches this multiple of the account's median reach
  syncFailures: number; // alert after this many failed sync runs in a row
}

export const DEFAULT_ALERT_SETTINGS: AlertSettings = {
  push: { token_expiring: true, needs_reconnect: true, sync_failing: true, reach_drop: true, taking_off: false },
  reachDropPct: 20,
  takingOffRatio: 2,
  syncFailures: 2,
};

/** [min, max, decimals] per threshold: what the Settings form allows. */
export const LIMITS = {
  reachDropPct: [5, 90, 0],
  takingOffRatio: [1.5, 10, 1],
  syncFailures: [1, 10, 0],
} as const;

type NumKey = keyof typeof LIMITS;

function clampNum(v: unknown, key: NumKey): number {
  const [min, max, decimals] = LIMITS[key];
  const n = typeof v === 'number' ? v : typeof v === 'string' && v.trim() !== '' ? Number(v) : NaN;
  if (!Number.isFinite(n)) return DEFAULT_ALERT_SETTINGS[key];
  const f = 10 ** decimals;
  return Math.min(max, Math.max(min, Math.round(n * f) / f));
}

const obj = (v: unknown): Record<string, unknown> => (v !== null && typeof v === 'object' && !Array.isArray(v) ? (v as Record<string, unknown>) : {});

export function parseAlertSettings(raw: unknown): AlertSettings {
  const r = obj(raw);
  const p = obj(r.push);
  return {
    push: Object.fromEntries(ALERT_KINDS.map((k) => [k, typeof p[k] === 'boolean' ? p[k] : DEFAULT_ALERT_SETTINGS.push[k]])) as Record<AlertKind, boolean>,
    reachDropPct: clampNum(r.reachDropPct, 'reachDropPct'),
    takingOffRatio: clampNum(r.takingOffRatio, 'takingOffRatio'),
    syncFailures: clampNum(r.syncFailures, 'syncFailures'),
  };
}
```

```ts
// Alert rules (SPEC §7c). Pure: every input is plain data, `now` is injected. Each alert carries a dedupe key built so
// it never repeats (the notifications table has a unique index on it) - see the key comments per rule.
import type { AccountStatus } from '@/lib/accounts/types';
import { reachDrop, takingOff } from '@/lib/analysis/flags';
import type { DailyRow, Post } from '@/lib/analysis/types';
import type { AlertKind, AlertSettings } from '@/lib/alerts/settings';
import { localDay } from '@/lib/sync/time';

export const TOKEN_STAGES_DAYS = [7, 2] as const; // "token expiring" fires at 7 days left, and again at 2
export const REACH_DROP_COOLDOWN_DAYS = 7;
export const TAKING_OFF_WITHIN_DAYS = 3; // only fresh posts: enabling alerts must not dump a week of old wins

export type Severity = 'info' | 'warning' | 'critical';

/** i18n parameters only, never prose. */
export interface AlertPayload {
  username: string;
  days?: number;
  runs?: number;
  pct?: number;
  ratio?: number;
  postId?: string;
}

export interface Alert {
  kind: AlertKind;
  accountId: string;
  severity: Severity;
  dedupeKey: string;
  payload: AlertPayload;
}

export interface RuleInput {
  account: { id: string; username: string; status: AccountStatus; tokenExpiresAt: string | null };
  sync: { consecutiveFailures: number; lastSuccessAt: string | null };
  daily: DailyRow[];
  posts: Post[];
  lastReachDropAt: string | null; // created_at of the newest reach_drop notification for this account
  settings: AlertSettings;
  now: Date;
  tz: string;
}

const DAY = 86_400_000;
const round1 = (n: number) => Math.round(n * 10) / 10;

type Rule = (i: RuleInput) => Alert[];

/** Key: token_expiring:<account>:<expiry day>:<stage>. A refresh moves the expiry, so a later problem alerts again. */
const tokenExpiring: Rule = ({ account: a, now }) => {
  const expires = a.tokenExpiresAt ? Date.parse(a.tokenExpiresAt) : NaN;
  if (a.status !== 'active' || Number.isNaN(expires)) return [];
  const left = expires - now.getTime();
  if (left <= 0) return []; // already expired: the sync flips the account to needs_reconnect, which alerts instead
  const stage = left <= TOKEN_STAGES_DAYS[1] * DAY ? TOKEN_STAGES_DAYS[1] : left <= TOKEN_STAGES_DAYS[0] * DAY ? TOKEN_STAGES_DAYS[0] : null;
  if (stage === null) return [];
  return [{ kind: 'token_expiring', accountId: a.id, severity: stage === 2 ? 'critical' : 'warning', dedupeKey: `token_expiring:${a.id}:${new Date(expires).toISOString().slice(0, 10)}:${stage}`, payload: { username: a.username, days: Math.max(1, Math.ceil(left / DAY)) } }];
};

/** Key: needs_reconnect:<account>:<last success>. One alert per broken stretch; a successful sync starts a new one. */
const needsReconnect: Rule = ({ account: a, sync }) =>
  a.status === 'needs_reconnect' ? [{ kind: 'needs_reconnect', accountId: a.id, severity: 'critical', dedupeKey: `needs_reconnect:${a.id}:${sync.lastSuccessAt ?? 'never'}`, payload: { username: a.username } }] : [];

/** Key: sync_failing:<account>:<last success>. Fires once when the streak reaches the threshold, not on every failure after. */
const syncFailing: Rule = ({ account: a, sync, settings }) =>
  a.status === 'active' && sync.consecutiveFailures >= settings.syncFailures
    ? [{ kind: 'sync_failing', accountId: a.id, severity: 'warning', dedupeKey: `sync_failing:${a.id}:${sync.lastSuccessAt ?? 'never'}`, payload: { username: a.username, runs: sync.consecutiveFailures } }]
    : [];

/** Key: reach_drop:<account>:<today>, plus a 7-day cool-down from the last reach_drop alert. No data = no alert. */
const reachDropRule: Rule = ({ account: a, daily, lastReachDropAt, settings, now, tz }) => {
  if (a.status !== 'active') return [];
  if (lastReachDropAt && now.getTime() - Date.parse(lastReachDropAt) < REACH_DROP_COOLDOWN_DAYS * DAY) return [];
  const flag = reachDrop(daily, localDay(now, tz), tz, -settings.reachDropPct / 100);
  if (!flag) return [];
  return [{ kind: 'reach_drop', accountId: a.id, severity: 'warning', dedupeKey: `reach_drop:${a.id}:${localDay(now, tz)}`, payload: { username: a.username, pct: Math.round(-flag.change * 100) } }];
};

/** Key: taking_off:<media id>. Once per post, ever. */
const takingOffRule: Rule = ({ account: a, posts, settings, now }) =>
  a.status === 'archived'
    ? []
    : takingOff(posts, now, TAKING_OFF_WITHIN_DAYS, settings.takingOffRatio).map((f) => ({ kind: 'taking_off' as const, accountId: a.id, severity: 'info' as const, dedupeKey: `taking_off:${f.postId}`, payload: { username: a.username, ratio: round1(f.ratio), postId: f.postId } }));

const RULES: Rule[] = [needsReconnect, tokenExpiring, syncFailing, reachDropRule, takingOffRule];

/** Every alert that currently applies to one account. A rule that throws (bad data) is skipped; the others still run. */
export function evaluateRules(input: RuleInput): Alert[] {
  if (input.account.status === 'archived') return [];
  return RULES.flatMap((rule) => {
    try {
      return rule(input);
    } catch {
      return [];
    }
  });
}
```

```ts
// so a notification reads the same in the app and on the lock screen.
import { createTranslator } from 'next-intl';
import type { AlertPayload } from '@/lib/alerts/rules';
import type { AlertKind } from '@/lib/alerts/settings';
import { formatNumber, type FormatPrefs } from '@/lib/format';
import { deepMerge } from '@/lib/merge';
import { DEFAULT_PREFS, type Locale } from '@/lib/prefs';
import en from '@/messages/en.json';
import zh from '@/messages/zh-CN.json';

/** A translator scoped to `notifications.kinds` (next-intl's useTranslations / createTranslator both fit). */
export type KindTranslator = (key: string, values?: Record<string, string | number>) => string;

export const MAX_NAME = 40;
const clip = (s: string, n: number) => ([...s].length > n ? [...s].slice(0, n - 1).join('') + '…' : s);

export function alertText(kind: AlertKind, p: AlertPayload, t: KindTranslator, prefs: FormatPrefs): { title: string; body: string } {
  const values = {
    username: clip(p.username, MAX_NAME),
    days: p.days ?? 0,
    runs: p.runs ?? 0,
    pct: formatNumber(p.pct ?? null, prefs),
    ratio: formatNumber(p.ratio ?? null, prefs, { maximumFractionDigits: 1 }),
  };
  return { title: t(`${kind}.title`, values), body: t(`${kind}.body`, values) };
}

/** Same-origin path the notification opens. */
export function alertHref(kind: AlertKind, accountId: string | null): string {
  if (!accountId) return '/overview';
  if (kind === 'taking_off') return `/accounts/${accountId}?tab=posts`;
  if (kind === 'reach_drop') return `/accounts/${accountId}`;
  return '/accounts';
}

export interface PushMessage {
  title: string;
  body: string;
  url: string;
  tag: string;
}

const CATALOGS: Record<Locale, typeof en> = { en, 'zh-CN': deepMerge(en, zh) };

/** Server-side: the push text in the owner's language. Nothing sensitive: text, a same-origin path, a grouping tag. */
export function pushMessage(a: { kind: AlertKind; accountId: string | null; payload: AlertPayload }, locale: Locale): PushMessage {
  const tr = createTranslator({ locale, messages: CATALOGS[locale] });
  const t: KindTranslator = (key, values) => tr(`notifications.kinds.${key}` as never, values as never);
  const { title, body } = alertText(a.kind, a.payload, t, { ...DEFAULT_PREFS, locale });
  return { title, body, url: alertHref(a.kind, a.accountId), tag: `${a.kind}:${a.accountId ?? 'all'}` };
}
```

```ts
import 'server-only'; // the VAPID private key must never reach a browser bundle
// Web Push delivery. web-push does the VAPID signing and payload encryption (RFC 8291/8292); this file only fans a
// message out to every subscription, isolates failures per device and prunes subscriptions the push service has dropped.
import webpush from 'web-push';
import type { PushMessage } from '@/lib/alerts/message';

export interface PushSub {
  endpoint: string;
  keys: { p256dh: string; auth: string };
}

/** Sends one payload to one subscription and returns the push service's HTTP status (0 = network error). Never throws. */
export type PushTransport = (sub: PushSub, payload: string) => Promise<number>;

export interface Vapid {
  publicKey: string;
  privateKey: string;
  subject: string;
}

/** null when push is not configured (alerts are then in-app only). */
export function vapidFromEnv(env: Record<string, string | undefined> = process.env): Vapid | null {
  const publicKey = env.NEXT_PUBLIC_VAPID_PUBLIC_KEY?.trim();
  const privateKey = env.VAPID_PRIVATE_KEY?.trim();
  const subject = env.VAPID_SUBJECT?.trim();
  return publicKey && privateKey && subject ? { publicKey, privateKey, subject } : null;
}

export function webPushTransport(vapid: Vapid): PushTransport {
  return async (sub, payload) => {
    try {
      const r = await webpush.sendNotification(sub, payload, { vapidDetails: vapid, TTL: 86_400, urgency: 'normal', timeout: 5_000 });
      return r.statusCode;
    } catch (e) {
      // WebPushError carries the status; never log the error itself (it includes the endpoint)
      const status = (e as { statusCode?: unknown } | null)?.statusCode;
      return typeof status === 'number' ? status : 0;
    }
  };
}

export interface SendResult {
  sent: number;
  failed: number;
  pruned: number;
}

/** 404/410: the subscription is gone for good (unsubscribed, browser data cleared, app uninstalled). */
const GONE = new Set([404, 410]);

export async function sendToAll(subs: PushSub[], msg: PushMessage, transport: PushTransport, prune: (endpoint: string) => Promise<void>): Promise<SendResult> {
  const payload = JSON.stringify(msg);
  const out: SendResult = { sent: 0, failed: 0, pruned: 0 };
  await Promise.all(
    subs.map(async (s) => {
      const status = await transport(s, payload).catch(() => 0);
      if (status >= 200 && status < 300) out.sent++;
      else if (GONE.has(status)) {
        out.pruned++;
        await prune(s.endpoint).catch(() => {}); // a failed prune is retried at the next 410
      } else out.failed++;
    }),
  );
  return out;
}
```

```ts
import type { Alert } from '@/lib/alerts/rules';
import { parseAlertSettings, type AlertSettings } from '@/lib/alerts/settings';

/** takingOff needs the posts of the last 3 days plus the 20 before them; 60 covers busy accounts. */
export const ALERT_POSTS = 60;

export interface AlertStore {
  /** The owner's alert settings and UI language (push text is written in it). */
  context(): Promise<{ settings: AlertSettings; locale: Locale }>;
  daily(accountId: string, fromDay: string): Promise<DailyRow[]>;
  posts(accountId: string): Promise<Post[]>;
  lastReachDropAt(accountId: string): Promise<string | null>;
  /** INSERT … ON CONFLICT (dedupe_key) DO NOTHING RETURNING: only the alerts that were really new come back. */
  insertNew(alerts: Alert[]): Promise<Alert[]>;
  subscriptions(): Promise<PushSub[]>;
  deleteSubscription(endpoint: string): Promise<void>;
}

type Row = Record<string, unknown>;

function fail(op: string): never {
  throw new Error(`alert store: ${op} failed`);
}

const isStr = (v: unknown): v is string => typeof v === 'string' && v !== '';

export function supabaseAlertStore(db: SupabaseClient): AlertStore {

    async context() {
      const owner = await db.from('owners').select('user_id').limit(1).maybeSingle();

    posts: (accountId) => loadPosts(db, accountId, ALERT_POSTS),

      const { data, error } = await db.from('notifications').select('created_at').eq('account_id', accountId).eq('kind', 'reach_drop').order('created_at', { ascending: false }).limit(1).maybeSingle();
      if (error) fail('lastReachDropAt');
      const at = (data as Row | null)?.created_at;
      return isStr(at) ? at : null;

      if (alerts.length === 0) return [];
      const rows = alerts.map((a) => ({ account_id: a.accountId, kind: a.kind, severity: a.severity, payload: a.payload, dedupe_key: a.dedupeKey }));
      const { data, error } = await db.from('notifications').upsert(rows, { onConflict: 'dedupe_key', ignoreDuplicates: true }).select('dedupe_key');
      if (error) fail('insertNew');
      const inserted = new Set(((data ?? []) as Row[]).map((r) => r.dedupe_key));
      return alerts.filter((a) => inserted.has(a.dedupeKey));
    },
    async subscriptions() {
      const { data, error } = await db.from('push_subscriptions').select('endpoint,keys').limit(50);
      if (error) fail('subscriptions');
      return ((data ?? []) as Row[]).flatMap((r) => {
        const k = (r.keys ?? {}) as Row;
        return isStr(r.endpoint) && isStr(k.p256dh) && isStr(k.auth) ? [{ endpoint: r.endpoint, keys: { p256dh: k.p256dh, auth: k.auth } }] : [];
      });
    },
    async deleteSubscription(endpoint) {
      const { error } = await db.from('push_subscriptions').delete().eq('endpoint', endpoint);
      if (error) fail('deleteSubscription');
    },
  };
}
```

```ts
// Runs after the account jobs of every tick (SPEC §6): evaluate the rules per account, store new alerts once, push the
// new ones. Never throws. One account's failure (bad data, DB hiccup) is counted and the others carry on; push failures
// are isolated per device. The summary holds counts only - never endpoints, keys, tokens or error objects.
import type { AccountsStore } from '@/lib/accounts/types';
import { pushMessage } from '@/lib/alerts/message';
import { evaluateRules, type Alert } from '@/lib/alerts/rules';
import type { AlertStore } from '@/lib/alerts/store';
import { sendToAll, type PushTransport } from '@/lib/push/send';
import type { SyncStore } from '@/lib/sync/store';
import { addDays, localDay } from '@/lib/sync/time';

/** Alerts get this long after the sync budget (route maxDuration 60 s, sync stops at 35 s). */
export const ALERT_BUDGET_MS = 10_000;
/** Two 7-day windows + Instagram's up-to-3-day lag, with margin. */
const DAILY_DAYS = 20;

export interface AlertDeps {
  store: AlertStore;
  push: PushTransport | null; // null: VAPID not configured, alerts stay in-app
}

export interface AlertRunSummary {
  created: number;
  pushed: number;
  failed: number; // accounts that could not be evaluated + pushes that failed + a failed insert
}

export interface AlertRunContext {
  accounts: AccountsStore;
  sync: Pick<SyncStore, 'loadStates'>;
  now: Date;
  tz: string;
  deadline: number; // ms epoch
  clock: () => number;
  accountId?: string; // manual "Sync now" for one account: evaluate only that one
}

export async function runAlerts(deps: AlertDeps, c: AlertRunContext): Promise<AlertRunSummary> {
  const out: AlertRunSummary = { created: 0, pushed: 0, failed: 0 };
  try {
    const { settings, locale } = await deps.store.context();
    // fresh reads: an account flipped to needs_reconnect (or a failure streak grown) during this tick must alert now
    const accounts = (await c.accounts.list()).filter((a) => a.status !== 'archived' && (!c.accountId || a.id === c.accountId));
    const states = await c.sync.loadStates(accounts.map((a) => a.id));
    const fromDay = addDays(localDay(c.now, c.tz), -DAILY_DAYS);

    const found: Alert[] = [];
    for (const a of accounts) {
      if (c.clock() >= c.deadline) break;
      try {
        const [daily, posts, lastReachDropAt] = await Promise.all([deps.store.daily(a.id, fromDay), deps.store.posts(a.id), deps.store.lastReachDropAt(a.id)]);
        const s = states.get(a.id);
        found.push(...evaluateRules({ account: a, sync: { consecutiveFailures: s?.consecutiveFailures ?? 0, lastSuccessAt: s?.lastSuccessAt ?? null }, daily, posts, lastReachDropAt, settings, now: c.now, tz: c.tz }));
      } catch {
        out.failed++;
      }
    }

    const fresh = await deps.store.insertNew(found);
    out.created = fresh.length;
    const toPush = fresh.filter((a) => settings.push[a.kind]);
    if (!deps.push || toPush.length === 0) return out;

    let subs = await deps.store.subscriptions();
    for (const a of toPush) {
      if (subs.length === 0 || c.clock() >= c.deadline) break;
      const gone = new Set<string>();
      const r = await sendToAll(subs, pushMessage(a, locale), deps.push, async (endpoint) => {
        gone.add(endpoint);
        await deps.store.deleteSubscription(endpoint);
      });
      out.pushed += r.sent;
      out.failed += r.failed;
      subs = subs.filter((s) => !gone.has(s.endpoint));
    }
  } catch {
    out.failed++;
  }
  return out;
}
```

```ts
// Notification centre reads. OWNER SESSION client only (RLS: owner select). Never throws: the app shell must render
// even when this fails, it then shows an empty bell.
import type { SupabaseClient } from '@supabase/supabase-js';
import type { AlertPayload, Severity } from '@/lib/alerts/rules';
import { ALERT_KINDS, type AlertKind } from '@/lib/alerts/settings';

export const NOTIFICATION_LIMIT = 20;

export interface NotificationItem {
  id: number;
  kind: AlertKind;
  accountId: string | null;
  severity: Severity;
  payload: AlertPayload;
  createdAt: string;
  readAt: string | null;
}

type Row = Record<string, unknown>;
const SEVERITIES: readonly string[] = ['info', 'warning', 'critical'];
const num = (v: unknown) => (typeof v === 'number' && Number.isFinite(v) ? v : undefined);

/** Validates a stored row: unknown kinds are dropped, payload fields are type-checked one by one. */
export function rowToNotification(r: Row): NotificationItem | null {
  if (!(ALERT_KINDS as readonly unknown[]).includes(r.kind) || typeof r.id !== 'number' || typeof r.created_at !== 'string') return null;
  const p = (r.payload !== null && typeof r.payload === 'object' ? r.payload : {}) as Row;
  const payload: AlertPayload = { username: typeof p.username === 'string' ? p.username : '' };
  for (const k of ['days', 'runs', 'pct', 'ratio'] as const) {
    const v = num(p[k]);
    if (v !== undefined) payload[k] = v;
  }
  if (typeof p.postId === 'string') payload.postId = p.postId;
  return {
    id: r.id,
    kind: r.kind as AlertKind,
    accountId: typeof r.account_id === 'string' ? r.account_id : null,
    severity: SEVERITIES.includes(r.severity as string) ? (r.severity as Severity) : 'info',
    payload,
    createdAt: r.created_at,
    readAt: typeof r.read_at === 'string' ? r.read_at : null,
  };
}

/** Newest 20 + the unread count (a head-only count query, no rows transferred). */
export async function loadNotifications(db: SupabaseClient): Promise<{ items: NotificationItem[]; unread: number }> {
  try {
    const [list, count] = await Promise.all([
      db.from('notifications').select('id,kind,account_id,severity,payload,created_at,read_at').order('created_at', { ascending: false }).limit(NOTIFICATION_LIMIT),
      db.from('notifications').select('id', { count: 'exact', head: true }).is('read_at', null),
    ]);
    if (list.error || count.error) return { items: [], unread: 0 };
    return { items: ((list.data ?? []) as Row[]).map(rowToNotification).filter((n): n is NotificationItem => n !== null), unread: count.count ?? 0 };
  } catch {
    return { items: [], unread: 0 };
  }
}
```

```ts
'use server';

// Mark read. OWNER-SESSION client: RLS (notifications_owner_update) plus the column grant (read_at only) apply to
// every write. Never the admin client here.
import { revalidatePath } from 'next/cache';
import { requireOwner } from '@/lib/auth/require-owner';
import { createServerSupabase } from '@/lib/supabase/server';

export type NotificationResult = { ok: true } | { ok: false; error: 'not_found' | 'unexpected' };

async function markRead(id?: number): Promise<NotificationResult> {
  try {
    const db = await createServerSupabase();
    let q = db.from('notifications').update({ read_at: new Date().toISOString() }).is('read_at', null);
    if (id !== undefined) q = q.eq('id', id);
    const { error } = await q;
    if (error) return { ok: false, error: 'unexpected' };
    revalidatePath('/', 'layout'); // the bell lives in the (app) layout
    return { ok: true };
  } catch {
    return { ok: false, error: 'unexpected' };
  }
}

// Server actions are public endpoints: authorize first (outside try/catch: it redirects by throwing), then validate.
export async function markReadAction(id: number): Promise<NotificationResult> {
  await requireOwner();
  if (typeof id !== 'number' || !Number.isSafeInteger(id) || id <= 0) return { ok: false, error: 'not_found' };
  return markRead(id);
}

export async function markAllReadAction(): Promise<NotificationResult> {
  await requireOwner();
  return markRead();
}
```

```ts
// Boundary validation for a browser's PushSubscription.toJSON() before it is stored. Anything off-shape is refused.

export interface SubscriptionInput {
  endpoint: string;
  keys: { p256dh: string; auth: string };
}

const B64URL = /^[A-Za-z0-9_-]+={0,2}$/;
const MAX_ENDPOINT = 1024;

/** An https URL without credentials, at most 1024 characters (the DB check matches). */
export function parseEndpoint(v: unknown): string | null {
  if (typeof v !== 'string' || v.length > MAX_ENDPOINT) return null;
  try {
    const u = new URL(v);
    return u.protocol === 'https:' && !u.username && !u.password && u.hostname !== '' ? v : null;
  } catch {
    return null;
  }
}

const key = (v: unknown, min: number, max: number) => (typeof v === 'string' && B64URL.test(v) && v.length >= min && v.length <= max ? v : null);

/** p256dh = 65-byte P-256 public key (87 base64url chars), auth = 16-byte secret (22 chars); a little slack for padding. */
export function parseSubscription(raw: unknown): SubscriptionInput | null {
  if (raw === null || typeof raw !== 'object') return null;
  const r = raw as Record<string, unknown>;
  const endpoint = parseEndpoint(r.endpoint);
  const k = (r.keys ?? {}) as Record<string, unknown>;
  const p256dh = key(k.p256dh, 80, 100);
  const auth = key(k.auth, 16, 32);
  return endpoint && p256dh && auth ? { endpoint, keys: { p256dh, auth } } : null;
}

export const clipUserAgent = (v: unknown): string | null => (typeof v === 'string' && v.trim() !== '' ? v.slice(0, 512) : null);

/** The VAPID public key (base64url) as the bytes pushManager.subscribe wants for applicationServerKey. */
export function vapidKeyBytes(key: string): Uint8Array<ArrayBuffer> {
  const b64 = (key + '='.repeat((4 - (key.length % 4)) % 4)).replace(/-/g, '+').replace(/_/g, '/');
  return Uint8Array.from(atob(b64), (c) => c.charCodeAt(0));
}
```

```ts
// Push subscriptions and alert settings. OWNER-SESSION client: RLS (push_subscriptions_owner_all, profiles_owner_all)
// applies to every write. Never the admin client here. Errors are keys, never Supabase text.
export type PushResult = { ok: true } | { ok: false; error: 'invalid' | 'unexpected' };

export async function saveSubscriptionAction(subscription: unknown, userAgent: unknown): Promise<PushResult> {
  await requireOwner();
  const s = parseSubscription(subscription);
  if (!s) return { ok: false, error: 'invalid' };
  try {
    const db = await createServerSupabase();
    const { error } = await db.from('push_subscriptions').upsert({ endpoint: s.endpoint, keys: s.keys, user_agent: clipUserAgent(userAgent) }, { onConflict: 'endpoint' });
    return error ? { ok: false, error: 'unexpected' } : { ok: true };
  } catch {
    return { ok: false, error: 'unexpected' };
  }
}

export async function deleteSubscriptionAction(endpoint: unknown): Promise<PushResult> {
  await requireOwner();
  const e = parseEndpoint(endpoint);
  if (!e) return { ok: false, error: 'invalid' };
  try {
    const db = await createServerSupabase();
    const { error } = await db.from('push_subscriptions').delete().eq('endpoint', e);
    return error ? { ok: false, error: 'unexpected' } : { ok: true };
  } catch {
    return { ok: false, error: 'unexpected' };
  }
}

/** Saves the normalised settings (unknown keys dropped, thresholds clamped) and returns what was stored. */
export async function saveAlertSettingsAction(raw: unknown): Promise<{ ok: true; settings: AlertSettings } | { ok: false; error: 'unexpected' }> {
  const { userId } = await requireOwner();
  const settings = parseAlertSettings(raw);
  try {
    const db = await createServerSupabase();
    const { error } = await db.from('profiles').upsert({ user_id: userId, alert_settings: settings, updated_at: new Date().toISOString() });
    if (error) return { ok: false, error: 'unexpected' };
    revalidatePath('/settings');
    return { ok: true, settings };
  } catch {
    return { ok: false, error: 'unexpected' };
  }
}
```

```tsx
'use client';

import { useEffect, useState, useTransition } from 'react';
import { useTranslations } from 'next-intl';
import { Badge } from '@/components/ui/badge';
import { Button } from '@/components/ui/button';
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from '@/components/ui/card';
import { vapidKeyBytes } from '@/lib/push/subscription';

type Result = { ok: boolean };
type Status = 'checking' | 'unsupported' | 'ios-install' | 'not-configured' | 'denied' | 'off' | 'on';

export interface NotificationsCardProps {
  vapidPublicKey: string | null;
  save: (subscription: unknown, userAgent: string) => Promise<Result>;
  remove: (endpoint: string) => Promise<Result>;
}

const isIos = () => /iPad|iPhone|iPod/.test(navigator.userAgent) || (navigator.platform === 'MacIntel' && navigator.maxTouchPoints > 1);
// a feature check (is this the installed app?), not layout: runs in an effect only
const isStandalone = () => window.matchMedia?.('(display-mode: standalone)').matches === true || (navigator as Navigator & { standalone?: boolean }).standalone === true;

export function NotificationsCard({ vapidPublicKey, save, remove }: NotificationsCardProps) {
  const t = useTranslations('settings.notifications');
  const [status, setStatus] = useState<Status>('checking');
  const [error, setError] = useState(false);
  const [pending, start] = useTransition();

  useEffect(() => {
    let alive = true;
    const set = (s: Status) => alive && setStatus(s);
    (async () => {
      if (!('serviceWorker' in navigator) || !('PushManager' in window) || !('Notification' in window)) return set(isIos() && !isStandalone() ? 'ios-install' : 'unsupported');
      if (!vapidPublicKey) return set('not-configured');
      if (Notification.permission === 'denied') return set('denied');
      const reg = await navigator.serviceWorker.getRegistration();
      set((await reg?.pushManager.getSubscription()) ? 'on' : 'off');
    })().catch(() => set('off'));
    return () => {
      alive = false;
    };
  }, [vapidPublicKey]);

  // permission is requested ONLY here, from the explicit button (SPEC §7c)
  const enable = () =>
    start(async () => {
      setError(false);
      try {
        const permission = await Notification.requestPermission();
        if (permission !== 'granted') return setStatus(permission === 'denied' ? 'denied' : 'off');
        if (!(await navigator.serviceWorker.getRegistration())) await navigator.serviceWorker.register('/sw.js');
        const reg = await navigator.serviceWorker.ready;
        const sub = await reg.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey: vapidKeyBytes(vapidPublicKey!) });
        const r = await save(sub.toJSON(), navigator.userAgent);
        if (!r.ok) {
          await sub.unsubscribe().catch(() => false); // not stored: don't leave a subscription nobody sends to
          return setError(true);
        }
        setStatus('on');
      } catch {
        setError(true);
      }
    });

  const disable = () =>
    start(async () => {
      setError(false);
      try {
        const sub = await (await navigator.serviceWorker.getRegistration())?.pushManager.getSubscription();
        if (sub) {
          await remove(sub.endpoint);
          await sub.unsubscribe();
        }
        setStatus('off');
      } catch {
        setError(true);
      }
    });

  const note = (key: 'checking' | 'unsupported' | 'iosInstall' | 'notConfigured' | 'denied') => <p className="text-sm text-muted-foreground">{t(key)}</p>;

  return (
    <Card>
      <CardHeader>
        <CardTitle className="flex flex-wrap items-center gap-2">
          {t('pushTitle')}
          {status === 'on' ? <Badge variant="secondary">{t('on')}</Badge> : null}
        </CardTitle>
        <CardDescription>{t('pushDescription')}</CardDescription>
      </CardHeader>
      <CardContent className="flex flex-col gap-[var(--gp)]">
        {status === 'checking' ? note('checking') : null}
        {status === 'unsupported' ? note('unsupported') : null}
        {status === 'ios-install' ? note('iosInstall') : null}
        {status === 'not-configured' ? note('notConfigured') : null}
        {status === 'denied' ? note('denied') : null}
        {status === 'off' ? (
          <div className="flex flex-col items-start gap-1.5">
            <Button onClick={enable} disabled={pending}>
              {t('enable')}
            </Button>
            <p className="text-xs text-muted-foreground">{t('enableHint')}</p>
          </div>
        ) : null}
        {status === 'on' ? (
          <Button variant="outline" className="self-start" onClick={disable} disabled={pending}>
            {t('disable')}
          </Button>
        ) : null}
        {error ? (
          <p role="alert" className="text-sm text-destructive">
            {t('error')}
          </p>
        ) : null}
      </CardContent>
    </Card>
  );
}
```

```ts
// public/sw.js runs in a fake service-worker global (node:vm): event handlers, caches, fetch and clients are fakes.
import { readFileSync } from 'node:fs';
import { join } from 'node:path';
import { runInNewContext } from 'node:vm';
import { describe, expect, it, vi } from 'vitest';

const SRC = readFileSync(join(process.cwd(), 'public/sw.js'), 'utf8');
const ORIGIN = 'https://app.test';
type Handler = (e: Record<string, unknown>) => void;
type Req = { url: string; method: string; mode: string };

const basic = (body: string) => Object.defineProperty(new Response(body), 'type', { value: 'basic' }); // like a same-origin fetch

function load(o: { offline?: boolean } = {}) {
  const handlers: Record<string, Handler> = {};
  const store = new Map<string, Map<string, Response>>();
  const key = (r: string | Req) => (typeof r === 'string' ? new URL(r, ORIGIN).href : r.url);
  const caches = {
    open: vi.fn(async (name: string) => {
      if (!store.has(name)) store.set(name, new Map());
      const m = store.get(name)!;
      return { addAll: async (urls: string[]) => urls.forEach((u) => m.set(key(u), basic(`cached ${u}`))), put: async (r: Req, res: Response) => void m.set(key(r), res) };
    }),
    match: async (r: string | Req) => [...store.values()].find((m) => m.has(key(r)))?.get(key(r)),
    keys: async () => [...store.keys()],
    delete: vi.fn(async (k: string) => store.delete(k)),
  };
  const fetch = vi.fn(async (r: Req) => (o.offline ? Promise.reject(new TypeError('Failed to fetch')) : basic(`network ${r.url}`)));
  const self = {
    addEventListener: (t: string, fn: Handler) => void (handlers[t] = fn),
    location: { origin: ORIGIN },
    skipWaiting: vi.fn(async () => {}),
    clients: { claim: vi.fn(async () => {}), matchAll: vi.fn(async () => [] as { url: string; focus: () => void }[]), openWindow: vi.fn(async () => null) },
    registration: { showNotification: vi.fn(async () => {}) },
  };
  runInNewContext(SRC, { self, caches, fetch, Response, URL, Promise, console });
  const fire = (type: string, init: Record<string, unknown> = {}) => {
    const waits: Promise<unknown>[] = [];
    let responded: Promise<Response> | undefined;
    handlers[type]({ ...init, waitUntil: (p: Promise<unknown>) => void waits.push(p), respondWith: (p: Promise<Response>) => void (responded = p) });
    return { responded, settled: () => Promise.all(waits) };
  };
  return { fire, store, caches, fetch, self };
}

    expect([...sw.store.keys()]).toEqual(['in2sight-static-v1']);
    expect(sw.self.skipWaiting).toHaveBeenCalled();
  });

  it('activate drops older in2sight caches only, then claims open pages', async () => {
    const sw = load();
    for (const k of ['in2sight-static-v0', 'in2sight-static-v1', 'someone-else']) sw.store.set(k, new Map());
    await sw.fire('activate').settled();
    expect([...sw.store.keys()].sort()).toEqual(['in2sight-static-v1', 'someone-else']);
    expect(sw.self.clients.claim).toHaveBeenCalled();
  });

  it('never caches /api, pages, RSC or cross-origin responses', async () => {
    const sw = load();
```

```js
// in2sight service worker. Hand-written, no build step (SPEC §8b.6).
// Caches ONLY static, content-hashed assets, the icons and the public offline page. Pages, RSC payloads, /api/* and
// every cross-origin request (Supabase, Instagram) are never cached and never answered from cache: on a shared device
// nothing private may outlive the session. Also shows Web Push notifications (SPEC §7c).
// Bump VERSION to drop the old cache (e.g. when the offline page changes).
const VERSION = 'v1';
const CACHE = `in2sight-static-${VERSION}`;
const OFFLINE = '/offline';
const PRECACHE = [OFFLINE, '/manifest.webmanifest', '/icons/icon-192.png', '/icons/icon-512.png'];
const STATIC = [/^\/_next\/static\//, /^\/icons\//, /^\/favicon\.ico$/];

self.addEventListener('install', (event) => {
  // the cache only holds immutable assets, so the new worker can take over at once
  event.waitUntil(
    caches
      .open(CACHE)
      .then((cache) => cache.addAll(PRECACHE))
      .then(() => self.skipWaiting()),
  );
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches
      .keys()
      .then((keys) => Promise.all(keys.filter((k) => k.startsWith('in2sight-') && k !== CACHE).map((k) => caches.delete(k))))
      .then(() => self.clients.claim()),
  );
});

self.addEventListener('fetch', (event) => {
  const req = event.request;
  if (req.method !== 'GET') return;
  const url = new URL(req.url);
  if (url.origin !== self.location.origin) return; // Supabase, Instagram, fonts: straight to the network

  if (req.mode === 'navigate') {
    // pages are always fetched live; only when the network is down do we show the public offline page
    event.respondWith(fetch(req).catch(() => caches.match(OFFLINE).then((hit) => hit || Response.error())));
    return;
  }
  if (!STATIC.some((re) => re.test(url.pathname))) return; // RSC, /api, data: network only, never cached

  event.respondWith(
    caches.match(req).then(
      (hit) =>
        hit ||
        fetch(req).then((res) => {
          if (res.ok && res.type === 'basic') {
            const copy = res.clone();
            event.waitUntil(caches.open(CACHE).then((cache) => cache.put(req, copy)));
          }
          return res;
        }),
    ),
  );
});

/** Only same-origin paths may be opened from a notification. */
const safePath = (u) => (typeof u === 'string' && u.startsWith('/') && !u.startsWith('//') && !u.includes('\\') ? u : '/overview');
const text = (v, max) => (typeof v === 'string' ? v.slice(0, max) : '');

self.addEventListener('push', (event) => {
  let data = {};
  try {
    data = event.data ? event.data.json() : {};
  } catch {
    data = {};
  }
  const title = text(data.title, 120) || 'in2sight';
  event.waitUntil(
    self.registration.showNotification(title, {
      body: text(data.body, 300),
      icon: '/icons/icon-192.png',
      badge: '/icons/icon-192.png',
      tag: text(data.tag, 100) || undefined,
      data: { url: safePath(data.url) },
    }),
  );
});

self.addEventListener('notificationclick', (event) => {
  event.notification.close();
  const target = new URL(safePath(event.notification.data && event.notification.data.url), self.location.origin).href;
  event.waitUntil(
    self.clients.matchAll({ type: 'window', includeUncontrolled: true }).then((wins) => {
      const open = wins.find((w) => w.url === target);
      return open ? open.focus() : self.clients.openWindow(target);
    }),
  );
});
```

```js
// Generates the PWA icons in public/icons/ from the brand mark (the conic-gradient tile in components/shared/AppShell.tsx
// with a white lens), using only Node's zlib: no image library. Run once and commit the PNGs:
//   node scripts/make-icons.mjs
// Colours = Ink light --chart-1 / --chart-5 / --chart-4 from styles/tokens.css (tests/pwa.test.ts keeps them in sync).
import { mkdirSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';
import { crc32, deflateSync } from 'node:zlib';

const STOPS = ['#4F46E5', '#EC4899', '#F59E0B', '#4F46E5'].map((h) => [1, 3, 5].map((i) => parseInt(h.slice(i, i + 2), 16)));
const SS = 4; // 4×4 supersampling for smooth edges

/** Conic gradient from 210° (clockwise from 12 o'clock), like the CSS in AppShell. */
function gradient(dx, dy) {
  const deg = ((Math.atan2(dx, -dy) * 180) / Math.PI - 210 + 720) % 360;
  const t = (deg / 360) * (STOPS.length - 1);
  const i = Math.min(Math.floor(t), STOPS.length - 2);
  const f = t - i;
  return STOPS[i].map((c, k) => c + (STOPS[i + 1][k] - c) * f);
}

/** RGBA at a point in unit space (0..1). rounded: transparent corners (radius 22%); else full bleed (maskable / Apple). */
function sample(x, y, rounded) {
  const r = 0.22;
  if (rounded) {
    const cx = Math.min(Math.max(x, r), 1 - r);
    const cy = Math.min(Math.max(y, r), 1 - r);
    if ((x - cx) ** 2 + (y - cy) ** 2 > r * r) return [0, 0, 0, 0];
  }
  const dx = x - 0.5;
  const dy = y - 0.5;
  const d = Math.hypot(dx, dy);
  // the mark sits inside the 80% maskable safe zone: a ring and a dot
  if ((d > 0.17 && d < 0.25) || d < 0.075) return [255, 255, 255, 255];
  return [...gradient(dx, dy), 255];
}

function png(size, rounded) {
  const raw = Buffer.alloc((size * 4 + 1) * size);
  for (let y = 0; y < size; y++) {
    raw[y * (size * 4 + 1)] = 0; // filter: none
    for (let x = 0; x < size; x++) {
      const acc = [0, 0, 0, 0];
      for (let sy = 0; sy < SS; sy++)
        for (let sx = 0; sx < SS; sx++) {
          const p = sample((x + (sx + 0.5) / SS) / size, (y + (sy + 0.5) / SS) / size, rounded);
          for (let k = 0; k < 3; k++) acc[k] += p[k] * p[3]; // premultiply so transparent samples don't darken edges
          acc[3] += p[3];
        }
      const o = y * (size * 4 + 1) + 1 + x * 4;
      for (let k = 0; k < 3; k++) raw[o + k] = acc[3] ? Math.round(acc[k] / acc[3]) : 0;
      raw[o + 3] = Math.round(acc[3] / (SS * SS));
    }
  }
  const chunk = (type, data) => {
    const len = Buffer.alloc(4);
    len.writeUInt32BE(data.length);
    const td = Buffer.concat([Buffer.from(type, 'ascii'), data]);
    const crc = Buffer.alloc(4);
    crc.writeUInt32BE(crc32(td));
    return Buffer.concat([len, td, crc]);
  };
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(size, 0);
  ihdr.writeUInt32BE(size, 4);
  ihdr.set([8, 6, 0, 0, 0], 8); // 8-bit RGBA, no interlace
  return Buffer.concat([Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]), chunk('IHDR', ihdr), chunk('IDAT', deflateSync(raw, { level: 9 })), chunk('IEND', Buffer.alloc(0))]);
}

const out = join(process.cwd(), 'public/icons');
mkdirSync(out, { recursive: true });
for (const [name, size, rounded] of [
  ['icon-192.png', 192, true],
  ['icon-512.png', 512, true],
  ['maskable-512.png', 512, false],
  ['apple-touch-icon.png', 180, false], // iOS paints transparency black: full bleed
]) {
  writeFileSync(join(out, name), png(size, rounded));
  console.log(`public/icons/${name}`);
}
```
