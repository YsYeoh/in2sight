# Plan 9: Exports (Excel + PDF reports) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner downloads an Excel workbook (Summary, Daily, Posts + tags, Stories, Audience, Tags) or an A4 PDF report (chosen sections, title, note) for one account, a group, or all accounts over 7/30/90 days, from an Export dialog on the Overview and on Account detail.

**Architecture:** Both exports start in an owner-session route handler (`assertOwner`), validate the query string by allow-list (`lib/export/params.ts`), resolve the scope against the live accounts, and read everything with the OWNER SESSION client through the existing dashboard readers (`lib/export/read.ts`, RLS applies, no admin client anywhere in this plan). Excel: a pure `buildWorkbook()` turns that data into six sheets of typed cells (numbers as numbers, real date cells in the owner's date format, empty cells for missing values, formula-injection guard on all user/Meta text), and `write-excel-file` writes the `.xlsx`. PDF: a pure `buildReport()` turns the same data into a small serialisable `ReportModel`; the PDF route launches headless Chromium (`puppeteer-core` + `@sparticuz/chromium`, behind an injectable `launch` seam), opens the app's own `/report/print` page (an empty, data-less shell exempt from the session proxy), hands it the model through `page.evaluateOnNewDocument` (DevTools protocol, never a URL), waits for `[data-report-ready]` and fonts, prints A4, and always closes the browser. The same `ReportDocument` component renders the owner-session preview `/report?…`, which needs no Chromium, so the layout can be checked on any dev machine.

**Tech Stack:** Next.js 16.4 App Router (route handlers, `maxDuration`), TypeScript strict, `@supabase/supabase-js` (owner session only), next-intl 4 (`createTranslator` server-side for sheet headers), Recharts 3 (via the existing `SeriesChart`), Vitest 5 + Testing Library + jsdom. **New dependencies (exact pins, all ≥ 2 weeks old on 2026-10-15):**
- `write-excel-file@4.1.1` (runtime; pre-approved in SPEC §2; 1.8 MB unpacked, one dependency `fflate`; NOT `xlsx`). API checked in the installed package: `import writeXlsxFile from 'write-excel-file/node'`, `writeXlsxFile(sheets).toBuffer()`; cells `{ value, type: String|Number|Date, format }`, `stickyRowsCount`, `columns: [{ width }]`; dates become Excel serials from the Date's UTC time; sheet names are validated (throws on `[]/\:*?`, > 31 chars); invalid XML characters are stripped; text is never written as a formula unless `type: 'Formula'`.
- `puppeteer-core@25.11.0` (runtime; pre-approved; ships no browser). Its pinned browser is Chrome 153.0.8010.36, matching the Chromium build below (25.12.0 already expects Chrome 154).

## Decisions taken in this plan (owner: please confirm the ones marked ⚠)

- ⚠ **No signed token: the report data is handed to the headless page over the DevTools protocol.** SPEC §7d says the PDF route renders the report page "via a short-lived signed token". Every token design needs the token-holding page to read the data itself, i.e. a cookie-less page with the admin (service-role) client, or a URL carrying the data (Vercel caps URLs at 14 KB). Instead, the PDF route (owner session, RLS) builds the `ReportModel` itself and injects it with `page.evaluateOnNewDocument((m) => { window.__IN2SIGHT_REPORT__ = m }, model)`; `/report/print` is an empty shell that renders only what was injected into its own window. That page needs no secret and no data access: opened by anyone, it shows "Preparing the report…" and nothing else, and no URL or link can put data into it. Result: no admin client, no new secret path, nothing to forge or replay. `REPORT_SIGNING_SECRET` becomes unused (left optional in `.env.example`/`check-env`, marked unused in the runbook). If the owner wants the token anyway, it would only gate an empty shell.
- **`/report/print` is the one new exact-path exemption** in `lib/auth/route-policy.ts` (`/^\/report\/print$/`, next to the cron/Meta endpoints). Everything else (`/report`, `/api/export/xlsx`, `/api/export/pdf`) needs the owner session like any page; the export routes use `assertOwner` and answer 401 JSON (no redirect).
- **Prefs travel as the normal prefs cookie.** Puppeteer sets the (non-secret) `in2sight_prefs` cookie for the app origin with the owner's prefs and `mode: 'light'`, so the root layout renders the right language, date/number formats and theme, always light (SPEC §7d). The owner preview `/report` forces light the same way through a `ForceLight` effect.
- **SSRF guard:** the browser only ever navigates to `new URL('/report/print', NEXT_PUBLIC_APP_URL)` (origin must be `https://…` or `http://localhost[:port]`, else `not_configured`), and request interception aborts every request whose origin is not the app origin. No user input reaches a URL.
- **Windows:** Excel and Summary windows. Raw sheets (Daily, Posts, Stories, Tags) cover the last `period` days including today (`exportWindow`). KPI columns use the dashboard's own windows (`summarize`: the current window ends on the latest day with reach data), and print their own From/To columns, so the numbers match the Overview.
- **Formula injection:** text cells from users or Meta (captions, usernames, display/group/tag/city names) that start with `= + - @ TAB CR` (and the full-width `＝ ＋ － ＠`) get a leading apostrophe. Visible on purpose: it survives copy/paste and re-saving as CSV, which is where the injection actually fires; an invisible zero-width prefix would not survive and would silently break lookups. Numbers and dates are never strings, so they are never prefixed.
- **Missing values are empty cells, never 0** (Meta returns nothing under 100 followers or 5 story viewers; a 0 would read as "measured: zero").
- **Excel number formats:** counts `#,##0`, averages `#,##0.0`, ratios `0.0%`; dates from the owner's date format (`YYYY-MM-DD`→`yyyy-mm-dd`, `DD/MM/YYYY`→`dd/mm/yyyy`, `MM/DD/YYYY`→`mm/dd/yyyy`, `D MMM YYYY`→`d mmm yyyy`, zh-CN `yyyy"年"m"月"d"日"`), plus ` hh:mm` / ` h:mm AM/PM`. Thousands/decimal separators follow the viewer's Excel locale (an Excel format code cannot force them); instants are converted to the owner's wall clock first (`wallClock` in `lib/format.ts`) because Excel has no timezones.
- **Row limits** come from the readers, not new caps: ≤ 500 posts, ≤ 200 daily rows, ≤ 200 stories and ≤ 45 rows per audience breakdown per account (3–4 accounts → a few thousand rows at most; Review Focus 3 times 500 posts).
- **File names:** `in2sight-<@username | group | all>-<today>.xlsx|pdf`, sent as RFC 6266 `filename="<ascii>"` + RFC 5987 `filename*=UTF-8''<exact name>`; slashes, quotes, controls and Windows-reserved characters become `-`. The dialog downloads with `fetch` → blob, re-cleaning the name from the header.
- **Report sections** (SPEC §7d): KPIs + deltas, reach/views trend, top posts (top 10 by reach in the window), format comparison, tag performance, best time (followers-online and post-performance grids for the scope), audience (per account, top 8), Stories summary (per account), flags (per account). The globe is excluded. Title ≤ 120 code points (empty = translated default), note ≤ 1,000 code points, both rejected (not cut) when longer; control and bidi-override characters are rejected.
- **Charts print without animation:** `SeriesChart` gets an `animate` prop (default unchanged); the report passes `animate={false}`; the print stylesheet also disables CSS animations/transitions.
- **PDF guards:** `maxDuration = 60`; Chromium launch with `@sparticuz/chromium` args, `headless: 'shell'`, A4 viewport; `goto` 20 s, ready-selector 15 s, `pdf` 20 s, everything inside one 45 s budget; the browser is closed in `finally` (SIGKILL if `close()` fails); failures answer `{ error: 'pdf_failed' }` 502 with a fixed log line, never an error object. `CHROMIUM_PATH` (optional env) points at a local Chrome for trying the PDF route off-Vercel.
- **Memory:** Chromium needs ~1 GB; Vercel's default function memory (2 GB on current plans) is enough. The runbook says where to check.

## Review Focus

1. **Hostile account/group/tag names and captions** (emoji, CJK, `/`, quotes, a leading `=`): the download name stays one header line with an ASCII fallback and the exact UTF-8 name; cells show the text with an apostrophe guard and are never formulas → Task 1 "hostile names: ASCII fallback + exact UTF-8 filename*…", Task 5 "Posts: formula-like captions and tag names are neutralised…" and "opens as a zip … text never stored as a formula".
2. **Account with no data yet** (just connected, under 100 followers): every sheet is still valid with empty cells (not zeros), the totals row ignores it, and the report says "No data" → Task 5 "Summary: … EMPTY cells (not 0)…" and "no accounts at all: six sheets…", Task 7 "an account without data…".
3. **500 posts on one account** (the backfill maximum): every post gets a row and the file is written in seconds → Task 5 "500 posts on one account".
4. **Someone opens `/report/print` directly, or with a forged query, or injects junk**: no session needed, no data shown, junk ignored; the PDF route rejects tampered parameters before any read → Task 9 "the print shell renders nothing without an injected model…", Task 11 "tampered parameters are rejected before any read".
5. **Chromium fails** (launch error, page never ready, PDF timeout, `close()` throws): the response is a 502 `pdf_failed` and the browser is always closed (killed if needed) — no zombie Chromium left in a warm function → Task 10 "always closes the browser…" cases and Task 11 "a renderer failure is a 502 pdf_failed".

Also covered in the owning tasks: duplicate/unknown query keys (Task 1), over-long title/note and bidi tricks (Task 1), sheet-name collisions after translation (Task 2), timezone shifts in date cells (Task 2), off-origin requests from the headless page (Task 10), a missing `NEXT_PUBLIC_APP_URL` (Task 11).

```ts
export interface ExportParams {
  scope: ExportScope;
  period: Period;
}
export interface ReportParams extends ExportParams {
  sections: Section[];
  title: string; // '' = the translated default title
  note: string;
}
export type Parsed<T> = { ok: true; params: T } | { ok: false; error: 'bad_params' };

export const TITLE_MAX = 120;
export const NOTE_MAX = 1000;

const BAD = { ok: false, error: 'bad_params' } as const;
// C0/C1 controls (except tab/newline, handled below) and bidi overrides/isolates that can disguise text
const FORBIDDEN = /[\u0000-\u0008\u000b\u000c\u000e-\u001f\u007f-\u009f‪-‮⁦-⁩]/;

/** Exactly one value per key: `?scope=a&scope=b` is ambiguous, so it is rejected rather than guessed. */
function single(q: URLSearchParams, key: string): string | null {
  const all = q.getAll(key);
  return all.length === 1 ? all[0] : null;
}

export function parseScope(v: string | null): ExportScope | null {
  if (v === 'all') return { kind: 'all' };
  if (v?.startsWith('a:') && isUuid(v.slice(2))) return { kind: 'account', id: v.slice(2).toLowerCase() };
  if (v?.startsWith('g:')) {
    const g = normalizeGroup(v.slice(2));
    return g.ok && g.value !== null && g.value === v.slice(2) ? { kind: 'group', name: g.value } : null;
  }
  return null;
}

export const scopeParam = (s: ExportScope): string => (s.kind === 'all' ? 'all' : s.kind === 'group' ? `g:${s.name}` : `a:${s.id}`);

/** Free text (title, note): NFC, no control/bidi characters, at most `max` code points. Over-long text is rejected, not cut. */
function text(v: string | null, max: number, multiline: boolean): string | null {
  if (v === null) return '';
  const nfc = v.normalize('NFC').replace(/\r\n?/g, '\n');
  if (FORBIDDEN.test(nfc) || (!multiline && nfc.includes('\n'))) return null;
  const value = (multiline ? nfc.replace(/[ \t]+/g, ' ').replace(/\n{3,}/g, '\n\n') : nfc.replace(/\s+/g, ' ')).trim();
  return [...value].length <= max ? value : null;
}

export function parseExportParams(q: URLSearchParams): Parsed<ExportParams> {
  const scope = parseScope(single(q, 'scope'));
  const period = Number(single(q, 'period'));
  if (!scope || !(PERIODS as readonly number[]).includes(period)) return BAD;
  return { ok: true, params: { scope, period: period as Period } };
}

export function parseReportParams(q: URLSearchParams): Parsed<ReportParams> {
  const base = parseExportParams(q);
  if (!base.ok) return BAD;
  const raw = single(q, 'sections');
  const list = raw ? raw.split(',') : [];
  const sections = SECTIONS.filter((s) => list.includes(s)); // fixed display order, duplicates collapse
  if (list.length === 0 || list.some((s) => !(SECTIONS as readonly string[]).includes(s))) return BAD;
  if (q.getAll('title').length > 1 || q.getAll('note').length > 1) return BAD;
  const title = text(q.get('title'), TITLE_MAX, false);
  const note = text(q.get('note'), NOTE_MAX, true);
  if (title === null || note === null) return BAD;
  return { ok: true, params: { ...base.params, sections, title, note } };
}

/** The live (non-archived) accounts a scope covers, sorted by username; null when the group/account does not exist. */
export function resolveScope(scope: ExportScope, accounts: StoredAccount[]): StoredAccount[] | null {
  const live = accounts.filter((a) => a.status !== 'archived').sort((a, b) => a.username.localeCompare(b.username));
  if (scope.kind === 'all') return live;
  const hit = scope.kind === 'group' ? live.filter((a) => a.groupName === scope.name) : live.filter((a) => a.id === scope.id);
  return hit.length ? hit : null;
}

export interface ScopeOption {
  value: string; // scopeParam()
  kind: ExportScope['kind'];
  name: string; // group name or username ('' for all)
}

/** What the export dialog offers: all accounts, each group, each account. */
export function exportScopes(accounts: StoredAccount[]): ScopeOption[] {
  const live = resolveScope({ kind: 'all' }, accounts) ?? [];
  const groups = [...new Set(live.map((a) => a.groupName).filter((g): g is string => !!g))].sort((a, b) => a.localeCompare(b));
  return [
    { value: 'all', kind: 'all', name: '' },
    ...groups.map((g) => ({ value: `g:${g}`, kind: 'group' as const, name: g })),
    ...live.map((a) => ({ value: `a:${a.id}`, kind: 'account' as const, name: a.username })),
  ];
}

/** Short label for file names and the report header: '@username', the group name, or 'all'. */
export function scopeLabel(scope: ExportScope, accounts: StoredAccount[]): string {
  if (scope.kind === 'all') return 'all';
  if (scope.kind === 'group') return scope.name;
  return `@${accounts.find((a) => a.id === scope.id)?.username ?? 'account'}`;
}
```

```ts
// Download file names. Account and group names may contain emoji, CJK, slashes or quotes: the header carries an
// ASCII-only `filename` (old clients) plus the exact UTF-8 name in RFC 5987/6266 `filename*` (every current browser).

// path separators, quotes, Windows-reserved characters and controls can never be part of a file name
const UNSAFE = /[\u0000-\u001f\u007f"\\/:*?<>|]+/g;
const MAX = 100; // code points, before the extension

function clean(base: string): string {
  const s = [...base.normalize('NFC').replace(UNSAFE, '-').replace(/-{2,}/g, '-').replace(/\s+/g, ' ').trim()].slice(0, MAX).join('').trim();
  return s.replace(/^\.+/, '') || 'in2sight'; // never a hidden or empty name
}

export function exportBasename(label: string, today: string): string {
  return `in2sight-${label}-${today}`;
}

export function contentDisposition(base: string, ext: 'xlsx' | 'pdf'): string {
  const name = clean(base);
  const ascii =
    name
      .normalize('NFKD')
      .replace(/[̀-ͯ]/g, '')
      .replace(/[^A-Za-z0-9._-]+/g, '-')
      .replace(/-{2,}/g, '-')
      .replace(/^[-.]+|[-.]+$/g, '') || 'in2sight';
  // encodeURIComponent leaves ' ( ) * unencoded; RFC 5987 attr-char does not allow them
  const star = encodeURIComponent(name).replace(/['()*]/g, (c) => `%${c.charCodeAt(0).toString(16).toUpperCase()}`);
  return `attachment; filename="${ascii}.${ext}"; filename*=UTF-8''${star}.${ext}`;
}

/** The browser side: the name to save a fetched blob under (same cleaning, so a hostile header cannot pick a path). */
export function filenameFromDisposition(header: string | null, fallback: string): string {
  const star = header?.match(/filename\*=UTF-8''([^;]+)/i)?.[1];
  let name: string | null = null;
  if (star) {
    try {
      name = decodeURIComponent(star.trim());
    } catch {
      name = null;
    }
  }
  name ??= header?.match(/filename="([^"]*)"/i)?.[1] ?? null;
  if (!name) return fallback;
  const dot = name.lastIndexOf('.');
  const ext = dot > 0 ? name.slice(dot + 1).toLowerCase() : '';
  return ext === 'xlsx' || ext === 'pdf' ? `${clean(name.slice(0, dot))}.${ext}` : fallback;
}
```

```ts
/**
 * The owner's wall-clock time of an instant as a Date whose UTC fields carry it (2026-10-15T01:30Z in Kuala Lumpur
 * gives a Date of 2026-10-15T09:30Z). For spreadsheet cells: Excel has no timezones and write-excel-file converts a
 * Date's UTC time into the cell value. A day string 'YYYY-MM-DD' with tz 'UTC' gives that day at 00:00. Null for junk.
 */
export function wallClock(v: DateInput, tz: string): Date | null {
  const d = toDate(v); // a bare 'YYYY-MM-DD' parses as UTC midnight
  if (!d) return null;
  const { year, month, day, hour, minute } = parts(d, tz);
  return new Date(Date.UTC(Number(year), Number(month) - 1, Number(day), Number(hour), Number(minute)));
}
```

```ts
// Spreadsheet cell rules shared by every sheet: safe text, sheet names, Excel number formats for the owner's settings.
import type { DateFormat, Locale, TimeFormat } from '@/lib/prefs';

/** Excel's hard limit per cell; longer text is cut (a caption can be up to 2,200 characters, so this never bites in practice). */
export const CELL_MAX = 32_767;

// A cell starting with one of these is read as a formula by Excel/LibreOffice/Sheets once someone edits or re-saves it
// as CSV (OWASP "CSV injection"). Full-width variants are included because some IMEs turn them into formulas too.
const FORMULA_START = /^[=+\-@\t\r＝＋－＠]/;

/**
 * Text from users or Meta (captions, usernames, tag/group/city names) → a cell string, or null for an empty cell.
 * Formula-like text gets a leading apostrophe. Visible on purpose: it survives copy/paste and CSV re-saves (an
 * invisible zero-width prefix would not, and would silently break lookups). The cell is a string cell either way.
 */
export function safeText(v: string | null | undefined): string | null {
  if (v === null || v === undefined || v === '') return null;
  const guarded = FORMULA_START.test(v) ? `'${v}` : v;
  if (guarded.length <= CELL_MAX) return guarded;
  const cut = guarded.slice(0, CELL_MAX);
  return /[\uD800-\uDBFF]$/.test(cut) ? cut.slice(0, -1) : cut; // never leave half an emoji
}

const SHEET_FORBIDDEN = /[[\]:*?/\\]/g;

/** Excel sheet names: 1–31 UTF-16 units, none of []:*?/\, no leading/trailing apostrophe, unique ignoring case. */
export function sheetNames(names: string[]): string[] {
  const used = new Set<string>();
  const fit = (s: string, max: number) => {
    let out = '';
    for (const ch of s) {
      if (out.length + ch.length > max) break;
      out += ch;
    }
    return out;
  };
  return names.map((raw) => {
    const base = fit(raw.replace(SHEET_FORBIDDEN, ' ').replace(/\s+/g, ' ').trim().replace(/^'+|'+$/g, ''), 31).trim() || 'Sheet';
    let name = base;
    for (let i = 2; used.has(name.toLowerCase()); i++) name = `${fit(base, 31 - ` (${i})`.length)} (${i})`;
    used.add(name.toLowerCase());
    return name;
  });
}

/** The owner's date format as an Excel number format (SPEC §8b.7 formats map 1:1). */
export function excelDateFormat(f: DateFormat, locale: Locale): string {
  switch (f) {
    case 'YYYY-MM-DD':
      return 'yyyy-mm-dd';
    case 'DD/MM/YYYY':
      return 'dd/mm/yyyy';
    case 'MM/DD/YYYY':
      return 'mm/dd/yyyy';
    case 'D MMM YYYY':
      return locale === 'zh-CN' ? 'yyyy"年"m"月"d"日"' : 'd mmm yyyy';
  }
}

/** ponytail: 12h uses Excel's AM/PM marker, which Excel prints in the viewer's language; add [$-804] if zh-CN wants 上午/下午 forced. */
export function excelDateTimeFormat(f: DateFormat, t: TimeFormat, locale: Locale): string {
  return `${excelDateFormat(f, locale)} ${t === '24h' ? 'hh:mm' : 'h:mm AM/PM'}`;
}

/** Counts and ratios. The thousands/decimal separators follow the viewer's Excel locale (not the app's number format). */
export const COUNT_FORMAT = '#,##0';
export const AVG_FORMAT = '#,##0.0';
export const PERCENT_FORMAT = '0.0%';
```

```ts
// Everything an export needs for the accounts in scope, read with the OWNER SESSION client (RLS) through the existing
// dashboard readers (explicit columns, hard limits, fixed error messages). Never the admin client, never account_tokens.
import type { SupabaseClient } from '@supabase/supabase-js';
import type { StoredAccount } from '@/lib/accounts/types';
import type { DailyRow, OnlineFollowersRow, Period, Tag } from '@/lib/analysis/types';
import { loadAudience, loadOnline, loadPostRows, loadStories, loadTags, type AudienceSnapshots, type PostRow, type StoryRow } from '@/lib/dashboard/detail-read';
import { fromDayFor } from '@/lib/dashboard/overview';
import { loadDaily } from '@/lib/dashboard/read';
import { listSyncStatus, type SyncStatus } from '@/lib/sync/store';
import { addDays, dayStart } from '@/lib/sync/time';

export interface ExportData {
  accounts: StoredAccount[]; // the scope, sorted by username (resolveScope)
  sync: Record<string, SyncStatus>;
  daily: Record<string, DailyRow[]>; // two windows + lag (fromDayFor), so KPIs can compare
  posts: Record<string, PostRow[]>; // newest first, at most 500 per account (MEDIA_LIMIT), with caption + tag ids
  stories: Record<string, StoryRow[]>; // posted inside the export window
  audience: Record<string, AudienceSnapshots>;
  online: Record<string, OnlineFollowersRow[]>; // last 30 days (what Instagram keeps)
  tags: Tag[];
}

/** The raw-data window of an export: the last `period` days including today (owner timezone days). */
export function exportWindow(period: Period, today: string): { from: string; to: string } {
  return { from: addDays(today, -(period - 1)), to: today };
}

const byId = <T>(accounts: StoredAccount[], values: T[]): Record<string, T> => Object.fromEntries(accounts.map((a, i) => [a.id, values[i]]));

/** 5 queries per account + 3 shared, all in parallel. Any failed read throws (the route answers with an error key). */
export async function loadExportData(db: SupabaseClient, accounts: StoredAccount[], o: { period: Period; today: string; tz: string }): Promise<ExportData> {
  const ids = accounts.map((a) => a.id);
  const since = dayStart(exportWindow(o.period, o.today).from, o.tz).toISOString();
  const [sync, tags, online, per] = await Promise.all([
    listSyncStatus(db),
    loadTags(db),
    loadOnline(db, ids, addDays(o.today, -30)),
    Promise.all(accounts.map((a) => Promise.all([loadDaily(db, a.id, fromDayFor(o.period, o.today)), loadPostRows(db, a.id), loadStories(db, a.id, since), loadAudience(db, a.id)]))),
  ]);
  return {
    accounts,
    sync,
    daily: byId(accounts, per.map((p) => p[0])),
    posts: byId(accounts, per.map((p) => p[1])),
    stories: byId(accounts, per.map((p) => p[2])),
    audience: byId(accounts, per.map((p) => p[3])),
    online,
    tags,
  };
}
```

```ts
export interface WorkbookSheet {
  sheet: string;
  data: SheetData;
  columns: { width: number }[];
  stickyRowsCount: number; // the header row stays visible ("frozen")
}

type Kind = 'text' | 'count' | 'avg' | 'percent' | 'date' | 'datetime';
type Value = string | number | null | undefined;
interface Col<R> {
  header: string;
  kind: Kind;
  width: number;
  get: (r: R) => Value;
}

export interface WorkbookOptions {
  period: Period;
  today: string;
  now: Date;
  prefs: FormatPrefs;
  scopeName: string; // label of the totals row ("All accounts" / the group name)
}

const KPI_IDS: KpiId[] = ['followers', 'reach', 'views', 'engagementRate', 'posts', 'netFollows'];
const num = (v: Value) => (typeof v === 'number' && Number.isFinite(v) ? v : null);

function cellOf(kind: Kind, v: Value, o: WorkbookOptions): Cell {
  if (kind === 'text') {
    const s = safeText(typeof v === 'string' ? v : null);
    return s === null ? null : { value: s, type: String };
  }
  if (kind === 'date' || kind === 'datetime') {
    // a day string is already an owner-timezone day; an instant is moved to the owner's wall clock
    const d = typeof v === 'string' ? wallClock(v, kind === 'date' ? 'UTC' : o.prefs.timezone) : null;
    if (!d) return null;
    const { dateFormat, timeFormat, locale } = o.prefs;
    return { value: d, type: Date, format: kind === 'date' ? excelDateFormat(dateFormat, locale) : excelDateTimeFormat(dateFormat, timeFormat, locale) };
  }
  const n = num(v);
  if (n === null) return null;
  return { value: n, type: Number, format: kind === 'percent' ? PERCENT_FORMAT : kind === 'avg' ? AVG_FORMAT : COUNT_FORMAT };
}

function sheet<R>(name: string, cols: Col<R>[], rows: R[], o: WorkbookOptions): Omit<WorkbookSheet, 'sheet'> & { name: string } {
  return {
    name,
    data: [cols.map((c) => ({ value: c.header, type: String, fontWeight: 'bold' as const })), ...rows.map((r) => cols.map((c) => cellOf(c.kind, c.get(r), o)))],
    columns: cols.map((c) => ({ width: c.width })),
    stickyRowsCount: 1,
  };
}

      return entries.sort((x, y) => y[1] - x[1]).map(([key, value]) => ({ username: a.username, day: snap.day, kind, item: label(key), value, share: value / sum }));

    { header: t('metrics.posts'), kind: 'count', width: 9, get: (r) => r.posts },

    { header: t('metrics.engagementRate'), kind: 'percent', width: 12, get: (r) => r.engagementRate },
  ];

  const built = [
    sheet(t('export.sheets.summary'), summaryCols, sumRows, o),
    sheet(t('export.sheets.daily'), dailyCols, dailyRows, o),
    sheet(t('export.sheets.posts'), postCols, posts, o),
    sheet(t('export.sheets.stories'), storyCols, storyRows, o),
    sheet(t('export.sheets.audience'), audCols, audRows, o),
    sheet(t('export.sheets.tags'), tagCols, tagRows, o),
  ];
  const names = sheetNames(built.map((b) => b.name));
  return built.map((b, i) => ({ sheet: names[i], data: b.data, columns: b.columns, stickyRowsCount: b.stickyRowsCount }));
}

export function writeWorkbook(sheets: WorkbookSheet[]): Promise<Buffer> {
  return writeXlsxFile(sheets).toBuffer();
}
```

```ts
// The common front half of both export routes: owner check, parameter allow-list, scope, owner-session reads.
import { NextResponse } from 'next/server';
import { supabaseAccountsStore } from '@/lib/accounts/supabase-store';
import { assertOwner } from '@/lib/auth/assert-owner';
import { resolveScope, scopeLabel, type ExportParams, type Parsed } from '@/lib/export/params';
import { loadExportData, type ExportData } from '@/lib/export/read';
import type { Prefs } from '@/lib/prefs';
import { getPrefs } from '@/lib/prefs.server';
import { createServerSupabase } from '@/lib/supabase/server';
import { localDay } from '@/lib/sync/time';

export type ExportError = 'unauthorized' | 'bad_params' | 'not_found' | 'pdf_failed' | 'not_configured' | 'unexpected';

export interface ExportContext<P extends ExportParams> {
  params: P;
  data: ExportData;
  prefs: Prefs;
  now: Date;
  today: string;
  label: string; // scopeLabel(): '@username', the group name, or 'all'
}

export async function openExport<P extends ExportParams>(q: URLSearchParams, parse: (q: URLSearchParams) => Parsed<P>, h: Headers): Promise<{ ok: true; ctx: ExportContext<P> } | { ok: false; status: number; error: ExportError }> {
  if (!(await assertOwner(h))) return { ok: false, status: 401, error: 'unauthorized' };
  const parsed = parse(q);
  if (!parsed.ok) return { ok: false, status: 400, error: 'bad_params' };
  const prefs = await getPrefs(); // timezone + formats: the owner's (synced to profiles); the sync writes days in it too
  const now = new Date();
  const today = localDay(now, prefs.timezone);
  const db = await createServerSupabase({ responseHeaders: h }); // owner session: RLS applies
  const accounts = resolveScope(parsed.params.scope, await supabaseAccountsStore(db).list());
  if (!accounts) return { ok: false, status: 404, error: 'not_found' };
  const data = await loadExportData(db, accounts, { period: parsed.params.period, today, tz: prefs.timezone });
  return { ok: true, ctx: { params: parsed.params, data, prefs, now, today, label: scopeLabel(parsed.params.scope, accounts) } };
}

/** Every export response is private and uncached (it carries the owner's data, and maybe a refreshed session cookie). */
export function exportHeaders(): Headers {
  return new Headers({ 'cache-control': 'private, no-store' });
}

export function exportError(h: Headers, status: number, error: ExportError): NextResponse {
  return NextResponse.json({ error }, { status, headers: h });
}

export function exportFile(h: Headers, body: Uint8Array, type: string, disposition: string): NextResponse {
  h.set('content-type', type);
  h.set('content-disposition', disposition);
  h.set('x-content-type-options', 'nosniff');
  return new NextResponse(new Uint8Array(body), { status: 200, headers: h });
}
```

```ts
/** GET /api/export/xlsx?scope=all|g:<group>|a:<uuid>&period=7|30|90 — owner session only. */
export async function GET(request: NextRequest) {
  const h = exportHeaders();
  try {
    const r = await openExport(request.nextUrl.searchParams, parseExportParams, h);
    if (!r.ok) return exportError(h, r.status, r.error);
    const { params, data, prefs, now, today, label } = r.ctx;
    const t = translator(prefs.locale);
    const sheets = buildWorkbook(data, t, { period: params.period, today, now, prefs, scopeName: params.scope.kind === 'all' ? t('export.scopeAll') : label });
    return exportFile(h, await writeWorkbook(sheets), XLSX, contentDisposition(exportBasename(label, today), 'xlsx'));
  } catch {
    console.error('xlsx export failed'); // fixed text: never log error objects (they can carry row values)
    return exportError(h, 500, 'unexpected');
  }
}
```

```ts
// The PDF / preview report (SPEC §7d) as one small, JSON-serialisable model built from ExportData. Pure: now/today/tz
// are inputs. Reuses the dashboard analysis; nothing here is new maths.
import { onlineHeatmap, postHeatmap, type Heatmap } from '@/lib/analysis/best-time';
import { reachDrop, takingOff, type Flag } from '@/lib/analysis/flags';
import { combine, kpis, summarize, type Kpi, type KpiId } from '@/lib/analysis/growth';
import { engagementRate, formatComparison, topPosts } from '@/lib/analysis/posts';
import type { Period } from '@/lib/analysis/types';
import { buildAudience, type AudienceModel } from '@/lib/dashboard/audience';
import { buildStories, buildTagStats, snippet, type FeedFormat, type TagStat } from '@/lib/dashboard/content';
import type { ExportScope, ReportParams, Section } from '@/lib/export/params';
import { exportWindow, type ExportData } from '@/lib/export/read';
import type { WeekStart } from '@/lib/prefs';
import { addDays, localDay } from '@/lib/sync/time';

export const TOP_POSTS = 10;

export interface ReportPost {
  id: string;
  username: string;
  mediaType: FeedFormat;
  postedAt: string;
  permalink: string | null;
  caption: string | null; // one-line snippet
  reach: number;
  engagementRate: number | null;
}

export interface ReportModel {
  v: 1;
  title: string; // '' = the translated default title
  note: string;
  scope: { kind: ExportScope['kind']; name: string }; // name: group name, username, or '' for all
  period: Period;
  from: string; // KPI window, owner-timezone days
  to: string;
  generatedAt: string; // ISO instant; formatted by the view
  sections: Section[];
  kpis: Record<KpiId, Kpi>;
  accounts: { username: string; kpis: Record<KpiId, Kpi> }[]; // per account, when the scope has 2+
  trend: { day: string; reach: number | null; views: number | null }[];
  topPosts: ReportPost[];
  formats: ReturnType<typeof formatComparison>;
  tags: { name: string; color: string; stat: TagStat }[];
  untagged: TagStat;
  bestTime: { online: Heatmap; posts: Heatmap };
  audience: { username: string; model: Omit<AudienceModel, 'globe'> }[];
  stories: { username: string; count: number; avgReach: number | null; avgViews: number | null; avgExitRate: number | null }[];
  flags: { username: string; flag: Flag }[];
}

const avg = (vals: (number | null | undefined)[]): number | null => {
  const n = vals.filter((v): v is number => typeof v === 'number' && Number.isFinite(v));
  return n.length ? n.reduce((a, b) => a + b, 0) / n.length : null;
};
const add = (a: number | null, b: number | null) => (a === null ? b : b === null ? a : a + b);

export function buildReport(data: ExportData, p: ReportParams, o: { today: string; now: Date; tz: string; weekStart: WeekStart }): ReportModel {
  const { from: rawFrom, to: rawTo } = exportWindow(p.period, o.today);
  const user = new Map(data.accounts.map((a) => [a.id, a.username]));
  const allPosts = data.accounts.flatMap((a) => data.posts[a.id] ?? []);
  const windowPosts = allPosts.filter((x) => {
    const d = localDay(new Date(x.postedAt), o.tz);
    return x.mediaType !== 'STORY' && d >= rawFrom && d <= rawTo;
  });

  const summaries = data.accounts.map((a) => summarize(data.daily[a.id] ?? [], data.posts[a.id] ?? [], p.period, o.today, o.tz));
  const withData = summaries.filter((_, i) => (data.daily[data.accounts[i].id] ?? []).length > 0);
  const total = summaries.length === 1 ? summaries[0] : combine(withData.length ? withData : summaries) ?? summarize([], [], p.period, o.today, o.tz);
  const to = total.endDay;
  const from = addDays(to, -(p.period - 1));
  const days = Array.from({ length: p.period }, (_, i) => addDays(from, i));
  const byDay = (field: 'reach' | 'views') => {
    const m = new Map<string, number | null>();
    for (const a of data.accounts) for (const r of data.daily[a.id] ?? []) m.set(r.day, add(m.get(r.day) ?? null, r[field]));
    return m;
  };
  const reach = byDay('reach');
  const views = byDay('views');
  const tagStats = buildTagStats(windowPosts, data.tags);
  const caption = new Map(windowPosts.map((x) => [x.id, x.caption]));

  return {
    v: 1,
    title: p.title,
    note: p.note,
    scope: { kind: p.scope.kind, name: p.scope.kind === 'all' ? '' : p.scope.kind === 'group' ? p.scope.name : (data.accounts[0]?.username ?? '') },
    period: p.period,
    from,
    to,
    generatedAt: o.now.toISOString(),
    sections: p.sections,
    kpis: kpis(total),
    accounts: data.accounts.length > 1 ? data.accounts.map((a, i) => ({ username: a.username, kpis: kpis(summaries[i]) })) : [],
    trend: days.map((day) => ({ day, reach: reach.get(day) ?? null, views: views.get(day) ?? null })),
    topPosts: topPosts(windowPosts, 'reach', { limit: TOP_POSTS }).map(({ post, value }) => ({
      id: post.id,
      username: user.get(post.accountId) ?? '',
      mediaType: post.mediaType as FeedFormat,
      postedAt: post.postedAt,
      permalink: post.permalink,
      caption: snippet(caption.get(post.id) ?? null),
      reach: value,
      engagementRate: engagementRate(post),
    })),
    formats: formatComparison(windowPosts),
    tags: tagStats.rows.map((r) => ({ name: r.tag.name, color: r.tag.color, stat: { posts: r.posts, measured: r.measured, avgReach: r.avgReach, engagementRate: r.engagementRate, reason: r.reason } })),
    untagged: tagStats.untagged,
    bestTime: { online: onlineHeatmap(data.accounts.flatMap((a) => data.online[a.id] ?? []), o.weekStart), posts: postHeatmap(allPosts, o.tz, o.weekStart) },
    audience: data.accounts.map((a) => {
      const m = buildAudience(data.audience[a.id] ?? { age_gender: null, country: null, city: null });
      return { username: a.username, model: { ages: m.ages, countries: m.countries, cities: m.cities, reason: m.reason } }; // no globe in print
    }),
    stories: data.accounts.map((a) => {
      const list = buildStories(data.stories[a.id] ?? [], o.now);
      return { username: a.username, count: list.length, avgReach: avg(list.map((s) => s.final?.reach)), avgViews: avg(list.map((s) => s.final?.views)), avgExitRate: avg(list.map((s) => s.exitRate)) };
    }),
    flags: data.accounts.flatMap((a) => {
      const drop = reachDrop(data.daily[a.id] ?? [], o.today, o.tz);
      return [...takingOff(data.posts[a.id] ?? [], o.now, p.period), ...(drop ? [drop] : [])].map((flag) => ({ username: a.username, flag }));
    }),
  };
}

/** The print shell's check of what was injected into its window: right version and shape, else it renders nothing. */
export function isReportModel(v: unknown): v is ReportModel {
  if (v === null || typeof v !== 'object') return false;
  const m = v as Partial<ReportModel>;
  return m.v === 1 && typeof m.title === 'string' && typeof m.note === 'string' && Array.isArray(m.sections) && Array.isArray(m.trend) && typeof m.kpis === 'object' && m.kpis !== null;
}
```

```tsx
import { useEffect } from 'react';

/** Reports are always light (SPEC §7d): switch <html data-mode> to light while mounted, restore it on the way out. */
export function ForceLight() {
  useEffect(() => {
    const el = document.documentElement;
    const before = el.getAttribute('data-mode');
    el.setAttribute('data-mode', 'light');
    return () => {
      if (before) el.setAttribute('data-mode', before);
    };
  }, []);
  return null;
}
```

```tsx
import { buildReport } from '@/lib/export/report';

type SearchParams = Record<string, string | string[] | undefined>;

/** The owner's preview of a PDF report (/report?scope=…&period=…&sections=…&title=…&note=…): same component, no Chromium. */
export default async function ReportPage({ searchParams }: { searchParams: Promise<SearchParams> }) {
  await requireOwner(); // pages check the owner first, like every other page
  const q = new URLSearchParams();
  for (const [k, v] of Object.entries(await searchParams)) for (const one of Array.isArray(v) ? v : v === undefined ? [] : [v]) q.append(k, one);
  const r = await openExport(q, parseReportParams, new Headers());
  if (!r.ok) notFound(); // bad parameters or an unknown scope: nothing to show
  const { data, params, prefs, today, now } = r.ctx;
  return <ReportDocument model={buildReport(data, params, { today, now, tz: prefs.timezone, weekStart: prefs.weekStart })} />;
}
```

```tsx
'use client';

import { useEffect, useState, useSyncExternalStore } from 'react';
import { useTranslations } from 'next-intl';
import { ReportDocument } from '@/components/report/ReportDocument';
import { isReportModel } from '@/lib/export/report';

declare global {
  interface Window {
    __IN2SIGHT_REPORT__?: unknown; // set by lib/export/pdf.ts before any page script runs
  }
}

const noop = () => () => {};
const injected = () => window.__IN2SIGHT_REPORT__ ?? null;
const none = () => null;

/** Renders the injected model, then marks itself ready two frames later (charts measured and painted) for the PDF. */
export function PrintShell() {
  const t = useTranslations('export.report');
  const raw = useSyncExternalStore(noop, injected, none);
  const model = isReportModel(raw) ? raw : null;
  const [ready, setReady] = useState(false);
  useEffect(() => {
    if (!model) return;
    let second = 0;
    const first = requestAnimationFrame(() => {
      second = requestAnimationFrame(() => setReady(true));
    });
    return () => {
      cancelAnimationFrame(first);
      cancelAnimationFrame(second);
    };
  }, [model]);
  if (!model) return <p className="p-8 text-sm text-muted-foreground">{t('loading')}</p>;
  return (
    <div data-report-ready={ready ? 'true' : undefined}>
      <ReportDocument model={model} />
    </div>
  );
}
```

```ts
// Prints a ReportModel to an A4 PDF with headless Chromium. The browser comes from an injected `launch` (the real one is
// lib/export/chromium.ts; tests pass a fake), opens ONLY the app's own /report/print, receives the model over the
// DevTools protocol (never in a URL), and is always closed: a warm serverless function must not keep a zombie Chromium.
import type { Browser } from 'puppeteer-core';
import type { ReportModel } from '@/lib/export/report';
import { PREFS_COOKIE, serializePrefs, type Prefs } from '@/lib/prefs';

export type Launch = () => Promise<Browser>;

export const PRINT_PATH = '/report/print';
export const BUDGET_MS = 45_000; // inside the route's maxDuration (60 s), leaving time to answer
const GOTO_MS = 20_000;
const READY_MS = 15_000;
const PDF_MS = 20_000;
const CLOSE_MS = 5_000;

function withTimeout<T>(p: Promise<T>, ms: number): Promise<T> {
  let timer: ReturnType<typeof setTimeout> | undefined;
  return Promise.race([p, new Promise<never>((_, reject) => (timer = setTimeout(() => reject(new Error('timeout')), ms)))]).finally(() => clearTimeout(timer));
}

async function closeQuietly(browser: Browser): Promise<void> {
  try {
    await withTimeout(browser.close(), CLOSE_MS);
  } catch {
    browser.process()?.kill('SIGKILL'); // close() failed or hung: never leave the process behind
  }
}

/** The one origin the headless browser may talk to: NEXT_PUBLIC_APP_URL's (https, or http://localhost for local runs). */
export function appOrigin(raw: string | undefined): string | null {
  try {
    const u = new URL(raw ?? '');
    const local = u.protocol === 'http:' && (u.hostname === 'localhost' || u.hostname === '127.0.0.1');
    return u.protocol === 'https:' || local ? u.origin : null;
  } catch {
    return null;
  }
}

export async function renderReportPdf(model: ReportModel, o: { origin: string; prefs: Prefs; launch: Launch; budgetMs?: number }): Promise<Uint8Array> {
  const url = new URL(PRINT_PATH, o.origin);
  const launching = o.launch();
  try {
    return await withTimeout(
      (async () => {
        const browser = await launching;
        // the prefs cookie (not a secret) gives the root layout the owner's language, formats and theme; always light
        await browser.setCookie({ name: PREFS_COOKIE, value: serializePrefs({ ...o.prefs, mode: 'light' }), domain: url.hostname, path: '/', secure: url.protocol === 'https:', sameSite: 'Lax' });
        const page = await browser.newPage();
        await page.setBypassServiceWorker(true);
        await page.setRequestInterception(true);
        page.on('request', (req) => {
          let same = false;
          try {
            same = new URL(req.url()).origin === url.origin;
          } catch {
            same = false;
          }
          void (same ? req.continue() : req.abort()).catch(() => undefined); // SSRF guard: our own origin only
        });
        await page.evaluateOnNewDocument((m: unknown) => {
          (window as unknown as { __IN2SIGHT_REPORT__: unknown }).__IN2SIGHT_REPORT__ = m;
        }, model);
        await page.goto(url.href, { waitUntil: 'networkidle0', timeout: GOTO_MS });
        await page.waitForSelector('[data-report-ready="true"]', { timeout: READY_MS });
        await page.evaluate(() => document.fonts.ready.then(() => true)); // Noto Sans SC slices loaded: no tofu
        return await page.pdf({ format: 'A4', printBackground: true, preferCSSPageSize: true, timeout: PDF_MS });
      })(),
      o.budgetMs ?? BUDGET_MS,
    );
  } finally {
    // waits for a launch still in progress (puppeteer's own launch timeout bounds it), then closes or kills it
    await launching.then(closeQuietly, () => undefined);
  }
}
```

```ts
import type { NextRequest } from 'next/server';
import { launchChromium } from '@/lib/export/chromium';
import { contentDisposition, exportBasename } from '@/lib/export/filename';
import { parseReportParams } from '@/lib/export/params';
import { appOrigin, renderReportPdf } from '@/lib/export/pdf';
import { buildReport } from '@/lib/export/report';
import { exportError, exportFile, exportHeaders, openExport } from '@/lib/export/request';

// Chromium cold start (unpacking to /tmp) plus rendering: SPEC §7d accepts a few seconds; renderReportPdf stops at 45 s.
export const maxDuration = 60;

/** GET /api/export/pdf?scope=…&period=…&sections=…&title=…&note=… — owner session only. */
export async function GET(request: NextRequest) {
  const h = exportHeaders();
  const origin = appOrigin(process.env.NEXT_PUBLIC_APP_URL); // the only place the headless browser may go
  if (!origin) return exportError(h, 503, 'not_configured'); // the proxy already kept anonymous visitors out
  let model;
  let ctx;
  try {
    const r = await openExport(request.nextUrl.searchParams, parseReportParams, h);
    if (!r.ok) return exportError(h, r.status, r.error);
    ctx = r.ctx;
    model = buildReport(ctx.data, ctx.params, { today: ctx.today, now: ctx.now, tz: ctx.prefs.timezone, weekStart: ctx.prefs.weekStart });
  } catch {
    console.error('pdf export: read failed'); // fixed text: never log error objects
    return exportError(h, 500, 'unexpected');
  }
  try {
    const pdf = await renderReportPdf(model, { origin, prefs: ctx.prefs, launch: launchChromium });
    return exportFile(h, pdf, 'application/pdf', contentDisposition(exportBasename(ctx.label, ctx.today), 'pdf'));
  } catch {
    console.error('pdf export: render failed');
    return exportError(h, 502, 'pdf_failed');
  }
}
```

```ts
// Browser side of the export dialog: build the request URL and save the answer as a file.
import type { Period } from '@/lib/analysis/types';
import { filenameFromDisposition } from '@/lib/export/filename';
import type { Section } from '@/lib/export/params';

export type ExportFormat = 'xlsx' | 'pdf';
export interface ExportRequest {
  format: ExportFormat;
  scope: string; // a ScopeOption value
  period: Period;
  sections: Section[];
  title: string;
  note: string;
}

const KNOWN = ['bad_params', 'unauthorized', 'not_found', 'pdf_failed', 'not_configured', 'unexpected'];
const TYPES: Record<ExportFormat, string> = { xlsx: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet', pdf: 'application/pdf' };

/** '/api/export/<format>?…' (a download) or '/report?…' (the browser preview of the PDF report). */
export function exportUrl(r: ExportRequest, target: 'file' | 'preview' = 'file'): string {
  const q = new URLSearchParams({ scope: r.scope, period: String(r.period) });
  if (r.format === 'pdf' || target === 'preview') {
    q.set('sections', r.sections.join(','));
    if (r.title.trim()) q.set('title', r.title.trim());
    if (r.note.trim()) q.set('note', r.note.trim());
  }
  return target === 'preview' ? `/report?${q}` : `/api/export/${r.format}?${q}`;
}

/**
 * GETs the export and saves it under the server's (re-cleaned) file name. Error answers come back as an
 * `export.errors.*` key. A session that ended mid-way shows up as a redirect to an HTML page: never saved as a file.
 */
export async function downloadExport(url: string, format: ExportFormat, fetcher: typeof fetch = fetch): Promise<{ ok: true } | { ok: false; error: string }> {
  let res: Response;
  try {
    res = await fetcher(url, { credentials: 'same-origin' });
  } catch {
    return { ok: false, error: 'unexpected' };
  }
  if (!res.ok) {
    const key = ((await res.json().catch(() => null)) as { error?: unknown } | null)?.error;
    return { ok: false, error: typeof key === 'string' && KNOWN.includes(key) ? key : 'unexpected' };
  }
  if (res.redirected || !res.headers.get('content-type')?.startsWith(TYPES[format])) return { ok: false, error: 'unauthorized' };
  const href = URL.createObjectURL(await res.blob());
  const a = document.createElement('a');
  a.href = href;
  a.download = filenameFromDisposition(res.headers.get('content-disposition'), `in2sight.${format}`);
  document.body.append(a);
  a.click();
  a.remove();
  setTimeout(() => URL.revokeObjectURL(href), 60_000);
  return { ok: true };
}
```

```tsx
            <legend className="mb-1 text-sm font-medium">{t('format')}</legend>
            <RadioGroup value={format} onValueChange={(v) => setFormat(v as ExportFormat)} aria-label={t('format')}>
              {(['xlsx', 'pdf'] as const).map((f) => (

                  <Label htmlFor={`export-format-${f}`}>{t(`formats.${f}`)}</Label>
                </div>
              ))}
            </RadioGroup>
          </fieldset>

            <FormField id="export-scope" label={t('scope')}>

                  <SelectTrigger {...p} className="w-full min-w-0">
                    <SelectValue />
                  </SelectTrigger>
                  <SelectContent>
                    {scopes.map((s) => (
                      <SelectItem key={s.value} value={s.value}>
                        <span className="truncate" dir="auto">{label(s)}</span>
                      </SelectItem>
                    ))}
                  </SelectContent>
                </Select>
              )}
            </FormField>
            <fieldset className="grid gap-2">

            </fieldset>

                <legend className="mb-1 text-sm font-medium">{t('sections')}</legend>

            <p role="status" className="text-sm text-muted-foreground">
              {t('done')}
            </p>
          ) : null}

          <ResponsiveDialogFooter className="flex-wrap gap-2">

                  {t('preview')}
                </a>
              </Button>
            ) : null}
            <ResponsiveDialogClose asChild>
              <Button type="button" variant="outline">
                {tc('cancel')}
              </Button>
            </ResponsiveDialogClose>
            <Button type="submit" disabled={pending} aria-busy={pending || undefined}>
              <Download aria-hidden="true" />
              {pending ? t('working') : t('download')}

          </ResponsiveDialogFooter>
        </form>
      </ResponsiveDialogContent>
    </ResponsiveDialog>
```

````markdown
# Exports live-verification runbook (Plan 9)

Run this once after the app is deployed on its HTTPS URL (`<app-url>` = your `NEXT_PUBLIC_APP_URL`) with at least one account that has synced data. Who: owner, or Claude with the owner. **Nothing here has been verified live yet**: the unit tests use a fake browser, because headless Chromium cannot run inside the tests (and `@sparticuz/chromium` only runs on Linux).

Never paste tokens, cookies or `SUPABASE_SECRET_KEY` into chats, screenshots or tickets. Exported files contain your Instagram data: share them deliberately.

## 0. Before you start

- `NEXT_PUBLIC_APP_URL` in Vercel is the exact public origin (`https://…`, no trailing slash). The PDF route only ever opens `<app-url>/report/print`; with a missing or `http://` URL it answers `not_configured`.

Test on the production domain, or add a Protection Bypass for Automation (Vercel → Project → Settings → Deployment Protection) and tell Claude before changing anything.

## 1. Excel (any machine)

1. `<app-url>/overview` → **Export** → Format **Excel workbook** → Accounts **All accounts** → 30 days → **Download**. A file `in2sight-all-<date>.xlsx` is saved; the dialog says "Download started".
2. Open it in **Excel** and in **LibreOffice Calc** (both must open without a repair prompt). Check:
   - Six sheets: Summary, Daily, Posts, Stories, Audience, Tags (in Chinese when the app language is 简体中文: 概要, 每日数据, 帖子, 快拍, 受众, 标签).
   - The header row is bold and stays visible when scrolling (frozen).
   - Date columns are real dates (right-aligned; sorting and filtering by date work) shown in your Settings date format (try switching Settings → date format and exporting again).
   - Number columns are numbers (SUM works), engagement and shares show as `%`.
   - Missing values are empty cells, not `0` (e.g. Link taps, or reach of a post Instagram never measured).
   - A caption or tag starting with `=`, `+`, `-` or `@` shows with a leading `'` and is **not** evaluated. Click into such a cell and press Enter: it must stay text.
3. Export one account from its Account detail page (**Export** is next to Calendar; the account is preselected). File name `in2sight-@<username>-<date>.xlsx` (browsers that cannot save `@`/emoji use the ASCII fallback name).
4. An account with a slash, emoji or Chinese in its group name: export the group; the file name keeps the characters (slashes become `-`).

## 2. PDF report preview (any machine, no Chromium)

1. **Export** → Format **PDF report** → pick sections, a title in Chinese (e.g. `十月报告`) and a two-line note → **Preview in the browser**. A new tab opens `/report?…` with the report, always light even when the app is in dark mode.
2. Check every section renders with your data, the globe is absent, charts are drawn (no animation in print).
3. Ctrl+P (Save as PDF, A4): sections are not split across pages where avoidable; colours print (heatmap, chart lines).

## 3. PDF on Vercel (the real check)

1. **Export** → **PDF report** → all sections → **Download**. The first PDF after a quiet spell can take 10–30 s (Chromium unpacks to `/tmp`); a second one right after should be clearly faster. Note both times.
2. Open the PDF:

   - Charts and heatmaps are complete (not mid-animation).
3. Vercel → Project → Deployments → the deployment → **Functions**: `/api/export/pdf` size is shown (expect roughly 70–80 MB compressed; the limit is 250 MB unzipped). Logs → filter `/api/export/pdf`: duration under 60 s, memory used. If memory is near the limit, raise the function memory (Vercel → Settings → Functions) to 2 GB+.
4. Open `<app-url>/report/print` in a private window: it shows only "Preparing the report…", with no data and no error. That page never has data unless the PDF route injected it.

## 4. Troubleshooting

| Symptom | Likely cause | What to do |
|---|---|---|
| Dialog says "PDF export is not configured…" | `NEXT_PUBLIC_APP_URL` missing, `http://`, or has a path typo | fix it in Vercel env, redeploy |
| Dialog says "The PDF could not be generated" every time | Chromium failed to launch (logs: `pdf export: render failed`), Deployment Protection page, or a timeout | check the function log time and memory; test on the production domain; retry once (cold start) |
| PDF shows Vercel's login page | Deployment Protection on that URL | §0 |
| Chinese shows as boxes | fonts not loaded before printing (slow network to `/_next/static/media`) | export again; if it persists, tell Claude (the renderer waits for `document.fonts.ready`) |
````
