# Plan 13b: Post Lab — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One page per post, Reel, carousel and Story — `/accounts/[id]/media/[mediaId]` — that answers "how did this one do, compared with my own normal, and why": a header with the cover, caption, time, format, editable tags and the gone/expired state; a scorecard where every number has its percentile and difference vs the median of the account's last 30 or 90 posts of the same format and a verdict chip (Breakout / Above typical / Typical / Below typical / Too early) behind a sample-size guard; a velocity curve (cumulative reach/views at 1 h, 6 h, 24 h, 48 h, 7 d against the median curve of the same posts); a watch-time panel for Reels; a navigation funnel and a sequence view of the day's Stories; a caption lab; and a strip of similar posts. Every surface that lists posts (Posts table/grid, the post drawer, the Calendar day list, the Explorer item panel) links into it.

**Architecture:** One additive migration adds two small `security invoker` SQL functions (RLS still applies, execute for `authenticated` only): `post_lab_latest(ids)` returns the latest known value of every metric column per media (a snapshot taken on a busy tick can lack its extras; the previous one has them) and `post_lab_points(ids, marks, tols)` returns, per media and checkpoint, the snapshot nearest to "posted + mark" inside a tolerance window — one `DISTINCT ON` instead of shipping ~7,000 snapshot rows through PostgREST's 1,000-row pages. The checkpoint table (marks and tolerances) lives once, in TypeScript, and is passed in. Everything else is plain owner-session selects (the media row, its same-format predecessors, the day's Stories, the posting-day follower counts). The reader turns rows into null-safe `LabItem`s (Meta names such as the `BIO_LINK_CLICKED` action type stay in `lib/instagram/metrics.ts`); pure functions in `lib/analysis/post-lab.ts` (scorecard, percentiles, verdict, velocity, Story funnel and sequence, similar posts) and `lib/analysis/caption.ts` (caption features and the with/without split) build the page model. The page is wiring only; the view is split by section into small client components.

**Tech Stack:** Next.js 16.4 App Router, TypeScript strict, Supabase Postgres (SQL functions, RLS), `@supabase/supabase-js` owner-session client, next-intl 4, Recharts 3 (installed), Vitest 5 + Testing Library + jsdom 29. **New dependencies: none.**

**Spec:** `docs/superpowers/specs/2026-10-15-creator-toolkit-design.md` §5 "Phase C — Post Lab" (approved design), §0b (engagement rate both ways, desktop-first, own accounts only), §8 (cross-cutting rules); `docs/SPEC.md` §5, §7; Plan 13a `docs/superpowers/plans/2026-10-25-13a-covers-ui.md` (consumed: `MediaThumb` and the post drawer, see "Assumptions about 13a"). ## Decisions taken in this plan (owner: please confirm the ones marked ⚠)

- **Two small SQL functions, everything else plain selects.** A post with its 90 peers has ~7,000 snapshots (hourly for 48 h, daily to day 30, the day-7 checkpoint); picking "the snapshot nearest to posted + 6 h" per media is one `DISTINCT ON` in SQL but 7+ pages of 1,000 rows through PostgREST. `security invoker` keeps RLS in charge. The media row, the peers, the day's Stories and the follower counts are ordinary owner-session selects (one page each).
- ⚠ **Peers = the same account's posts of the same format published BEFORE this one, newest first: 30 by default, 90 with the toggle** (`?peers=90`). The post itself is never a peer. Reason: a fixed reference that does not drift when newer posts arrive, and the same "previous posts" idea as the "taking off" flag (`lib/analysis/flags.ts`). The reader always reads 90; the scorecard and the velocity medians use the first 30 or 90; the caption lab and the similar strip use all that were read.
- ⚠ **Sample guard = `MIN_PRIOR_POSTS` (5), Breakout = `TAKING_OFF_RATIO` (2× median), both imported from `lib/analysis/flags.ts`,** so the verdict and the "taking off" alert can never disagree. A comparison (median, percentile, difference) needs ≥ 5 peers that HAVE that number; below that the row shows no median/percentile and a note says "Comparisons need 5+ earlier posts of this format that have the number"; the verdict line says how many there are.
- **Percentile = mid-rank:** (peers below + ½ × peers equal) ÷ peers × 100, rounded. Difference vs median: relative for counts (`+23%`), percentage points for rates (`+1.2 pp`).
- ⚠ **Verdict uses reach** (as the flag and the best-time analysis do): Breakout ≥ 2× median; Above typical ≥ 75th percentile; Below typical < 25th; else Typical. **"Too early" rule:** a feed post / Reel younger than 24 h (`MIN_AGE_HOURS`) is always Too early; between 24 h and 7 days (`CHECKPOINT_DAYS`) only Breakout and Above typical are given (reach only grows, so a lead is real), otherwise Too early; from day 7 the full scale. A Story gets Breakout/Above while live and the full scale once expired (its final numbers). No verdict at all (a reason instead) without reach, under the sample guard, or for a Story Instagram never measured (under 5 viewers, error 10).
- **Velocity checkpoints (one table in `lib/analysis/post-lab.ts`, passed to SQL):** 1 h ± 30 min, 6 h ± 60 min, 24 h ± 2 h, 48 h ± 3 h, 7 d ± 12 h; Stories use 1 h, 6 h, 24 h. A checkpoint is the snapshot NEAREST to posted + mark inside its window. **Never invented:** no window hit → no point (the line breaks, `connectNulls={false}`); a peer without that point simply does not count for that point's median, and a median point needs ≥ 5 peers. The sentence "At 24 h this post had 2.3× the median reach of 12 earlier Reels" uses the latest checkpoint where both exist.
- **Latest numbers = the latest KNOWN value of each column** (`post_lab_latest`): the extras of a snapshot can be missing on a busy tick (20 extra calls per account run) while the snapshot before has them. Story numbers are their final numbers (Stories are only measured while live).
- **Scorecard rows per format.** Feed/carousel: reach, views, interactions, engagement rate, save rate, share rate, follows per 1,000 reach, profile visits, link taps. Reels: the same, follows and profile visits marked "Instagram doesn't report this for Reels" (verified, `docs/META_PROBE_RESULTS.md`), plus the watch-time panel (avg watch, total watch, skip rate vs your median; lower skip rate is better). Stories: reach, views, interactions (Instagram's total), replies, share rate, follows per 1,000 reach, profile visits, link taps, plus the funnel and the sequence; no engagement/save rate (Stories have no likes/saves; every existing analysis leaves them out). A missing number always carries a reason (unsupported / not captured / not measured / under 5 viewers / no follower count), never 0.
- **Engagement rate both ways (§0b):** per reach (default, = SPEC §7) or per followers (`?er=followers`): interactions ÷ the account's follower count on the posting day (`account_daily.followers`; each peer uses its own day). Days without a follower count give a reason, not a number.
- **Link taps** = `profile_activity`'s `BIO_LINK_CLICKED` action (Meta's `action_type` value; the name goes into `lib/instagram/metrics.ts`, read case-insensitively).
- **Post Lab metrics are a small table in `lib/analysis/post-lab.ts`, not entries in the Explorer registry `lib/metrics.ts`.** They are per-item snapshot values; the registry computes Explorer rollups from SQL parts, and save/share/follow rates or watch time would need new SQL parts there. A new Post Lab number is still one entry (+ one label).
- **Story sequence:** the account's Stories of the same owner-timezone day, oldest first, with reach, "% of the first Story's reach" and exit rate (exits ÷ views, as the Stories tab); best/worst frame = lowest/highest exit rate among ≥ 2 measured frames. Story funnel: forward taps, back taps, exits, swipes forward, each as a count and a share of views, plus replies.
- **Caption lab:** length (characters), hashtags (count + list), mentions (count), emoji (count), question (`?`/`？`), call-to-action words (a short en + zh list in `lib/analysis/caption.ts`). The with/without comparison runs over the peers that were read (same format, ≤ 90) and only from **20 measured posts** (spec), each side needing ≥ 5 posts; it compares median reach ("Posts with a question: 1.2K median reach (n = 14) vs 900 (n = 31)") and says plainly that this is a pattern in your own posts, not a cause. No caption lab for Stories (no captions).
- **Similar posts:** up to 6 peers, those sharing a tag first, then the newest; each links to its own Post Lab.
- **Back link and links in keep the Time Scope:** the Post Lab has no scope of its own, but it carries the canonical scope parameters (`scopeQuery(parseTimeScope(sp))`, never echoed raw) and puts them on its back link (the account's Posts or Stories tab) and on every link it renders; every link into it carries the referring page's scope. Browser Back covers "where did I come from" (Calendar, Explorer).
- **Entry points without breaking 12b's drill path:** the Posts table title and the grid tile date keep linking to the Explorer item level (12b; its follower curve around the post); next to them a small flask link opens the Post Lab, and 13a's drawers get "Open Post Lab" in their `action` slot. The Post Lab header links back to the Explorer item level ("Followers around this post"), the Explorer item level to the Post Lab. The Calendar day list links each item's name to its Post Lab.
- **Route group move:** `app/(app)/accounts/[id]/page.tsx` + `loading.tsx` move into `app/(app)/accounts/[id]/(tabs)/` (same URL) — at `[id]/` the account skeleton would also wrap the Post Lab (`tests/route-loading.test.tsx` forbids that; same pattern as `accounts/(list)/`).
- **Missing migration = a clear page, not a crash:** if PostgREST answers "function not found" (`PGRST202`) the Post Lab shows "The Post Lab needs a database update" with the runbook pointer; no other page calls the new functions (the links into the Post Lab are plain links), so nothing else depends on the migration.
- **Another account's media id gets nothing:** the media row is read with `account_id = <the URL's account>` under RLS; no row → 404.
- **No new dependencies; no Meta calls; no capture changes; no new Meta metrics** (one constant name for an action type that is already captured).

## Open questions for the owner (the plan implements the default shown)

1. Peers = the 30 (toggle: 90) same-format posts published before this one? **Default: yes.** Alternative: the newest 30 of the account whatever the post's age.
2. Sample guard 5 measured peers (same as the "taking off" flag)? **Default: yes** (5 is coarse for percentiles; 10 would hide comparisons on small accounts for months).
3. Verdict on reach for every format (Reels too)? **Default: yes** (views is Instagram's headline for Reels; switch is one line).
4. "Too early" before day 7 unless the post already leads (Breakout/Above)? **Default: yes.**
5. Caption lab compares the same format only? **Default: yes** (mixing Reels and images would compare formats, not captions).

## Global Constraints

- Ponytail: smallest thing that works; no abstraction with one implementation (`ScoreTable` has two callers: scorecard + watch time); **no new dependencies** (charts: Recharts via the existing `SeriesChart`).
- TypeScript strict. No Meta metric names added or changed; ONE constant for an already-captured breakdown value (`LINK_TAP_ACTION`) goes into `lib/instagram/metrics.ts`.
- DB: ONE new migration `supabase/migrations/20261026000001_post_lab.sql` (named after `20261024000001`; never edit applied migrations). Functions: `language sql stable security invoker set search_path = ''`, typed array parameters, no dynamic SQL; `revoke execute … from public, anon; grant execute … to authenticated`. No table, no policy change. **Apply it BEFORE deploying the code** (runbook §0); only the Post Lab route calls it, and without it shows "needs a database update" instead of crashing.
- Reads: OWNER SESSION client (`createServerSupabase`) only, under RLS; never the admin client, never `account_tokens`. Explicit column lists; fixed error messages (`post lab read: <op> failed`) that never echo Supabase errors. The media row is always filtered by the URL's account id.
- The page calls `requireOwner()` first, validates `id` (uuid) and `mediaId` (`isMediaId`) before any database client, hides archived accounts (404), and is wiring only.
- Pure logic deterministic: `lib/analysis/post-lab.ts`, `lib/analysis/caption.ts`, `lib/post-lab/params.ts` take `now`/`tz` as inputs; no `Date.now()` / `new Date()` there.
- Every UI string via next-intl; ALL new keys are added by Task 2 in BOTH `messages/en.json` and `messages/zh-CN.json` (real Simplified Chinese, full-width punctuation); later tasks only read them. `tests/messages.test.ts` enforces parity + placeholders (ICU `select` branches must be multi-word in English, see Task 2).
- Theming: semantic tokens only (`bg-success/15 text-success`, `bg-destructive/10`, `bg-muted`, `--chart-n` through `SeriesChart`); no raw colours. Responsive 360 / 768 / 1280, desktop-first; CSS breakpoints only; `min-w-0` + `truncate` on user text; no fixed pixel widths on layout containers.
- UI kit: build from `components/ui/` + `components/shared/`; tag editing reuses `TagPicker` (a `ResponsiveDialog`); density is un-layered (no `h-*`/`p-*` on shadcn `Button`/`Card`/table cells). No `npx shadcn` call is needed in this plan.
- Dates, times and numbers only via `lib/format.ts` (`formatDateTime`, `formatTime`, `formatNumber`, `formatCompact`, `formatPercent`, `formatSigned`, `formatDelta`); the "no number" dash is `formatNumber(null, prefs)`.
- Every link into the Post Lab carries the referring page's Time Scope (`postLabHref(accountId, mediaId, scope.query)`); every link out of it carries the scope it was opened with.
- Tests: Vitest timeout 20 s; jsdom 29; rerun once on "worker start timeout" before concluding anything (`tests/posts-tab.test.tsx` is known slow); never chain a commit after a piped command.

- [ ] **Step 3: Write the migration** — create `supabase/migrations/20261026000001_post_lab.sql`:

```sql
-- Plan 13b: Post Lab reads. Additive (two functions, nothing else). Apply BEFORE deploying the code that calls them;
-- only the Post Lab route (/accounts/[id]/media/[mediaId]) does, and it shows "needs a database update" without them.
--
-- Both functions are `security invoker`: they run with the caller's rights, so the owner-only RLS policies of media and
-- media_metrics still apply (any other session gets no rows). Execute is revoked from public/anon and granted to
-- `authenticated` only. Inputs are typed arrays (media ids, minutes); nothing is concatenated into SQL. The checkpoint
-- table (marks and tolerances in minutes) is passed in by lib/analysis/post-lab.ts, so it exists in one place only.

-- 1. The latest KNOWN value of every metric column per media (newest non-null value of each column), plus when the
-- newest snapshot was taken and how many there are. Extras of a snapshot can be missing on a busy tick (the per-run
-- extras budget) while the snapshot before has them; a Story's latest values are its final numbers (Stories are only
-- measured while live). Media without any snapshot return no row.
create or replace function public.post_lab_latest(p_ids text[])
returns table (media_id text, captured_at timestamptz, snapshots int, reach int, views int, likes int, comments int, saves int, shares int, total_interactions int, replies int, taps_forward int, taps_back int, exits int, swipe_forward int, follows int, profile_visits int, profile_activity jsonb, avg_watch_ms int, total_watch_ms bigint, skip_rate numeric)
language sql
stable
security invoker
set search_path = ''
as $$
  select x.media_id,
         max(x.captured_at),
         count(*)::int,
         (array_agg(x.reach order by x.captured_at desc) filter (where x.reach is not null))[1],
         (array_agg(x.views order by x.captured_at desc) filter (where x.views is not null))[1],
         (array_agg(x.likes order by x.captured_at desc) filter (where x.likes is not null))[1],
         (array_agg(x.comments order by x.captured_at desc) filter (where x.comments is not null))[1],
         (array_agg(x.saves order by x.captured_at desc) filter (where x.saves is not null))[1],
         (array_agg(x.shares order by x.captured_at desc) filter (where x.shares is not null))[1],
         (array_agg(x.total_interactions order by x.captured_at desc) filter (where x.total_interactions is not null))[1],
         (array_agg(x.replies order by x.captured_at desc) filter (where x.replies is not null))[1],
         (array_agg(x.taps_forward order by x.captured_at desc) filter (where x.taps_forward is not null))[1],
         (array_agg(x.taps_back order by x.captured_at desc) filter (where x.taps_back is not null))[1],
         (array_agg(x.exits order by x.captured_at desc) filter (where x.exits is not null))[1],
         (array_agg(x.swipe_forward order by x.captured_at desc) filter (where x.swipe_forward is not null))[1],
         (array_agg(x.follows order by x.captured_at desc) filter (where x.follows is not null))[1],
         (array_agg(x.profile_visits order by x.captured_at desc) filter (where x.profile_visits is not null))[1],
         (array_agg(x.profile_activity order by x.captured_at desc) filter (where x.profile_activity is not null))[1],
         (array_agg(x.avg_watch_ms order by x.captured_at desc) filter (where x.avg_watch_ms is not null))[1],
         (array_agg(x.total_watch_ms order by x.captured_at desc) filter (where x.total_watch_ms is not null))[1],
         (array_agg(x.skip_rate order by x.captured_at desc) filter (where x.skip_rate is not null))[1]
    from public.media_metrics x
   where x.media_id = any (p_ids)
   group by x.media_id
$$;

-- 2. Velocity checkpoints: per media and mark (minutes after posting), the snapshot NEAREST to posted_at + mark whose
-- age is within the mark's tolerance (p_marks[i] pairs with p_tols[i]); the earlier snapshot wins a tie. No snapshot in
-- the window = no row for that mark (a point is never interpolated). age_min = the snapshot's real age in minutes.
create or replace function public.post_lab_points(p_ids text[], p_marks int[], p_tols int[])
returns table (media_id text, mark int, age_min int, reach int, views int)
language sql
stable
security invoker
set search_path = ''
as $$
  select distinct on (x.media_id, k.mark)
         x.media_id, k.mark, round(extract(epoch from x.captured_at - m.posted_at) / 60)::int, x.reach, x.views
    from public.media m
    join public.media_metrics x on x.media_id = m.id
   cross join unnest(p_marks, p_tols) as k(mark, tol)
   where m.id = any (p_ids)
     and (x.reach is not null or x.views is not null)
     and abs(extract(epoch from x.captured_at - m.posted_at) / 60 - k.mark) <= k.tol
   order by x.media_id, k.mark, abs(extract(epoch from x.captured_at - m.posted_at) / 60 - k.mark), x.captured_at
$$;

revoke execute on function public.post_lab_latest(text[]) from public, anon;
revoke execute on function public.post_lab_points(text[], int[], int[]) from public, anon;
grant execute on function public.post_lab_latest(text[]) to authenticated;
grant execute on function public.post_lab_points(text[], int[], int[]) to authenticated;
```

// Caption lab (creator-toolkit design §5.6): what a caption contains, and how the account's own posts with and without
// each trait did (median reach). Pure. A pattern in your own posts, never a cause; no comparison below 20 posts (spec).
import { median } from '@/lib/analysis/posts';

export const CAPTION_MIN_POSTS = 20; // measured posts (reach > 0) the with/without comparison needs at all
export const CAPTION_MIN_SIDE = 5; // posts each side of one trait needs for its median

/** Call-to-action words (lower case), English and Simplified Chinese. Matching rules for captions, not UI text.
 *  Latin words match as whole words ("comment below", not "comments"); Chinese words match anywhere; links, hashtags
 *  and mentions are skipped ("#shop" and "@brand.shop" are not a call to action). */
export const CTA_WORDS = ['link in bio', 'comment', 'save', 'share', 'tag', 'follow', 'dm', 'click', 'shop', 'subscribe', 'sign up', '评论', '收藏', '分享', '转发', '关注', '私信', '点击', '链接'] as const;

export interface CaptionFeatures {
  length: number; // characters (code points: an emoji or a Chinese character is one)
  hashtags: string[]; // unique, lower case, in order of appearance, without '#'
  mentions: number;
  emoji: number; // pictographic code points (ponytail: a ZWJ family emoji counts per person; fine for a rough count)
  question: boolean;
  cta: string[]; // the call-to-action words found
}

const HASHTAG = /#([\p{L}\p{N}_]+)/gu;
const MENTION = /(^|[^\w.])@[\w.]+/g; // "a@b.com" is an e-mail, not a mention
const EMOJI = /\p{Extended_Pictographic}/gu;
const LATIN = /^[a-z ]+$/;
const NOT_WORDS = /https?:\/\/\S+|[#@][\p{L}\p{N}_.]+/gu; // links, hashtags and mentions are not call-to-action words
const escape = (s: string) => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
const CTA = CTA_WORDS.map((w) => ({ w, re: LATIN.test(w) ? new RegExp(`(^|[^\\p{L}\\p{N}])${escape(w)}($|[^\\p{L}\\p{N}])`, 'iu') : null }));

export function captionFeatures(caption: string | null): CaptionFeatures {
  const text = caption ?? '';
  const words = text.replace(NOT_WORDS, ' ');
  const lower = words.toLowerCase();
  return {
    length: [...text].length,
    hashtags: [...new Set([...text.matchAll(HASHTAG)].map((m) => m[1].toLowerCase()))],
    mentions: [...text.matchAll(MENTION)].length,
    emoji: [...text.matchAll(EMOJI)].length,
    question: /[?？]/.test(text),
    cta: CTA.filter(({ w, re }) => (re ? re.test(words) : lower.includes(w))).map(({ w }) => w),
  };
}

export const CAPTION_TRAITS = ['long', 'hashtags', 'mentions', 'emoji', 'question', 'cta'] as const;
export type CaptionTrait = (typeof CAPTION_TRAITS)[number];

export interface CaptionSide {
  n: number;
  median: number | null; // median reach; null below CAPTION_MIN_SIDE posts
}
export interface CaptionSplit {
  trait: CaptionTrait;
  has: boolean; // this post has the trait
  with: CaptionSide;
  without: CaptionSide;
}
export interface CaptionLab {
  features: CaptionFeatures;
  measured: number; // peers with reach > 0
  longFrom: number | null; // "long" = at least this many characters (the peers' median length)
  splits: CaptionSplit[] | null; // null below CAPTION_MIN_POSTS measured peers
}

function traitOf(t: CaptionTrait, f: CaptionFeatures, longFrom: number): boolean {
  switch (t) {
    case 'long':
      return f.length >= longFrom;
    case 'hashtags':
      return f.hashtags.length > 0;
    case 'mentions':
      return f.mentions > 0;
    case 'emoji':
      return f.emoji > 0;
    case 'question':
      return f.question;
    case 'cta':
      return f.cta.length > 0;
  }
}

const side = (reach: number[]): CaptionSide => ({ n: reach.length, median: reach.length >= CAPTION_MIN_SIDE ? median(reach) : null });

/** This caption's features, and median reach of the peers with vs without each trait (from 20 measured peers on). */
export function captionLab(caption: string | null, peers: { caption: string | null; reach: number | null }[]): CaptionLab {
  const features = captionFeatures(caption);
  const measured = peers.filter((p): p is { caption: string | null; reach: number } => typeof p.reach === 'number' && p.reach > 0).map((p) => ({ f: captionFeatures(p.caption), reach: p.reach }));
  if (measured.length < CAPTION_MIN_POSTS) return { features, measured: measured.length, longFrom: null, splits: null };
  const longFrom = median(measured.map((m) => m.f.length)) ?? 0;
  const splits = CAPTION_TRAITS.map((trait) => {
    const yes = measured.filter((m) => traitOf(trait, m.f, longFrom)).map((m) => m.reach);
    const no = measured.filter((m) => !traitOf(trait, m.f, longFrom)).map((m) => m.reach);
    return { trait, has: traitOf(trait, features, longFrom), with: side(yes), without: side(no) };
  });
  return { features, measured: measured.length, longFrom, splits };
}

/** Share of `values` below `v` plus half of those equal to it, × 100 (mid-rank percentile). */
export function percentile(v: number, values: number[]): number | null {
  if (values.length === 0) return null;
  const below = values.filter((x) => x < v).length;
  const equal = values.filter((x) => x === v).length;
  return Math.round(((below + equal / 2) / values.length) * 100);
}

const followersOn = (followers: Record<string, number>, postedAt: string, tz: string): number | null => {
  const f = followers[localDay(new Date(postedAt), tz)];
  return num(f) ? f : null;

function reasonOf(id: LabMetricId, item: LabItem, c: Ctx): LabReason {
  const d = LAB_METRICS[id];
  if (d.unsupported?.includes(item.mediaType)) return 'unsupported';
  if (!item.latest) return item.mediaType === 'STORY' ? 'needs_5_viewers' : 'not_measured';
  if (id === 'engagementRate' && c.er === 'followers') return c.followers === null ? 'no_followers' : 'not_captured';
  if ((d.perReach || id === 'engagementRate') && !(num(item.latest.reach) && item.latest.reach > 0)) return 'no_reach';
  return 'not_captured';
}

/** One row per metric shown for the item's format, each against the same metric of the peers. */
export function scoreRows(ids: readonly LabMetricId[], item: LabItem, peers: LabItem[], o: { er: ErBasis; followers: Record<string, number>; tz: string }): ScoreRow[] {
  const story = item.mediaType === 'STORY';
  const ctxOf = (x: LabItem): Ctx => ({ er: o.er, followers: followersOn(o.followers, x.postedAt, o.tz), story });
  return ids
    .filter((id) => LAB_METRICS[id].formats.includes(item.mediaType))
    .map((id) => {
      const d = LAB_METRICS[id];
      const c = ctxOf(item);
      const unsupported = d.unsupported?.includes(item.mediaType) ?? false;
      const value = !unsupported && item.latest ? d.value(item.latest, c) : null;
      const values = unsupported ? [] : peers.flatMap((p) => (p.latest ? [d.value(p.latest, ctxOf(p))] : [])).filter(num);
      const med = values.length >= MIN_PRIOR_POSTS ? median(values) : null;
      const compare = value !== null && med !== null;
      return {
        id,
        kind: d.kind,
        lowerIsBetter: d.lowerIsBetter ?? false,
        value,
        reason: value === null ? reasonOf(id, item, c) : null,
        n: values.length,
        median: med,
        percentile: compare ? percentile(value, values) : null,
        delta: compare ? (d.kind === 'percent' ? value - med : med > 0 ? value / med - 1 : null) : null,
      };
    });
}

export type Verdict = 'breakout' | 'above' | 'typical' | 'below' | 'too_early';

const expiryOf = (i: LabItem) => (i.expiresAt ? Date.parse(i.expiresAt) : Date.parse(i.postedAt) + DAY);

/**
 * The verdict chip, from reach vs the peers' reach. Null (the UI says why) without reach or below the sample guard.
 * Reach only grows, so a lead counts early: a feed post / Reel gets Breakout (≥ 2× median, the "taking off" rule) or
 * Above typical (≥ 75th percentile) from 24 h on, the full scale only from day 7; a Story the lead while live, the full
 * scale once expired (final numbers). Anything else before that is Too early.
 */
export function verdictOf(item: LabItem, reach: ScoreRow | undefined, now: Date): Verdict | null {
  if (!reach || reach.value === null || reach.median === null || reach.percentile === null) return null;
  const age = now.getTime() - Date.parse(item.postedAt);
  const story = item.mediaType === 'STORY';
  if (!story && age < MIN_AGE_HOURS * HOUR) return 'too_early';
  if (reach.median > 0 && reach.value >= TAKING_OFF_RATIO * reach.median) return 'breakout';
  if (reach.percentile >= 75) return 'above';
  const final = story ? now.getTime() >= expiryOf(item) : age >= CHECKPOINT_DAYS * DAY;
  if (!final) return 'too_early';
  return reach.percentile < 25 ? 'below' : 'typical';
}

export interface VelocityPoint {
  id: CheckpointId;
  due: boolean; // the checkpoint's time has passed (a missing point is then a gap in the snapshots, not "not yet")
  reach: number | null;
  views: number | null;
  medianReach: number | null; // null below the sample guard
  medianViews: number | null;
  nReach: number;
  nViews: number;
}
export interface Velocity {
  points: VelocityPoint[];
  /** The latest checkpoint where the item and the median both exist: "at 24 h, 2.3× the median reach of 12 posts". */
  lead: { at: CheckpointId; metric: 'reach' | 'views'; ratio: number; n: number } | null;
}

export function velocity(item: LabItem, peers: LabItem[], now: Date): Velocity {
  const ids = item.mediaType === 'STORY' ? STORY_CHECKPOINTS : CHECKPOINTS.map((c) => c.id);
  const age = (now.getTime() - Date.parse(item.postedAt)) / MIN;
  const points = ids.map((id): VelocityPoint => {
    const c = CHECKPOINTS.find((x) => x.id === id)!;
    const own = item.points[id];
    const of = (k: keyof LabPoint) => peers.map((p) => p.points[id]?.[k] ?? null).filter(num);
    const r = of('reach');
    const w = of('views');
    return {
      id,
      due: age >= c.min,
      reach: own?.reach ?? null,
      views: own?.views ?? null,
      medianReach: r.length >= MIN_PRIOR_POSTS ? median(r) : null,
      medianViews: w.length >= MIN_PRIOR_POSTS ? median(w) : null,
      nReach: r.length,
      nViews: w.length,
    };
  });
  let lead: Velocity['lead'] = null;
  for (const p of [...points].reverse()) {
    if (num(p.reach) && num(p.medianReach) && p.medianReach > 0) lead = { at: p.id, metric: 'reach', ratio: p.reach / p.medianReach, n: p.nReach };
    else if (num(p.views) && num(p.medianViews) && p.medianViews > 0) lead = { at: p.id, metric: 'views', ratio: p.views / p.medianViews, n: p.nViews };
    if (lead) break;
  }
  return { points, lead };
}

/** A Story's navigation (taps forward/back, exits, swipes to the next account) as counts and shares of its views. */
export function storyFunnel(v: LabValues | null): Funnel | null {

    id: s.id,

    views: s.latest?.views ?? null,
    exitRate: ratio(s.latest?.exits ?? null, s.latest?.views ?? null),
    retention: ratio(s.latest?.reach ?? null, base),
    current: s.id === currentId,
  }));
  const rated = frames.filter((f): f is Frame & { exitRate: number } => f.exitRate !== null);
  if (rated.length < 2) return { frames, best: null, worst: null };
  const best = rated.reduce((a, f) => (f.exitRate < a.exitRate ? f : a));
  const worst = rated.reduce((a, f) => (f.exitRate > a.exitRate ? f : a));
  return { frames, best: best.id, worst: worst.id === best.id ? null : worst.id };
}

/** Up to SIMILAR_MAX peers: those sharing a tag with the item first, then the newest (peers are newest first). */
export function similarPosts(item: LabItem, peers: LabItem[]): LabItem[] {
  const tagged = peers.filter((p) => p.tagIds.some((t) => item.tagIds.includes(t)));
  return [...tagged, ...peers.filter((p) => !tagged.includes(p))].slice(0, SIMILAR_MAX);
}

export interface PostLabModel {
  item: LabItem;
  peers: { asked: PeerCount; used: number; read: number };
  er: ErBasis;
  followers: number | null; // the account's followers on the posting day
  live: boolean; // a Story still up
  verdict: Verdict | null;
  scorecard: ScoreRow[];
  watch: ScoreRow[] | null; // Reels
  velocity: Velocity;
  funnel: Funnel | null; // Stories
  sequence: Sequence | null; // Stories
  caption: CaptionLab | null; // not for Stories
  similar: LabItem[];
}

export function buildPostLab(input: LabInput, o: { now: Date; tz: string; peers: PeerCount; er: ErBasis }): PostLabModel {
  const { item } = input;
  const story = item.mediaType === 'STORY';
  const peers = input.peers.slice(0, o.peers);
  const opts = { er: o.er, followers: input.followers, tz: o.tz };
  const scorecard = scoreRows(SCORECARD, item, peers, opts);
  return {
    item,
    peers: { asked: o.peers, used: peers.length, read: input.peers.length },
    er: o.er,
    followers: followersOn(input.followers, item.postedAt, o.tz),
    live: story && o.now.getTime() < expiryOf(item) && item.goneAt === null,
    verdict: verdictOf(item, scorecard.find((r) => r.id === 'reach'), o.now),
    scorecard,
    watch: item.mediaType === 'REELS' ? scoreRows(WATCH, item, peers, opts) : null,
    velocity: velocity(item, peers, o.now),
    funnel: story ? storyFunnel(item.latest) : null,
    sequence: story ? storySequence(input.day.some((s) => s.id === item.id) ? input.day : [...input.day, item], item.id) : null,
    caption: story ? null : captionLab(item.caption, input.peers.map((p) => ({ caption: p.caption, reach: p.latest?.reach ?? null }))),
    similar: similarPosts(item, input.peers),
  };
}

// Post Lab reads. OWNER SESSION client only (RLS decides what exists; never the admin client, never account_tokens).
// Plain selects for the media row, its same-format predecessors (peers), the day's Stories and the posting-day follower
// counts; the latest values and the velocity checkpoints come from the two `security invoker` functions of
// supabase/migrations/20261026000001_post_lab.sql. Fixed error messages only (Supabase messages can echo values).
import type { SupabaseClient } from '@supabase/supabase-js';
import { CHECKPOINTS, PEER_MAX, type CheckpointId, type LabInput, type LabItem, type LabValues } from '@/lib/analysis/post-lab';
import { safeLink } from '@/lib/dashboard/read';
import { LINK_TAP_ACTION } from '@/lib/instagram/metrics';
import type { MediaKind } from '@/lib/instagram/parse';
import type { CoverStatus } from '@/lib/sync/covers';
import { addDays, dayStart, localDay } from '@/lib/sync/time';

/** The day's Stories read for the sequence view (Instagram allows 100 live Stories). */
export const DAY_STORIES_MAX = 100;
const MEDIA_COLUMNS = 'id,account_id,media_type,posted_at,expires_at,gone_at,permalink,caption,cover_status,children_count,media_tags(tag_id)';
const COVERS: readonly string[] = ['pending', 'ok', 'unavailable', 'failed'];
const KINDS: readonly string[] = ['IMAGE', 'CAROUSEL_ALBUM', 'REELS', 'STORY'];
/** PostgREST "function not found" / Postgres undefined_function: the Post Lab migration is not applied yet. */
const MISSING_FUNCTION = ['PGRST202', '42883'];

export type PostLabRead = { kind: 'ok'; input: LabInput } | { kind: 'not_found' } | { kind: 'needs_migration' };

type Row = Record<string, unknown>;
const num = (v: unknown) => (typeof v === 'number' && Number.isFinite(v) ? v : typeof v === 'string' && v.trim() !== '' && Number.isFinite(Number(v)) ? Number(v) : null);
const str = (v: unknown) => (typeof v === 'string' ? v : null);
const rows = (data: unknown) => (Array.isArray(data) ? (data as Row[]) : []);

function fail(op: string): never {
  throw new Error(`post lab read: ${op} failed`);
}

function toItem(r: Row): LabItem {
  return {
    id: String(r.id),
    accountId: String(r.account_id),
    mediaType: r.media_type as MediaKind,
    postedAt: String(r.posted_at),
    expiresAt: str(r.expires_at),
    goneAt: str(r.gone_at),
    permalink: safeLink(r.permalink),
    caption: str(r.caption),
    tagIds: rows(r.media_tags).flatMap((t) => (typeof t.tag_id === 'string' ? [t.tag_id] : [])),
    cover: COVERS.includes(r.cover_status as string) ? (r.cover_status as CoverStatus) : 'pending',
    slides: num(r.children_count),
    measuredAt: null,
    latest: null,
    points: {},
  };
}

/** profile_activity → link taps: the BIO_LINK_CLICKED count, whatever the key's case. */
function linkTaps(activity: unknown): number | null {
  if (activity === null || typeof activity !== 'object' || Array.isArray(activity)) return null;
  const hit = Object.entries(activity as Row).find(([k]) => k.toUpperCase() === LINK_TAP_ACTION);
  return hit ? num(hit[1]) : null;
}

function toValues(r: Row): LabValues {
  const skip = num(r.skip_rate);
  return {
    reach: num(r.reach),
    views: num(r.views),
    likes: num(r.likes),
    comments: num(r.comments),
    saves: num(r.saves),
    shares: num(r.shares),
    interactions: num(r.total_interactions),
    replies: num(r.replies),
    tapsForward: num(r.taps_forward),
    tapsBack: num(r.taps_back),
    exits: num(r.exits),
    swipeForward: num(r.swipe_forward),
    follows: num(r.follows),
    profileVisits: num(r.profile_visits),
    linkTaps: linkTaps(r.profile_activity),
    avgWatchMs: num(r.avg_watch_ms),
    totalWatchMs: num(r.total_watch_ms),
    skipRate: skip === null ? null : skip / 100, // reels_skip_rate is a percent
  };
}

/**
 * Everything the Post Lab needs for one media item of one account: not_found when the item is not that account's
 * (or not visible under RLS), needs_migration when the SQL functions do not exist yet.
 */
export async function loadPostLab(db: SupabaseClient, accountId: string, mediaId: string, tz: string): Promise<PostLabRead> {
  const head = await db.from('media').select(MEDIA_COLUMNS).eq('id', mediaId).eq('account_id', accountId).limit(1);
  if (head.error) fail('item');
  const first = rows(head.data)[0];
  if (!first || !KINDS.includes(first.media_type as string)) return { kind: 'not_found' };
  const base = toItem(first);
  const day = localDay(new Date(base.postedAt), tz);
  const [peerRes, dayRes] = await Promise.all([
    db
      .from('media')
      .select(MEDIA_COLUMNS)
      .eq('account_id', accountId)
      .eq('media_type', base.mediaType)
      .lt('posted_at', base.postedAt)
      .order('posted_at', { ascending: false })
      .order('id', { ascending: false })
      .limit(PEER_MAX),
    base.mediaType === 'STORY'
      ? db
          .from('media')
          .select(MEDIA_COLUMNS)
          .eq('account_id', accountId)
          .eq('media_type', 'STORY')
          .gte('posted_at', dayStart(day, tz).toISOString())
          .lt('posted_at', dayStart(addDays(day, 1), tz).toISOString())
          .order('posted_at', { ascending: true })
          .limit(DAY_STORIES_MAX)
      : Promise.resolve({ data: [], error: null }),
  ]);
  if (peerRes.error) fail('peers');
  if (dayRes.error) fail('day');
  const peers = rows(peerRes.data).map(toItem);
  const dayItems = rows(dayRes.data).map(toItem);
  const ids = [...new Set([base, ...peers, ...dayItems].map((m) => m.id))];
  const days = [...new Set([base, ...peers].map((m) => localDay(new Date(m.postedAt), tz)))];
  const [latest, points, daily] = await Promise.all([
    db.rpc('post_lab_latest', { p_ids: ids }),
    db.rpc('post_lab_points', { p_ids: [base, ...peers].map((m) => m.id), p_marks: CHECKPOINTS.map((c) => c.min), p_tols: CHECKPOINTS.map((c) => c.tol) }),
    db.from('account_daily').select('day,followers').eq('account_id', accountId).in('day', days),
  ]);
  for (const e of [latest.error, points.error]) if (e && MISSING_FUNCTION.includes(String((e as { code?: unknown }).code))) return { kind: 'needs_migration' };
  if (latest.error) fail('latest');
  if (points.error) fail('points');
  if (daily.error) fail('followers');

  const byId = new Map(rows(latest.data).map((r) => [String(r.media_id), r]));
  const marks = new Map<number, CheckpointId>(CHECKPOINTS.map((c) => [c.min, c.id]));
  const curve = new Map<string, LabItem['points']>();
  for (const r of rows(points.data)) {
    const id = marks.get(Number(r.mark));
    if (!id) continue;
    const key = String(r.media_id);
    curve.set(key, { ...curve.get(key), [id]: { reach: num(r.reach), views: num(r.views) } });
  }
  const fill = (m: LabItem): LabItem => {
    const r = byId.get(m.id);
    return { ...m, measuredAt: r ? str(r.captured_at) : null, latest: r ? toValues(r) : null, points: curve.get(m.id) ?? {} };
  };
  const followers: Record<string, number> = {};
  for (const r of rows(daily.data)) {
    const f = num(r.followers);
    if (f !== null && typeof r.day === 'string') followers[r.day] = f;
  }
  return { kind: 'ok', input: { item: fill(base), peers: peers.map(fill), day: dayItems.map(fill), followers } };
}

// Post Lab URL state: its two toggles (?peers=90, ?er=followers) plus the Time Scope it only CARRIES for its links
// (the Post Lab is per item and has no scope of its own). Pure; anything unknown falls back to the default.
import type { ErBasis, PeerCount } from '@/lib/analysis/post-lab';
import type { WeekStart } from '@/lib/prefs';
import { parseTimeScope, scopeParams } from '@/lib/time-scope/scope';

type Params = Record<string, string | string[] | undefined>;

export interface LabParams {
  peers: PeerCount;
  er: ErBasis;
  scope: Record<string, string>; // the canonical Time Scope parameters (scopeParams), never raw URL values
}

export function parseLabParams(sp: Params, weekStart: WeekStart = 'mon'): LabParams {
  return {
    peers: sp.peers === '90' ? 90 : 30,
    er: sp.er === 'followers' ? 'followers' : 'reach',
    scope: scopeParams(parseTimeScope(sp, weekStart)),
  };
}

/** The Post Lab of one item. `query` = the referring page's scope query (ResolvedScope.query), '' for none. */
export function postLabHref(accountId: string, mediaId: string, query = ''): string {
  return `/accounts/${encodeURIComponent(accountId)}/media/${encodeURIComponent(mediaId)}${query ? `?${query}` : ''}`;
}

/** The query of this Post Lab with one toggle changed: the scope first, then only non-default toggles. */
export function labQuery(p: LabParams, patch: Partial<Pick<LabParams, 'peers' | 'er'>> = {}): string {
  const next = { ...p, ...patch };

  if (next.peers !== 30) q.set('peers', String(next.peers));
  if (next.er !== 'reach') q.set('er', next.er);
  return q.toString();
}

/** Back to the account's Posts (or Stories) tab, with the scope. */
export function backHref(accountId: string, story: boolean, p: LabParams): string {
  const q = new URLSearchParams({ tab: story ? 'stories' : 'posts', ...p.scope });
  return `/accounts/${encodeURIComponent(accountId)}?${q}`;

'use client';

// Post Lab scorecard and the Reels watch-time panel (same rows): each number with your median, its percentile among
// your earlier posts of the same format and the difference, or a short reason why it is missing (explained under the
// table). Plus the verdict chip with its one-line reason. Table on md+, cards on phones (DataTable).
import { Hourglass, Minus, Rocket, TrendingDown, TrendingUp } from 'lucide-react';
import { useTranslations } from 'next-intl';
import { usePrefs } from '@/components/providers/PrefsProvider';
import { ChartCard } from '@/components/shared/ChartCard';
import { DataTable, type Column } from '@/components/shared/DataTable';
import { DeltaPill, type StatDelta } from '@/components/shared/StatCard';
import type { LabKind, ScoreRow, Verdict } from '@/lib/analysis/post-lab';
import { formatDelta, formatNumber, formatPercent, formatSigned } from '@/lib/format';
import { cn } from '@/lib/utils';

/** A Post Lab number as text, by kind (durations come in milliseconds). */
export function useLabValue() {
  const t = useTranslations('postLab');
  const { prefs } = usePrefs();
  return (kind: LabKind, v: number | null): string => {
    if (v === null || kind === 'count') return formatNumber(v, prefs, { maximumFractionDigits: 0 });
    if (kind === 'percent') return formatPercent(v, prefs);
    if (kind === 'per1k') return formatNumber(v, prefs, { maximumFractionDigits: 1 });
    const s = v / 1000;
    const n = (x: number) => formatNumber(x, prefs, { maximumFractionDigits: 1 });
    return s >= 3600 ? t('duration.h', { n: n(s / 3600) }) : s >= 60 ? t('duration.min', { n: n(s / 60) }) : t('duration.s', { n: n(s) });
  };
}

function useDelta() {
  const t = useTranslations('postLab');
  const { prefs } = usePrefs();
  return (r: ScoreRow): StatDelta | null => {
    if (r.delta === null) return null;
    const points = r.kind === 'percent';
    const shown = Number((r.delta * 100).toFixed(1));
    const direction = shown > 0 ? 'up' : shown < 0 ? 'down' : 'flat';
    const tone = direction === 'flat' ? 'neutral' : (direction === 'up') !== r.lowerIsBetter ? 'good' : 'bad';
    return { text: points ? t('points', { value: formatSigned(r.delta * 100, prefs, 1) }) : formatDelta(r.delta, prefs), direction, tone };
  };
}

export function ScoreTable({ title, subtitle, rows }: { title: string; subtitle: string; rows: ScoreRow[] }) {
  const t = useTranslations('postLab');
  const { prefs } = usePrefs();
  const value = useLabValue();
  const delta = useDelta();
  const dash = formatNumber(null, prefs); // lib/format.ts's placeholder for "no number"
  const reasons = [...new Set(rows.flatMap((r) => (r.reason ? [r.reason] : [])))];
  const few = rows.some((r) => r.value !== null && r.median === null);
  const columns: Column<ScoreRow>[] = [
    { key: 'metric', header: t('col.metric'), cell: (r) => t(`metric.${r.id}`) },
    { key: 'value', header: t('col.value'), align: 'right', cell: (r) => (r.value === null ? <span className="text-muted-foreground">{t(`reason.${r.reason ?? 'not_captured'}`)}</span> : value(r.kind, r.value)) },
    { key: 'median', header: t('col.median'), align: 'right', cell: (r) => (r.median === null ? dash : t('medianOf', { value: value(r.kind, r.median), n: r.n })) },
    { key: 'pct', header: t('col.percentile'), align: 'right', cell: (r) => (r.percentile === null ? dash : t('percentile', { n: r.percentile })) },
    {
      key: 'delta',
      header: t('col.delta'),
      align: 'right',
      cell: (r) => {
        const d = delta(r);
        return d ? <DeltaPill delta={d} /> : dash;
      },
    },
  ];
  return (
    <ChartCard title={title} subtitle={subtitle}>
      <DataTable rows={rows} columns={columns} rowKey={(r) => r.id} caption={title} />
      {reasons.length || few ? (
        <ul className="mt-3 grid gap-1 text-xs text-muted-foreground">
          {reasons.map((r) => (
            <li key={r}>
              <span className="font-medium">{t(`reason.${r}`)}:</span> {t(`reasonHint.${r}`)}
            </li>
          ))}
          {few ? <li>{t('fewPeers')}</li> : null}
        </ul>
      ) : null}
    </ChartCard>
  );
}

const CHIP: Record<Verdict, { icon: typeof Rocket; className: string }> = {
  breakout: { icon: Rocket, className: 'bg-success/15 text-success' },
  above: { icon: TrendingUp, className: 'bg-success/10 text-success' },
  typical: { icon: Minus, className: 'bg-muted text-muted-foreground' },
  below: { icon: TrendingDown, className: 'bg-destructive/10 text-destructive' },
  too_early: { icon: Hourglass, className: 'bg-muted text-muted-foreground' },
};

/** The verdict chip and why: from reach vs your median, or the reason there is no verdict. */
export function VerdictLine({ verdict, reach, story }: { verdict: Verdict | null; reach: ScoreRow | undefined; story: boolean }) {
  const t = useTranslations('postLab');
  const { prefs } = usePrefs();
  let why: string;
  if (verdict === null) why = reach?.reason ? t(`reasonHint.${reach.reason}`) : t('why.fewPosts', { n: reach?.n ?? 0 });
  else if (verdict === 'too_early') why = t(story ? 'why.tooEarlyStory' : 'why.tooEarly');
  else if (verdict === 'breakout') why = t('why.breakout', { ratio: formatNumber((reach?.value ?? 0) / (reach?.median || 1), prefs, { maximumFractionDigits: 1 }), n: reach?.n ?? 0 });
  else why = t('why.rank', { pct: reach?.percentile ?? 0, n: reach?.n ?? 0 });
  const chip = verdict ? CHIP[verdict] : null;
  return (
    <div className="flex min-w-0 flex-wrap items-center gap-2">
      {chip ? (
        <span data-verdict={verdict} className={cn('inline-flex items-center gap-1 rounded-full px-2.5 py-0.5 text-sm font-medium', chip.className)}>
          <chip.icon aria-hidden="true" className="size-3.5" />
          {t(`verdict.${verdict}`)}
        </span>
      ) : null}
      <p className="min-w-0 text-xs text-muted-foreground">{why}</p>
    </div>
  );
}

'use client';

// Caption lab: what this caption contains, and the median reach of your posts of this format with vs without each trait
// (from 20 measured posts on, each side from 5). A pattern in your own posts, said plainly: not a cause.
import { useTranslations } from 'next-intl';
import { usePrefs } from '@/components/providers/PrefsProvider';
import { ChartCard } from '@/components/shared/ChartCard';
import { DataTable, type Column } from '@/components/shared/DataTable';
import { CAPTION_MIN_POSTS, type CaptionLab as CaptionLabModel, type CaptionSide, type CaptionSplit } from '@/lib/analysis/caption';
import { formatNumber } from '@/lib/format';

export function CaptionLab({ lab }: { lab: CaptionLabModel }) {
  const t = useTranslations('postLab.caption');
  const { prefs } = usePrefs();
  const count = (n: number) => formatNumber(n, prefs, { maximumFractionDigits: 0 });
  const { features: f } = lab;
  const facts: [string, string][] = [
    [t('length'), count(f.length)],
    [t('hashtags'), count(f.hashtags.length)],
    [t('mentions'), count(f.mentions)],
    [t('emoji'), count(f.emoji)],
    [t('question'), t(f.question ? 'yes' : 'no')],
    [t('cta'), f.cta.length ? f.cta.join(', ') : t('no')],
  ];
  const side = (s: CaptionSide) => (s.median === null ? t('tooFew', { n: s.n }) : t('side', { value: count(s.median), n: s.n }));
  const columns: Column<CaptionSplit>[] = [
    { key: 'trait', header: t('trait'), cell: (s) => (s.trait === 'long' ? t('trait_long', { n: count(lab.longFrom ?? 0) }) : t(`trait_${s.trait}`)) },
    { key: 'has', header: t('thisPost'), cell: (s) => t(s.has ? 'yes' : 'no') },
    { key: 'with', header: t('with'), align: 'right', cell: (s) => side(s.with) },
    { key: 'without', header: t('without'), align: 'right', cell: (s) => side(s.without) },
  ];
  return (
    <ChartCard title={t('title')} subtitle={t('hint')}>
      <dl className="grid grid-cols-2 gap-x-3 gap-y-2 text-sm sm:grid-cols-3 xl:grid-cols-6">
        {facts.map(([k, v]) => (
          <div key={k} className="min-w-0">
            <dt className="truncate text-xs text-muted-foreground">{k}</dt>
            <dd className="truncate font-medium tabular-nums" dir="auto">
              {v}
            </dd>
          </div>
        ))}
      </dl>
      {f.hashtags.length ? (
        <ul aria-label={t('hashtags')} className="mt-2 flex flex-wrap gap-1">
          {f.hashtags.map((h) => (
            <li key={h} className="max-w-full truncate rounded-full bg-muted px-2 py-0.5 text-xs text-muted-foreground" dir="auto">
              #{h}
            </li>
          ))}
        </ul>
      ) : null}
      <div className="mt-4">
        {lab.splits ? (
          <>
            <DataTable rows={lab.splits} columns={columns} rowKey={(s) => s.trait} caption={t('splitCaption')} />
            <p className="mt-2 text-xs text-muted-foreground">{t('notCause', { n: lab.measured })}</p>
          </>
        ) : (
          <p className="text-sm text-muted-foreground">{t('needMore', { min: CAPTION_MIN_POSTS, n: lab.measured })}</p>
        )}
      </div>
    </ChartCard>
  );
}

import { notFound } from 'next/navigation';
import { setPostTagsAction } from '@/app/(app)/tags/actions';
import { PostLabUnavailable, PostLabView } from '@/components/post-lab/PostLabView';
import { buildPostLab } from '@/lib/analysis/post-lab';
import { requireOwner } from '@/lib/auth/require-owner';
import { loadAccounts } from '@/lib/dashboard/cached';
import { loadTags } from '@/lib/dashboard/detail-read';
import { backHref, parseLabParams } from '@/lib/post-lab/params';
import { loadPostLab } from '@/lib/post-lab/read';
import { getPrefs } from '@/lib/prefs.server';
import { createServerSupabase } from '@/lib/supabase/server';
import { isMediaId, isUuid } from '@/lib/tags';

type SearchParams = Record<string, string | string[] | undefined>;

/** Post Lab: one post, Reel, carousel or Story of one live account (creator-toolkit design §5). Wiring only. */
export default async function PostLabPage({ params, searchParams }: { params: Promise<{ id: string; mediaId: string }>; searchParams: Promise<SearchParams> }) {
  await requireOwner(); // layouts don't re-run on client navigation, so the page checks too
  const { id, mediaId } = await params;
  if (!isUuid(id) || !isMediaId(mediaId)) notFound();
  const [sp, accounts, prefs] = await Promise.all([searchParams, loadAccounts(), getPrefs()]);
  const account = accounts.find((a) => a.id === id.toLowerCase() && a.status !== 'archived'); // archived accounts are hidden (SPEC §7c)
  if (!account) notFound();
  const lab = parseLabParams(sp, prefs.weekStart);
  const db = await createServerSupabase(); // owner session: RLS applies, never the admin client
  const [read, tags] = await Promise.all([loadPostLab(db, account.id, mediaId, prefs.timezone), loadTags(db)]);
  if (read.kind === 'not_found') notFound(); // includes another account's media id
  if (read.kind === 'needs_migration') return <PostLabUnavailable back={backHref(account.id, false, lab)} />;
  const model = buildPostLab(read.input, { now: new Date(), tz: prefs.timezone, peers: lab.peers, er: lab.er });
  // the imported server action is passed straight to the client component (never wrapped in a closure here)
  return <PostLabView model={model} account={{ id: account.id, username: account.username }} tags={tags} params={lab} setPostTags={setPostTagsAction} />;
}
