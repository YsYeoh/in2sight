# Plan 14c: App-shell tabs — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Implementers: read `docs/superpowers/implementer-rules.md` first.

**Goal:** Browser-style tabs inside the app (spec §4.3): several pages open at once in the existing header row, switching is instant and never reloads, each tab keeps its own range, filters, scroll and open drawer; the left sidebar stays; per-tab Back/Forward; the open tabs survive a reload.

**Architecture:** The top-level document becomes **the shell plus a tab host only**; every tab is a same-origin `<iframe>` of the app, kept mounted while inactive (`invisible` + `inert`), up to 8 live frames (3 on touch devices), least-recently-viewed inactive frames discarded (their tab stays and reloads from its URL when selected). The same `(app)` layout serves both: `AppShell` renders the **host** (sidebar, header with the tab strip, frames) at the top level and a **chromeless** page (no sidebar/header, a `FrameBridge`) inside a frame. "Am I framed?" is decided on the client (`window.self !== window.top`, through `useSyncExternalStore`); `Sec-Fetch-Dest: iframe` is only the server-render hint so the first paint of a frame has no chrome. Frames and shell talk through a small validated `postMessage` protocol (`lib/tabs/protocol.ts`); all tab logic is one pure reducer (`lib/tabs/model.ts`). Per-tab Back/Forward use a history stack the shell keeps per tab (not the frame's `history`, which is shared by the whole window). Pages themselves are unchanged.

**Tech Stack:** Next.js 16.4 App Router, React 19.3 (`useSyncExternalStore`, `inert`), TypeScript strict, next-intl 4, Radix via `components/ui` + `ResponsiveDialog`, lucide-react, Vitest 5 + Testing Library + jsdom 29. **New dependencies: none. No migration.**

**Spec:** `docs/superpowers/specs/2026-10-20-ux-polish-and-tabs-design.md` §4.3 (App-shell tabs), §3 (owner decisions: strip in the header row, sidebar click rule, in-page links), §5 (constraints, `frame-ancestors 'self'`), §8 items 4–5 (spike pass/fail, phone), §9 (Back/Forward). Project rules: `CLAUDE.md` (binding).

**Runs in parallel with Plan 14a** (foundation: control height, scrollbar, underline tabs, RangeBar, FilterToolbar). This plan does not use any 14a component; it reuses the existing `--ctl` control token, `Button` sizes and the `bg-hover` / `bg-accent` conventions of the current sidebar. Shared files are listed in the task table.

## Decisions taken in this plan (owner: please confirm the ones marked ⚠)

1. **Framed or not is decided on the client.** `AppShell` takes `framed` (the server's `Sec-Fetch-Dest: iframe` hint, read in `app/(app)/layout.tsx`) and computes `useSyncExternalStore(noop, () => isFramed(), () => framedHint)`. After hydration the real answer wins, so a refresh or server action that re-renders the layout without the header (Spike A 3–4) can never bring the chrome back. If a browser ever omits the header, the frame paints the chrome for one frame and then hides it (no break). No query flag.
2. **The top level never shows a page.** In host mode `AppShell` does not render `children` (the server still renders the page once for that top-level request; ponytail: one wasted page render per full reload of the shell, accepted; the alternative, a proxy rewrite to a shell-only route, breaks on any top-level `router.refresh()` because RSC requests cannot be told apart). Frames mount only after hydration (no `<iframe>` in the server HTML), so a mis-detected frame can never nest another frame.
3. **Hidden, not unmounted:** inactive live frames get `invisible` + `inert` + `aria-hidden` and stay absolutely positioned at full size (charts keep their width; focus and screen readers skip them; Spike A 7).
4. ⚠ **Back/Forward are per-tab stacks kept by the shell** (max 50 entries each), not `frame.history` (Spike A 5 shows the history is shared by all frames). Back sets the tab's URL to the previous entry and the shell sends the frame `in2sight:go` (a client navigation, `router.push`), so the page re-renders at that URL: its URL state (range, filters, `?tab`, `?page`) comes back, scroll goes to the top and an open drawer is closed. The browser's own Back button stays best effort (it steps whichever frame navigated last), as the spec says; documented in the runbook. Stacks are not persisted across a reload.
5. **Link rules in one capture listener per document.** Top level (`TabsProvider`): any same-origin link to a tab page is turned into a tab action; the mode comes from the nearest `[data-tab-open]` ancestor: the sidebar `nav` is `nav` (jump to the most recently viewed tab whose path matches; "Accounts" matches `/accounts` only), the phone bottom bar is `current` (navigate inside the active tab, spec §8.5), everything else (bell items, user menu "Settings") is `exact`; ctrl/⌘/middle-click is always `exact`. Inside a frame (`FrameBridge`): ctrl/⌘-click, middle-click and `target="_blank"` on a link to a tab page post `in2sight:open` (new tab, or jump to the tab with that exact URL); plain clicks are left to Next (they stay in the tab). Links to anything that is not a tab page (Instagram, `/report` preview, `/api/*` downloads) keep their normal browser behaviour.
6. **Break-out = "a framed document that is not a tab page"**, checked by `FrameBreakout` in the ROOT layout on every pathname: `/login`, `/login/verify`, `/setup`, `/auth/signout`, `/report`, `/styleguide`, `/` all take over the whole window with `window.top.location.replace(location.href)` (same origin, so the frame may do it directly; no message needed, and it works even if the shell's script failed). This also covers proxy redirects and server-action redirects to `/login`. Sign-out (in the top-level user menu) is unchanged.
7. ⚠ **Tab titles come from the page, not from new metadata:** the frame reports the text of `main h1` (every page has one through `PageHeader` or the Post Lab header); on an account page (`/accounts/<id>`) it appends the selected section tab (`@yseny_ · Overview`). A `MutationObserver` (250 ms debounce) re-reports when the heading streams in. Until a title arrives the strip shows the sidebar label of the path (for example "Explorer") or "Loading…". No page files change.
8. **Service worker:** iframe navigations are no longer answered by the worker (Spike A 10), so they keep `Sec-Fetch-Dest: iframe`. Consequence: offline, a frame shows the browser's own error inside the tab; the top-level shell still gets the offline page. Push clicks: if a top-level window exists the worker posts it `in2sight:open` and focuses it (the shell opens or jumps to the tab with that exact URL); otherwise it opens a new window at the URL (the shell restores the saved tabs and activates that URL). Nested frame clients are ignored.
9. **Live-frame cap:** 8, or 3 when `readMotionEnv(window).coarsePointer` (phones and tablets; the existing shared check in `lib/motion.ts`, no new media query). Frames mount lazily: after a reload only the active tab loads; the others load when first selected.
10. ⚠ **Stale tabs:** a live tab that was not viewed for 30 minutes (the sync interval) is marked stale when you switch back to it; the Refresh button next to Back/Forward then shows a dot and a longer label; Refresh = `router.refresh()` in that frame (keeps scroll and drawers). Refresh is always available. No auto-refresh.
11. **Persistence:** `localStorage['in2sight.tabs'] = {"v":1,"tabs":[{"url","title"}, …]}` (try/catch both ways; invalid entries are dropped). The active tab is not stored separately: the address bar always shows it, and on load the address-bar URL always wins: if a saved tab has exactly that URL it becomes active, otherwise a tab for it is added and activated. Two browser windows share the list; the last writer wins (multi-window is a spec non-goal).
12. **New tab ("+") opens `/overview` and is appended at the end; links opened in a new tab are appended at the end too.** Closing the active tab activates its right neighbour, else the left one; closing the last tab opens Overview.
13. ⚠ **Phone:** header shows "Tabs (N)" (opens a sheet: Back/Forward/Refresh, the tab list with switch and close, "New tab"); the strip is `md+` only. The bottom bar navigates inside the current tab.
14. **"Open in new tab" icon:** a new shared `OpenInTab` link (`target="_blank"`, `AppWindow` icon, `aria-label` "Open … in a new tab"): inside the app the frame turns it into a tab; without tabs it is an ordinary new browser tab. ⚠ Placed on the Overview account cards and next to the Post Lab link of each Posts row/tile (Task 11, after 14a/14b have landed on those files). Ctrl/middle-click works on every link anyway.
15. **Every frame report and every shell command is validated** (`readFrameMessage` / `readShellMessage`): same origin only, the sender must be one of our frames (top level) or the parent (frame), URLs must resolve to a same-origin tab page (`javascript:`, other origins, `/login`, `/api` are rejected), titles are strings cut to 120 characters.
16. **`frame-ancestors 'self'`** for every route in `next.config.ts` (other sites cannot frame the app; the headless-Chromium PDF render is top-level and unaffected).

## Global Constraints

- Ponytail: smallest thing that works. No new dependency, no feature flag, no abstraction with one implementation: the reducer is the only tab logic; the context exists because four components (strip, sheet, frames, shell) read it.
- TypeScript strict. Pure logic (`lib/tabs/model.ts`, `lib/tabs/protocol.ts`) takes `now` and `origin` as inputs; no `Date.now()` / `window` there except `isFramed(w = window)`.
- Security: same-origin only. Every `message` handler checks `event.origin === location.origin` AND the sender (`event.source` is one of our frames at the top level; `window.parent` inside a frame); every URL from a message goes through `tabUrl()`; `postMessage` always passes `location.origin` as `targetOrigin`, never `'*'`. No tokens or user data in messages (URLs and page headings only). `frame-ancestors 'self'` on every route.
- Every UI string via next-intl; ALL new keys are added by Task 4 in BOTH message files (namespace `tabs`), real Simplified Chinese with full-width punctuation; later tasks only read them.
- Theming: semantic tokens only (`bg-background`, `bg-card`, `bg-hover`, `bg-accent`, `text-muted-foreground`, `bg-primary` for the stale dot). Every new component right in all themes, light and dark.
- Responsive: the strip is `md+` (`hidden md:flex`), the "Tabs (N)" button below `md` (`md:hidden`), CSS breakpoints only (never `matchMedia` for layout; the live cap uses `lib/motion.ts`, which is about device class, not layout). No fixed pixel widths on layout containers (tab items use `basis-56 min-w-16 max-w-56` in rem utilities).
- Density is un-layered: never `h-*` / `p-*` on a shadcn `Button`; the tab items are plain `button`s sized with `h-[var(--ctl)]`.
- Accessibility: `role="tablist"` with `aria-label`, `role="tab"` + `aria-selected` + roving `tabIndex`, Arrow/Home/End/Delete keys, close buttons named "Close <title>", every iframe has a `title`; motion only `transition-colors` (honours reduced motion by being trivial).
- Storage: every `localStorage` access in try/catch; the app works without it.
- Tests: Vitest, jsdom 29 (iframes there have an `about:blank` window; tests dispatch `MessageEvent`s with `source: iframe.contentWindow` and spy on `contentWindow.postMessage`). Timeout 20 s; rerun once on "worker start timeout".
- `npm run check` passes after every task. Commits: conventional, `git add` specific paths, `git commit -m "<msg>" -m "Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>"`. Don't push.

```ts
// App-shell tabs (Plan 14c, spec §4.3): the whole tab logic as one pure reducer. TabHost keeps this state; the frames
// only report where they are and obey "go"/"refresh". Deterministic: time comes in as `now`.
//
// url      = the page the shell wants the tab to show (the address bar shows the active tab's url).
// frameUrl = what the tab's live frame last reported (null = no report since it was mounted).
// url !== frameUrl (frameUrl not null) = a command is on its way: TabHost posts `in2sight:go` to that frame.
// Back/Forward are per-tab stacks kept here: all frames share ONE browser history, so a frame's history.back() can
// step another tab (Plan 14c, Spike A 5).
import { NAV_ITEMS, isActive, type NavItem } from '@/lib/nav';

export const HOME = '/overview';
export const LIVE_CAP = 8;
export const LIVE_CAP_COARSE = 3; // phones and tablets (lib/motion coarsePointer)
export const STALE_MS = 30 * 60_000; // the sync interval
export const HISTORY_MAX = 50;
export const STORAGE_KEY = 'in2sight.tabs';

export interface Tab {
  id: string;
  url: string;
  title: string; // '' until the frame reports a heading
  back: string[]; // oldest first
  fwd: string[]; // nearest first
  viewedAt: number; // last time it was active (0 = never since load: no frame yet)
  frameUrl: string | null;
  stale: boolean;
}
export interface TabsState {
  tabs: Tab[];
  active: string;
  next: number;
  cap: number;
}
/** nav = sidebar (path match), exact = same URL, current = navigate the active tab (phone bottom bar), new = always a new tab. */
export type OpenMode = 'nav' | 'exact' | 'current' | 'new';
export type TabsAction =
  | { type: 'open'; url: string; mode: OpenMode; now: number }
  | { type: 'activate'; id: string; now: number }
  | { type: 'close'; id: string; now: number }
  | { type: 'report'; id: string; url: string; title: string }
  | { type: 'step'; id: string; dir: -1 | 1 }
  | { type: 'refreshed'; id: string }
  | { type: 'cap'; cap: number }
  | { type: 'restore'; raw: string | null };

export const pathOf = (url: string): string => url.split(/[?#]/, 1)[0];

/** Pages that live in a tab: the six main sections and everything below them. Anything else breaks out of a frame. */
export const isTabPath = (pathname: string): boolean => NAV_ITEMS.some((i) => isActive(pathname, i.href));

/** Sidebar rule: same section path; "Accounts" means the list page only, not an account. */
export function navMatches(tabUrl: string, href: string): boolean {
  const p = pathOf(tabUrl);
  const h = pathOf(href);
  return h === '/accounts' ? p === h : isActive(p, h);
}

export function navKeyOf(url: string): NavItem['key'] | null {
  const p = pathOf(url);
  return NAV_ITEMS.find((i) => isActive(p, i.href))?.key ?? null;
}

const blank = (id: string, url: string, title = ''): Tab => ({ id, url, title, back: [], fwd: [], viewedAt: 0, frameUrl: null, stale: false });

export function initialTabs(url: string): TabsState {
  return { tabs: [blank('t0', url)], active: 't0', next: 1, cap: LIVE_CAP };
}

/** The frames that stay mounted: the active tab plus the most recently viewed others, up to the cap (LRU). */
export function liveIds(s: TabsState): Set<string> {
  const others = s.tabs.filter((t) => t.id !== s.active && t.viewedAt > 0).sort((a, b) => b.viewedAt - a.viewedAt);
  return new Set([s.active, ...others.slice(0, Math.max(0, s.cap - 1)).map((t) => t.id)]);
}

/** A tab whose frame was discarded forgets its frame report: the next mount loads `url` fresh. */
function settle(s: TabsState): TabsState {
  const live = liveIds(s);
  return { ...s, tabs: s.tabs.map((t) => (live.has(t.id) || (t.frameUrl === null && !t.stale) ? t : { ...t, frameUrl: null, stale: false })) };
}

const patch = (s: TabsState, id: string, f: (t: Tab) => Tab): TabsState => ({ ...s, tabs: s.tabs.map((t) => (t.id === id ? f(t) : t)) });
const push = (list: string[], url: string) => [...list, url].slice(-HISTORY_MAX);

function activate(s: TabsState, id: string, now: number): TabsState {
  if (id === s.active || !s.tabs.some((t) => t.id === id)) return s;
  const wasLive = liveIds(s).has(id);
  const tabs = s.tabs.map((t) => {
    if (t.id === s.active) return { ...t, viewedAt: now };
    if (t.id !== id) return t;
    return { ...t, viewedAt: now, stale: wasLive && t.viewedAt > 0 && now - t.viewedAt >= STALE_MS };
  });
  return settle({ ...s, tabs, active: id });
}

function open(s: TabsState, url: string, mode: OpenMode, now: number): TabsState {
  if (mode === 'current') {
    const cur = s.tabs.find((t) => t.id === s.active);
    return !cur || cur.url === url ? s : patch(s, s.active, (t) => ({ ...t, url, back: push(t.back, t.url), fwd: [], stale: false }));
  }
  const hits = mode === 'exact' ? s.tabs.filter((t) => t.url === url) : mode === 'nav' ? s.tabs.filter((t) => navMatches(t.url, url)) : [];
  const hit = hits.find((t) => t.id === s.active) ?? [...hits].sort((a, b) => b.viewedAt - a.viewedAt)[0];
  if (hit) return activate(s, hit.id, now);
  const id = `t${s.next}`;
  return activate({ ...s, tabs: [...s.tabs, blank(id, url)], next: s.next + 1 }, id, now);
}

function close(s: TabsState, id: string, now: number): TabsState {
  const i = s.tabs.findIndex((t) => t.id === id);
  if (i < 0) return s;
  const tabs = s.tabs.filter((t) => t.id !== id);
  if (!tabs.length) {
    const nid = `t${s.next}`;
    return { ...s, tabs: [{ ...blank(nid, HOME), viewedAt: now }], active: nid, next: s.next + 1 };
  }
  if (id !== s.active) return settle({ ...s, tabs });
  return activate({ ...s, tabs }, (tabs[i] ?? tabs[i - 1]).id, now);
}

function report(t: Tab, url: string, title: string): Tab {
  if (url === t.frameUrl) return { ...t, title: title || t.title }; // the frame has not moved: a title update (or a command still on its way)
  if (t.frameUrl === null || url === t.url) return { ...t, url, frameUrl: url, title: title || (url === t.url ? t.title : '') }; // first load (or a redirect), or a command arrived
  return { ...t, url, frameUrl: url, title, back: push(t.back, t.url), fwd: [] }; // a navigation inside the tab
}

function step(t: Tab, dir: -1 | 1): Tab {
  if (dir < 0) return t.back.length ? { ...t, url: t.back[t.back.length - 1], back: t.back.slice(0, -1), fwd: [t.url, ...t.fwd].slice(0, HISTORY_MAX), stale: false } : t;
  return t.fwd.length ? { ...t, url: t.fwd[0], fwd: t.fwd.slice(1), back: push(t.back, t.url), stale: false } : t;
}

function restore(s: TabsState, raw: string | null): TabsState {
  let saved: { url: string; title: string }[];
  try {
    const v = JSON.parse(raw ?? 'null') as { v?: unknown; tabs?: unknown } | null;
    if (v?.v !== 1 || !Array.isArray(v.tabs)) return s;
    saved = (v.tabs as { url?: unknown; title?: unknown }[])
      .filter((t) => typeof t?.url === 'string' && t.url.startsWith('/') && !t.url.startsWith('//') && isTabPath(pathOf(t.url)))
      .map((t) => ({ url: t.url as string, title: typeof t.title === 'string' ? t.title.slice(0, 120) : '' }));
  } catch {
    return s;
  }
  if (!saved.length) return s;
  const cur = s.tabs.find((t) => t.id === s.active)!;
  const at = saved.findIndex((t) => t.url === cur.url);
  const tabs = saved.map((t, k) => (k === at ? { ...cur, title: cur.title || t.title } : blank(`t${s.next + k}`, t.url, t.title)));
  return { ...s, tabs: at < 0 ? [...tabs, cur] : tabs, next: s.next + saved.length };
}

export function tabsReducer(s: TabsState, a: TabsAction): TabsState {
  switch (a.type) {
    case 'open':
      return open(s, a.url, a.mode, a.now);
    case 'activate':
      return activate(s, a.id, a.now);
    case 'close':
      return close(s, a.id, a.now);
    case 'report':
      return patch(s, a.id, (t) => report(t, a.url, a.title));
    case 'step':
      return patch(s, a.id, (t) => step(t, a.dir));
    case 'refreshed':
      return patch(s, a.id, (t) => ({ ...t, stale: false }));
    case 'cap':
      return settle({ ...s, cap: a.cap });
    case 'restore':
      return restore(s, a.raw);
  }
}

export function serialize(s: TabsState): string {
  return JSON.stringify({ v: 1, tabs: s.tabs.map(({ url, title }) => ({ url, title })) });
}
```

```ts
// App-shell tabs (Plan 14c): the messages between the shell (top window), its frames and the service worker. Every
// message is checked here before anyone acts on it: same origin only, URLs must be same-origin tab pages, titles are
// plain strings. Senders always pass `location.origin` as targetOrigin (never '*'). No tokens or user data, only
// URLs and page headings.
import { isTabPath } from '@/lib/tabs/model';

/** frame → shell: where the frame is now (after every navigation and when its heading changes). */
export type NavReport = { type: 'in2sight:nav'; url: string; title: string };
/** frame or service worker → shell: open a tab for this URL, or jump to the tab that has exactly this URL. */
export type OpenRequest = { type: 'in2sight:open'; url: string };
/** frame → shell: Alt+Left / Alt+Right pressed inside the frame. */
export type HistoryRequest = { type: 'in2sight:history'; dir: -1 | 1 };
export type FrameMessage = NavReport | OpenRequest | HistoryRequest;
/** shell → frame: navigate (client-side) to this URL / re-fetch the server data of the current page. */
export type ShellMessage = { type: 'in2sight:go'; url: string } | { type: 'in2sight:refresh' };

export const TITLE_MAX = 120;

/** A same-origin tab page as path + query (hash dropped), or null for anything else (other origins, /login, /api…). */
export function tabUrl(href: string, origin: string): string | null {
  let u: URL;
  try {
    u = new URL(href, origin);
  } catch {
    return null;
  }
  return u.origin === origin && isTabPath(u.pathname) ? u.pathname + u.search : null;
}

/** True inside a frame. A cross-origin parent throws on access: that is framed too. */
export function isFramed(w: Window = window): boolean {
  try {
    return w.self !== w.top;
  } catch {
    return true;
  }
}

type Raw = { type?: unknown; url?: unknown; title?: unknown; dir?: unknown };
const raw = (data: unknown): Raw | null => (data !== null && typeof data === 'object' ? (data as Raw) : null);
const url = (d: Raw, origin: string) => (typeof d.url === 'string' ? tabUrl(d.url, origin) : null);

/** A message from a frame or the service worker, validated; null when it is not ours or not valid. */
export function readFrameMessage(data: unknown, origin: string): FrameMessage | null {
  const d = raw(data);
  if (!d) return null;
  if (d.type === 'in2sight:nav' || d.type === 'in2sight:open') {
    const u = url(d, origin);
    if (!u) return null;
    return d.type === 'in2sight:open' ? { type: d.type, url: u } : { type: d.type, url: u, title: typeof d.title === 'string' ? d.title.trim().slice(0, TITLE_MAX) : '' };
  }
  if (d.type === 'in2sight:history' && (d.dir === -1 || d.dir === 1)) return { type: d.type, dir: d.dir };
  return null;
}

/** A command from the shell, validated; null when it is not ours or not valid. */
export function readShellMessage(data: unknown, origin: string): ShellMessage | null {
  const d = raw(data);
  if (!d) return null;
  if (d.type === 'in2sight:refresh') return { type: d.type };
  if (d.type === 'in2sight:go') {
    const u = url(d, origin);
    return u ? { type: d.type, url: u } : null;
  }
  return null;
}
```
